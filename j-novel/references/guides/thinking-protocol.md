# 思考协议（Thinking Protocol）—— 为什么 AI 味是在「正文之前」定下的

> **定位**：本文件是**原理层**（为什么）。操作层是 `references/cards/card-thinking.md`（写手读）；
> 运行时可粘贴的提示词原文在 `references/prompts/thinking-protocol.md`（逐字粘贴，不要改写）。
> **三者分工**：本文件解释机制与边界；卡给落笔动作；prompts 给系统提示原文。**同一段文字只住在一个地方。**
>
> **为什么需要它**：本体系此前 54 本 guides、10 张卡、22 个脚本，**没有任何一行管思维链**。
> 全部工程都压在**输出面**（句长、密度、次数、改写）。而实测反馈是两句话——
> **「文笔还是很 AI」**和**「想很久没成果」**。这两句不是输出的问题，是**思考的问题**。

---

## 零、一句话结论

> **思考买结构，材料买声音。**
> 把思考预算花在「决定」上（删什么、谁的眼中、失去什么、停在哪、第一个词），
> 把语域交给样本（口吻宪法 / 人类范本 / 本书最佳段落）。
> **反过来做——想出一个好句子——是这套系统里最贵的浪费。**

依据是`references/architecture.md` 第 7.1 节那张强度表：**具体材料 + 语域样本 = 最强；规则 = 弱**。
思考产出的是**规则级的自我约束**，它对语域几乎无效；它对**结构**有效，因为结构是离散的、可以被"选定"的。

## 一、病灶：V4.1-Flash 写小说为什么会「想很久没成果」

这不是模型能力不足，是**后训练把思维链训成了另一种商品**。技术报告里有五处可以直接对上的事实。

| # | 报告事实 | 出处 | 它对写作意味着什么 |
|---|---|---|---|
| 1 | effort 是 RL 训练出来的**标量条件信号**，写在系统提示里：`Reasoning Effort: {effort} (range 1–100; higher values request more thorough reasoning)`；公开 API 三档 `max=100 / high=75 / low=50` | §5.1.4、Table 2 | **「多想」是有开关的**，而且是训练过的开关，不是修辞。默认不传 = 低档。 |
| 2 | 奖励里带**长度罚**：`r = acc − min(λmax, λ(e)·τ/L_norm)`，`λ(e)=λ₀·exp(−(e−e_min)/d)`；档位越低罚得越重 | §5.1.4 式(9)(10)、附录 C | 低档下模型被**训练成"少想"**。这就是「畏手畏脚」的来源：它是一种学到的策略，不是情绪。 |
| 3 | 异步训练有**长度分布偏置**（短序列先跑完、主导早期批次），要靠"丢弃早返回的短样本"才能避免"过拟合到过短序列" | §5.2.2 | 长度先验**很顽固**——他们得专门对抗它。一句话提示未必拆得动它。 |
| 4 | effort 25→100，八个推理基准 67.1%→76.3%，代价 token ×2.5；**60–80 已拿到大部分收益**；最后一步到 100 只把轨迹拉长 1.6–1.8×，换 marginal 提升 | §5.3.3、Fig.9 | **「想得多」不是线性收益**。"无上限"不会自动变好。 |
| 5 | effort 在 agent 里「governs the total amount of **exploration and verification** across turns」；附录 C 自陈该指令「can directly change the reasoning strategy」 | §5.3.2 note、附录 C | ★ **关键**：effort 买的商品是**探勘与验证**。它改的是**策略族**，不是"更用力"。 |

### 1.1 推论一：写作没有验证器，所以验证在空转

推理题的思维链有终点：**能验算就是对的**。所以"探勘 + 验证"有回报。
小说没有验证器。同一个"验证"动作落在这里，产物是：

- 把约束再读一遍（"本章要还的债是……"）
- 把风险再评一遍（"这里会不会太露骨 / 会不会和设定冲突"）
- 把质量再问一遍（"这样够不够好 / 像不像 AI"）
- 把方案再列一遍，然后一个都不选（"可以有三种写法：A…… B…… C……"）

**这四类 token 的位移是零。** 它们不改任何一句正文。
「想很久没成果」= 观察到的正是这个：**思考量上去了，决定没上去。**

### 1.2 推论二：验证不只是浪费，它会改变语域

比浪费更严重的是**方向错了**：

> 一旦思考在做"检查"，正文就落在**安全且完整**的一侧。
> 而"安全且完整"就是 AI 味的定义——每件事都交代、每句都工整、每个情绪都有落点。

`architecture.md` §7.2 ③ 已经记过同一个机制，但**它只把自评挡在了正文之后**（"写完直接交，不要自评"）。
**而模型的自我审查发生在正文之前。** 那条闸门设在了一道已经流过去的下游。

这是本体系此前最贵的一处结构性错位：**最有效的反 AI 味机制，装在了错误的时刻上。**

### 1.3 三种思考模式（分诊表）

| 模式 | 思考里在做什么 | 产物长什么样 | 对正文的作用 |
|---|---|---|---|
| **决策式** ✅ | 在几个**不可逆**的选项里挑一个，并明确放弃其余 | 「这一章不写灵堂，写守夜」「比喻全部从苏晚的嗅觉取」 | **改变文本**：删掉的那件真的不在正文里 |
| **审稿式** ❌ | 对照清单检查、评估质量、权衡风险 | 「要确保不违反设定」「这里要注意别太长」「应该够了吧」 | **把文本推向均值**：保守 = 均匀 = AI 味 |
| **演戏式** ❌ | 用第一人称替角色内心独白、预演台词 | 「他想，如果她死了……」「我暗自……」 | **把解释腔带进正文**：正文变成内心戏的复述 |

**一句话判据**：**这个思考动作，能不能让正文少一句、或者多一件东西？**
不能 → 它在空转。空转超过三分之一，这段思考就是在生产 AI 味。

> **为什么会滑向审稿式**：这是训练出来的默认。RL 阶段模型见过的最"高质量"的思维链全是验证式的
> （报告 §5.1.2 的训练任务就是可验证的 agent / coding 任务）。**它在做它被奖励过的事，只是任务换了。**

## 二、机制一：把 effort 调到高档（官方开关，不是修辞）

```text
Reasoning Effort: 100 (range 1–100; higher values request more thorough reasoning)
```

- **放哪儿**：系统提示（或 brief 最前）。**逐字**，不要翻译、不要加解释——这是训练时的条件格式。
- **为什么不是"请认真思考"**：那是自然语言请求；这个是**训练过的条件信号**，模型在 RL 里见过它在不同取值下对应不同的策略族。
- **为什么不是 999**：档位训练范围是 1–100。超出范围的值落在训练分布外，行为不可预期。
- **为什么要 100 而不是 75**：写作是**结构不可逆**的任务，删除类决定的代价最高，值得买满。
  ⚠️ 但报告说 60–80 已拿到大部分收益、到 100 主要买"探索与验证"——**所以光调到 100 不够，
  必须同时把这份探索导向"决定"（第四节），否则买到的是更多空转。**

## 三、机制二：把「无上限」用在正确的地方

「你的 token 预算无上限、随意花费」这句话**有效，但它买的是错误商品**。

| 它做了什么 | 它没做什么 |
|---|---|
| 松开第 2 条那个长度罚带来的"少想"策略 | 不改变思考的**类型**——它让模型**更多地**做它原本在做的事 |
| 让模型敢展开、敢列候选、不早停 | 如果原本在做的是"验证"，那只是**验证得更多** |
| **可能加重**"到处都在用力"这一类 AI 味（`architecture.md` §7.3） | 不会自动产生一个决定 |

**正确形态：把"无上限"从全局改成定向。**

```text
算力声明：本次的 token 预算不设限，不必节省。但它只允许花在「决定」上——
删哪一件、从谁的眼睛取景、让谁失去什么、停在哪一句、第一个词是什么。
花在「检查自己合不合格」上的每一个字都是浪费：判是下一道工序的事，不是你的。
```

差别在于**后两句**：它给"挥霍"指定了用途，同时把自评从思考里**划出去**。
只留前一句（"你很富有"），等于给一个正在空转的人加满油。

## 四、机制三：决策五问（effort 的靶子）

这是本协议的核心。**五问都是不可逆的**——写下去之后再改，等于重写这一章。

| # | 问 | 怎么算答对了 | ❌ 空转的答法 |
|---|---|---|---|
| **1 删** | 这一章**不写**什么？ | 从细纲的 3 件事里**划掉 1 件**，并说清它去哪了（移到第 N 章 / 这章就是不发生） | 「本章要写 A、B、C」——那是复述细纲 |
| **2 眼** | 这一章所有的**比喻、量词、气味**从谁身上取？ | 一句话说出"这一章的物理世界长在谁的感官里"；**允许不是主角** | 「第三人称限知视角」——那是术语，不是决定 |
| **3 弃** | 主角这一章**失去**什么具体的东西？ | 一个**名词短语**，能在后文被人拿出来说"你上次丢了那个" | 「他很痛苦」「他受了伤」（下一章就好） |
| **4 留** | 哪一处**该解释而我不解释**，句子停在哪？ | 抄下你要停的那句的**最后几个字**（只出现在思考里，不进正文） | 「结尾留白」——那是形容词 |
| **5 开** | 第一句的**第一个词**是什么？ | 从「人 / 物 / 动作 / 话」里选一个。**不许是时间、天气、天色、"那年"** | 「用环境描写开头」——那是类型，不是词 |

**第 1 问为什么排第一**：AI 默认**把细纲全写**（"细纲里有，所以都要写"）。
一章装不下三件事——装三件的结果是三件都不深。**删掉一件，剩下两件才有空间长出代价。**
判据：如果划掉的那件让你心里不安，说明它才是你真正想写的 → **那就划掉另一件**。

**第 5 问为什么是"词"不是"句"**：词的约束比句紧一个量级。
"用环境开头"可以交差成"天色渐暗"；"第一个词必须是'铁'"则**只有一个解**。

**收尾一行（第六格）**：

```text
我放弃了：____
```

一句"这一章我本来想写 X，但没写"。**这是"活人感"唯一的上游生产点**——
人的文本里总有一处"作者忍住了"的痕迹，而 AI 的文本处处都是"我想到了所以我写了"。
事后补不出来：补出来的毛边是假的（`quality-constitution.md` 第四节那四条加法，只有第 1 次生成时才真）。

## 五、机制四：思考形式的四条禁令

这四条不是文风要求，每一条都对应一个具体的污染路径。

| # | 禁令 | 它在防什么 |
|---|---|---|
| 1 | **不用括号包裹内心独白**（"（心想：……）"），不用第一人称演角色（"我心想""我暗自"），分析性语言直接陈述 | 思考里的第一人称叙事会把**解释腔**带进正文。正文 AI 味的一大来源是"叙述者在解释人物为什么这样"——它常常是从思考里搬过去的 |
| 2 | **不在思考里写成品句子**（第 4 问要抄的那几个字除外） | 先在思考里把句子写好，正文就退化成"复述 + 修补"；而修补出来的句子是**平的最优解**。正文的句子必须在**声音样本**的直接影响下现长出来 |
| 3 | **不出现指标名、配额数字、评分、区间** | 这些词一出现，模式从"写"切到"审"。**检查是下一道工序的事**（`quality-constitution.md` 第三节：脚本用数字，写手用形态） |
| 4 | **不复述 brief / 细纲 / 任务**（"本章需要写的是……"） | 复述是零信息 token；而且每复述一次，注意力就从"这一章"退回"清单"。**清单已经在上下文里了，不需要念一遍** |

> **⚠️ 为什么禁令要配理由**：`prompt-engineering.md` 原则 3——**否定指令会反向强化**。
> 所以每一条都写成「**这里该做什么**」的形态（表格第 3 列是"它在防什么"，不是"不要 X"）。
> 纯禁令清单会让模型把注意力放在"别犯错"上，而**"别犯错"的落点正好是均值**。

## 六、机制五：起手式 —— 用「第一个决定」代替「第一个 token」

有一条流传的做法是：**规定思维链的第一个 token**（强制以 `<｜begin▁of▁thinking｜>` + 某个词开头），
理由是"起始字符决定 pattern"。

**原理是真的**：自回归模型对**前缀**极度敏感，思维链的前几十个 token 会把它锁进某一种策略族
（QA / 推理 / 写作 / Agent 各有不同的思维形状）。这正是报告附录 C 那句
「effort 指令 can directly change the reasoning strategy」的同一条机制。

**但作为工程手段它不稳定，三个原因**：

1. 对话模板由服务端渲染，`<｜begin▁of▁thinking｜>` 是**模板的一部分**，不是你能在 user 消息里"起始"的东西；
   多数 API 会把这类特殊 token 规范化或剥离。
2. 即使生效，也**只是条件化**，不是决定：它改变的是"从哪儿起步"，不改变"往哪儿走"。
3. 这正是它"抽奖"的原因——本项目对这类"靠运气"的机制有既定纪律：**不许当主闸门**。

**确定性替代（本协议采用）**：**不改 token，改第一个思考动作。**

> 思考的**第一件事**，必须是回答第 1 问：「这一章我不写 ___」。

- 同样的原理（起始内容锁定后半段），但**内容是可判的**：即使 pattern 没换，你也拿到了一个决定；
- 而且它把"删"顶到最前面——**先减后加**，是整条链路里最省的一次减法（改写阶段做减法贵十倍）；
- 落地位置：brief 的**最后一行**（见 `cards/card-thinking.md` 第五节）。
  **模型读完 brief 就开始思考，所以最后一行就是"第一个思考动作"。**

## 七、边界（诚实：它治不了什么）

| 能治 | 治不了 | 为什么 |
|---|---|---|
| **结构层**：删、代价、落点、开口、取景 | **语域与句子手感** | 语域由**样本**激活，思考产出的只是规则——而规则在强度表里是**弱**（`architecture.md` §7.1） |
| **"到处都在用力"**（每段都有钩子、每个细节都服务主题） | **"想出一个好句子"** | 好句子不是"想"出来的，是**在样本影响下长出来**的；在思考里想 = 得到一个可复述的句子（见禁令 2） |
| **解释过量**（正文替读者做结论） | **审美判断** | 哪个版本更好只有人能判（`quality-constitution.md` 六） |
| **空转**（想很久没成果） | **作者的个人经历** | 只有作者能提供（`author_shot` 槽位的存在理由） |

**还有一条反向风险**：开启协议后，如果**句长变长、比喻变多、段落变工整**，
说明多出来的 token **流进了正文而不是决定**。这不是协议生效，是协议被当成"更用力"的许可证。
**处置**：立刻停，回去只查一件事——六格里哪一格是空的。

## 八、怎么验证它真的有用（不许自我感觉）

本体系对"感觉有效"的既定态度是：**要么有退出码，要么有独立评委。**

### 8.1 主判据：盲测 A/B（唯一不由执行者打分的读数）

同一个 brief、同一个模型、同一章，**关 / 开**协议各写一稿 → 各抽 3 段 → 连同人类 3 段打乱 → 独立评委判"哪 3 段是人写的"。

| 读数 | 怎么读 |
|---|---|
| **人类置信度**（本书段被判"人" ÷ 3） | 开 > 关 = 有效；持平 = 这一章本来就不缺结构 |
| **评委可靠性**（人类段被判"人" ÷ 3） | **≤1 则本次作废**（评委不可信，读数不能用） |

⚠️ **只跑一章不算验证**：协议的靶子是"结构决定"，而结构问题的分布是跨章的。
**至少 3 章、且必须有 1 章是静场章**（静场章最考验"删"和"留"）。

### 8.2 辅判据：决策对账（看正文有没有兑现那六格）

把六格和正文并排放，逐格问"正文里有证据吗"：

| 格 | 对账问法 |
|---|---|
| 删 | 被划掉的那件事，正文里**真的没出现**吗（不是"提了一句"） |
| 眼 | 全章的比喻**是不是同一个感官来源**（抽 3 个比喻看取景位置） |
| 弃 | 失去的那个名词短语，正文里**有没有被具体说到** |
| 留 | 停的那句**是不是真的停了**（后面有没有跟着解释） |
| 开 | 第一句第一个词**是不是定的那个** |
| 不甘心 | —（这一格不对账，它是给下一章留的） |

这一项**必须由独立子代理做**（`guides/grill.md` 的评委），理由同 `deai-entry.md` 的第一条禁令：
**执行者会替自己的选择辩护**。

### 8.3 反例信号（出现任意一条 = 协议被误用）

- 正文变长、变华丽、段段有钩子 → token 流进正文
- 思考里出现"这一章要确保……"「应该够了」→ 滑回审稿式
- 六格里有两格以上是空的 → 协议被当成仪式
- 改稿轮次上升 → 决定的都是错的（罕见；多半是第 1 问删错了件）

## 九、和既有体系的关系（别造平行系统）

这份协议**不新增目标、不新增判据、不新增闸门**。它只做一件事：
**把已有的东西顶上移到它们真正被决定的那一刻。**

| 已有机制 | 它管什么 | 协议把它顶到哪儿 |
|---|---|---|
| `quality-constitution.md` 五条承诺 | 交付前对账（声音/具体/代价/冗余/未完成） | **决策五问是它的生成端**：1 删→冗余；2 眼→具体；3 弃→代价；4 留→未完成；5 开→声音。**对账在交付前，决定在动笔前，中间不许互相替代** |
| `故事账` 五格（L1） | 这一章该不该存在 | 故事账是**写进文件**的（跨章可比）；五问是**在思考里跑一遍**的（逐章现场）。**同源，不同粒度** |
| `craft_cards` 3–4 张 | 怎么写（句子层） | 卡是**照着写**的；协议是**写之前定**的。**先定后写**，顺序不许反 |
| `deai-entry.md` 五步 | 初稿之后怎么改 | 协议**减少**它要改的量，**不替代**它——AI 写出来的初稿一定不达标这条不变 |
| 口吻宪法 / 人类范本 | 语域（最强杠杆） | 协议**不碰**语域。**思考买结构，材料买声音** |

## 十、一句话交接

> **不要问模型"想得更用力一点"，要告诉它"这一章你决定不写什么"。**
> 前者买来更多的检查，后者买来更少的文本——而**更少的文本，才是人写的那个样子**。
