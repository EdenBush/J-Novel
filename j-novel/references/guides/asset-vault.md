# 资产沉淀库（Asset Vault）

**让体系越用越聪明。** 每写完一部作品，把有价值的资产沉淀下来——下一部作品就不再从零开始，而是"站在旧作品的肩膀上"。

资产库是**用户级**的（跨作品共享），位置：`~/.workbuddy/skills/j-novel/assets/`（或用户指定的资产目录）。每部作品结束后更新。

> **从 reasonix-novel 迁移**：若你在旧技能下已积累过资产，把 `~/.workbuddy/skills/reasonix-novel/assets/` 整个目录复制到 `~/.workbuddy/skills/j-novel/assets/` 即可，格式完全一致。两边不共享——新作品一律读 j-novel 的资产库。

---

## 四大资产

### 1. 文风资产库（style-assets.md）

**存什么**：每部作品确认版中最代表文风的片段（150-250 字）+ 文风基因描述 + 读者反馈"拍案瞬间"的段落。

```markdown
## [作品名] 文风档案
- **文风基因**：叙述者口吻 / 内心独白处理 / 对话节奏 / 感官偏好 / 收尾方式（各 1-2 句）
- **锚点片段**：[引用 150-250 字确认版正文]
- **读者反应**：[哪类读者对哪段反应最强烈]
- **适用题材**：[这部作品印证了这种文风适合什么题材]
```

**怎么用**：新作品采访第 7 轮（风格与语言）时，向作者展示"你以前的作品是这样写的"，快速定位风格；细纲的文风锚点示例可以引用历史锚点作为起点。

### 2. 教训库（lessons-learned.md）

**存什么**：每部作品的失误与修复——问题 → 根因 → 解法 → 验证结果。

```markdown
## [问题类型]：[一句话问题]
- **作品**：[哪部作品的哪一章]
- **根因**：[为什么会发生（如：大纲太简略 / 并行无台账 / 采访没磨透钩子）]
- **解法**：[怎么修的（如：补写前锚点检查 / 加状态台账）]
- **验证**：[修完效果]
- **预判**：[下个作品如何提前规避]
```

**怎么用**：
- 采访/规划/写作前，扫一眼教训库——"这个坑我踩过，这次别踩"
- 卷末复盘（volume-review.md）的 P0/P1 问题，解决后都入教训库
- 教训库是体系自己的"病历本"，越积越厚，体系越稳

### 3. 灵感库（ideas-vault.md）

**存什么**：任何值得留存的创作火花——

- 采访中用户提到但没用的设定（"以后再写"
- 卷末复盘里读者"拍案瞬间"揭示的爽点类型
- 作者随口说想写但还没写的题材方向
- 体系运行中发现的题材-结构-技法的最佳组合

```markdown
## [灵感标题]
- **一句话**：[这个 idea 的核心钩子]
- **为什么记下**：[触发场景 / 读者反应]
- **可发展的方向**：[题材/结构/技法的初步判断]
- **状态**：[未用 / 已用作XX]
```

**怎么用**：作者说"不知道写什么"时，从灵感库给 3 个候选；采访冷场时，灵感库可以当"题材题库"。

### 4. 作品档案库（works-archive.md）

**存什么**：每部作品的元数据 + 质量报告摘要（`quality-scorecard.md` 的全书质量报告）。

```markdown
## [作品名]（[完成日期]）
- **规格**：[题材 / 章数 / 总字数 / 写作模式]
- **质量报告**：[平均分 / 最强维度 / 最弱维度]
- **读者反馈摘要**：[普通/挑剔/同行 各一句]
- **资产贡献**：[入文风库 X 段 / 入教训库 X 条 / 入灵感库 X 条]
```

**怎么用**：
- 新作品选题时对比历史作品数据——"你的悬疑平均 74 分，言情只有 62 分，这次写悬疑胜率高"
- 追踪成长曲线——平均分是否逐部上升，最弱维度是否在改善
- 这是体系给作者的"成绩单"，也是给体系自己的"训练数据"

## 沉淀时机

| 时机 | 动作 |
|------|------|
| 每卷结束 | 卷末复盘后，把失误入教训库、强片段入文风库 |
| 全书完成 | 作品档案库登记 + 质量报告入档 + 清理无用资产 |
| 采访冷场 | 从灵感库给选题候选 |
| 新作启动 | 扫一眼教训库 + 查历史作品数据 + 从文风库找风格起点 |

---

## 维护规则

- **只存可复用的**：一次性信息（某章的临时设定）不存
- **标注来源**：每条资产都要标"来自哪部作品、什么场景"，保证可追溯
- **定期清理**：每年或每 5 部作品，清理过时/无效的条目（保留质量高的）
- **资产库是用户财产**：作者可随时查看、修改、删除自己的资产
