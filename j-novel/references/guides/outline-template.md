# [小说名称] 大纲

> 本文档是 Phase 3 每章创作前必读的规划依据。写完一章后，在末尾「章节摘要」区追加 300-500 字摘要，供后续章节保持连贯。
>
> **超长篇（2000+ 章）必须先读 `guides/volume-arc-planning.md`**——本文档的「卷规划」和「章节规划」分别对应它的"卷层"和"章节层"，中间的"弧层"由卷规划里的弧拆分承接。别试图一次性把 4000 章逐章列出来。

## 锁死清单 vs 留白清单（超长篇第一原则）

> 详见 `guides/volume-arc-planning.md` 第三节。**分不清锁死和留白，超长篇必然塌方。**

### 锁死清单（地基，采访阶段定死，此后只增不改）

1. **核心卖点（金手指）**：[主角凭什么在这个世界玩得动？]
2. **主线终极悬念**：[贯穿全书、到结局才解的那根线]

|---|---|---|---|---|
| [例：某女主感情线] | 评论提及率 | 明显高于其他 | 升官配，加戏 | 降背景板 |
| [例：反派定位] | 读者同情度 | 同情高 | 走悲剧镜像 | 走纯反派 |

## 卷规划（只详细规划下一卷，写一卷规划一卷）

```markdown
## 第 N 卷：[卷名]（第 X–Y 章，约 Z 章）

- **卷主题**（一句话，这 Z 章在讲什么）：
- **主角目标**（卷开头想要什么 → 卷尾得到/失去什么）：
- **卷内冲突**（主要对手 / 核心障碍）：
- **卷末高潮**（这卷最高潮的一场戏）：
- **卷间钩子**（钩着读者进下一卷的悬念）：
- **本卷新登场人物**（及其作用）：
- **本卷弧拆分**（3–5 个弧）：
  - 弧1：[弧名]（第 X–Y 章）
  - 弧2：[弧名]（第 X–Y 章）
  - ...
```

> **弧拆分的每个弧，写清：弧目标 / 事件链五步（目标→阻碍→转折→高潮→结果）/ 爽点分布（标章号）/ 弧末钩子。** 完整弧模板见 `volume-arc-planning.md` 第五节。**弧才是指导写作的真正单位，爽点间隔超过 5 章读者就跑。**

## 市场验证计划（前 10–30 章的真正目的）

- **要验证什么**：[核心卖点是否成立 / 节奏是否抓人 / 哪些角色受欢迎]
- **拿什么数据**：[追读率 / 完读率 / 评论关键词 / 收藏订阅]
- **验证后怎么改**：见 `volume-arc-planning.md` 第六节决策表；结论写回 `05-创作台账.md` 的 Open 区（**不是写"看市场反馈"，是写"验证什么+阈值+两种走向"**）。

## 章节规划（只滚动到下一批 5–10 章）

| 章节 | 标题 | 品质 | 核心事件 | 承接上章 | 开场类型 | 章首引子(新起型) | 悬念钩子 | 出场人物 | 场景列表 | 情感基调 |
|-----|------|------|---------|---------|---------|---------|---------|---------|---------|---------|
| 第1章 | | | | — | 新起 | | | | | |
| 第2章 | | | | | 续接(默认) | | | | | |
| 第3章 | | | | | 续接(默认) | | | | | |

（品质：⭐ 品质锚点章 / ● 普通推进章）

> **⚠ 详细度硬性要求（本章规是防"上文不接下文"的第一道防线）：**
> 1. **核心事件必须 2-3 句**，写清楚"发生了什么 + 为什么发生 + 造成什么后果"——一句话的"核心事件"是断档和 BUG 的温床，禁止
> 2. **承接上章必填**（第 1 章填"—"除外）：写清本章开头接的是上章结尾的哪个画面/悬念/情绪
> 2.5. **开场类型必填**：每章标「续接 / 新起 / 跳接」。默认「续接」——从上一章最后一幕同一时空、同一情绪接着写，**不写章首引子**；仅当换地点/时间跳/切 POV/刻意断场景才标「新起」并填「章首引子」列。这是去 AI 味（避免每章都炸）与保连贯（避免章章被剪断）的关键。详见 chapter-craft.md「续接优先」
> 3. **悬念钩子必填**：本章结尾要立什么新悬念？（参考 hook-techniques.md 招式库）
> 4. 每个出场人物，在本章结束后**状态要有变化**（位置/情绪/关系/认知/能力，至少一项），并把变化记入下方「人物状态变化表」
> 5. **每章至少回应一个旧悬念、立一个新悬念**，做到悬念闭环
> 6. 大纲字段不全时，写作阶段禁止动笔（Phase 3 步骤 1 强制）——先补规划再写

## 人物状态变化表（逐章登记，连续性防护）

| 章节 | 角色 | 本章开始时状态 | 本章结束时状态 | 变化原因 | 落地 |
|-----|------|--------------|--------------|---------|------|
| 第X章 | [角色] | [位置/情绪/关系/认知] | [变化后的状态] | [什么事件导致的] | ? |

> **「落地」列 = 三态标记（铁律五）**：`✓` 已落正文（标注章号）/ `?` 仅规划 / `✗` 已否定（标注推翻章号）。
> **默认无标记 = `?`。标 `?` 的条目，下游章节不得当作已发生的事实来写。**
> 每章写完收尾时，把该章真正写进正文的变化从 `?` 改成 `✓（第X章）`。
