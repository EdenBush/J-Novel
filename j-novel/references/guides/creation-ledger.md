# 创作台账：Agent 的外接工作区（J-Novel 核心）

**这份文件存在的唯一理由：长跑会静默丢约束。**

连写十几章之后，会发生三件**不会报错**的事——文风锚点被悄悄换掉、某条伏笔"写过了"和"打算写"记混了、排班专项到底查没查全凭印象。它们不报错，只会在第 20 章变成"这本书怎么读着不对劲"。

已有的 `03-状态台账.md` 记的是**故事里发生了什么**。这一本记的是**你知道什么**。

---

## 它和另外两本的区别（不要混）

| | 02-写作计划.json | 03-状态台账.md | **05-创作台账.md** |
|---|---|---|---|
| 回答什么 | 还剩什么没做 | 故事里现在发生了什么 | 我已经确认了什么 / 不确定什么 |
| 性质 | 待办清单 | 故事内状态 | 认知状态 |
| 谁读 | 每章启动检测 | 子代理写前读起点、写后写回 | **主编每个 seam 自己重读** |
| 能不能删 | 不能 | 不能 | 不能（但可以随时重写 Goal/Next） |

三本谁也替代不了谁。特别是：**台账不是待办清单**，别把"第 8 章还没写"写进去——那在 JSON 里。

---

## 模板

```markdown
# 创作台账（每次 seam 重读）

最近重读章号：第X章

## Goal
一句话。本阶段（或本批次）"完成"意味着什么，写得能判断自己到没到。

## Core
（≤2 条。第三条想进来必须先换掉一条，且换的时候要说出声）
- 文风锚点 —— [一句话描述 + 它为什么重要]
- 本卷张力 —— [一句话描述 + 它为什么重要]

## Verified
（编号追加，永不改写。每条写清依据，即它出现在哪一章）
- ✓01 [已落正文的既成事实]（依据：第X章）
- ✓02 [已落正文的既成事实]（依据：第X章）

## Open
（每条带"什么能终结它"）
- ?01 [还不确定什么] —— settled by: [什么能终结它]

## Next
单一动作，永不为空。
```

**字段规则：**

| 字段 | 规则 |
|---|---|
| **Goal** | 任务移动时更新。写得能判断"到没到"——"把第二卷写完"不合格，"第二卷 8 章全部 completed 且节奏诊断无风险标记"才算 |
| **Core** | **最多两条。** 超过两条就不是枢纽，是清单。剩下的写进 Verified 或 Open |
| **Verified** | **编号追加，永不改写。** 想改就标 `✗` 再开一条新的——改写会让回滚失去地址 |
| **Open** | 只在记录到 checkpoint 时关闭，**编号永不复用** |
| **Next** | 永不为空。**没有下一步动作的台账，是已经停用的台账** |

---

## SWAP：换掉一条 Core 时必须说出口

第三条想挤进来时：

1. **把离开的那条写回 Verified 或 Open**，写完整到能重新加载（不是一句"文风锚点"就完事）
2. 换上新的
3. **说一句换了什么**：`放下"卷二信息差"，拿起"卷三背叛倒计时"**

**第三不说是静默丢弃（silent drop）。** 它是"某个约束在任务中途悄悄停止生效"的头号原因。对应到小说：文风锚点在第 8 章被悄悄换掉，到第 20 章全书不是一个人写的，没人说得清从哪一章开始的。

说出声一次只要半句话。不说，代价是一本书。

---

## 三个自检问题（每个 seam 问一遍）

1. **我现在能说出舞台上的那一两条是什么吗？** 说不出，就是过载了——按重要性排序，留前两条，剩下的写下来。
2. **我有没有在第二次推导同一件事？** 有的话，它第一次就该被写进 Verified。现在写，然后继续。
3. **台账上一次被读是什么时候？** 如果答不上来，它已经死了。

---

## 常见误用

| 误用 | 后果 | 正解 |
|---|---|---|
| **建了不读** | 比没有更糟 —— 它看起来像状态 | 铁律六：每章 seam 强制重读。Phase 4 查"最近重读章号" |
| **写成工作日志** | 五段变成流水账，没人会重读 | 台账只放**状态**：已确定 / 待定 / 下一步。过程放内寄存器，草稿放章节文件 |
| **写成待办清单** | 和 02-写作计划.json 重复，两边不同步 | 待办进 JSON；台账只放"现在已知什么" |
| **Verified 写满推测** | 台账失去意义，三态铁律形同虚设 | Verified 只放**已落正文**的；推测进 Open，带 `?` |
| **Core 塞五条** | 每条分到五分之一的注意力，等于没有 | 两条。其余进 Verified / Open，按章节重新加载 |
| **Next 写"继续写第 9 章"** | 太长，看不出第一步 | Next 写**第一个动作**："读第 8 章结尾 + 台账，判定第 9 章开场类型" |

## 没有文件系统时

台账活在对话里，每个 seam 重述五段。纪律一样，介质不同。

**页面从来不是重点，重读才是。**
