# 标题生成工具箱

继承自 Chinese Novelist 的标题生成指南。用于 Phase 1 采访收尾（标题确认）——不要只让作者"想个标题"，要生成候选让他选。

---

## 一、题材-风格映射表

| 题材 | 风格方向 | 示例 |
|------|---------|------|
| 悬疑/推理 | "谜、局、消失的X" | 《消失的第十一天》 |
| 言情 | 诗意意象、四字 | 《你是迟来的欢喜》 |
| 奇幻/仙侠 | "录/传/纪/诀/歌" | 《九州风雷录》 |
| 科幻 | 技术意象 + 悖论 | 《群星坠落之前》 |
| 历史/古风 | 年代 + 地名锚点 | 《长安十二时辰》 |
| 都市 | 口语化 + 反差 | 《都挺好》 |
| 惊悚 | 暗示未完成句式 | 《别回头》 |

跨题材时，优先核心冲突的风格。

---

## 二、五大创作技法（每次生成必须用不同技法）

1. **核心冲突提炼法**：从主线冲突里提炼关键词。《她与她的最后一案》
2. **主角命名法**：以主角名或主角特质命名。《林深时见鹿》
3. **意象隐喻法**：用一个意象承载主题。《被风吹走的信》
4. **反差法**：两个矛盾元素并置。《温柔的杀人犯》
5. **悬念留白法**：暗示有秘密。《她没说的事》

---

## 三、质量标准

**必须满足**：
- 字数 2-8 字为主流，朗朗上口
- 原创、不撞常见书名
- 同一批候选用**不同技法**生成（防雷同）

**必须避免（AI 套路化黑名单）**：
- "XX之道 / XX的觉醒 / XX纪元 / XX崛起 / 重生之XX"
- 过于笼统的单字词（《风》《夜》——除非极其精准）
- 直接剧透（标题把反转说完了）
- 标题党（与内容不符的夸张）

---

## 四、生成流程（Phase 1 收尾用）

1. 从采访共识中提取创意元素（核心冲突、主角、意象、主题、关键场景）
2. 按题材匹配风格方向，用至少 3 种不同技法生成候选
   - 简单故事：3 个候选；复杂跨题材：5 个候选
   - 每个候选附一句话理由（用了什么技法、指向什么钩子）
3. 用选项展示给作者选，可"重新生成"迭代（最多 5 轮，之后提示"可直接输入你心中的标题"）
4. 确认后：标题进入 Phase 2，命名项目目录、写入写作计划 JSON 与大纲文件头
