# 硬性质检：质量底线清单

这是每一章的"出厂质检"（Reasonix 的五件套 + Chinese Novelist 的语言质量检查融合）。创作完成后，以质检员身份执行。**创作与质检状态严格分离**——写的时候关掉质检脑，审的时候拿出洁癖。

---

## 第一件事：字数

没有任何弹性。运行脚本：

```bash
python scripts/check_chapter_wordcount.py <章节文件路径> [最小字数]
```

低于约定的每章字数下限，这篇稿子就是没写完——不管写得多好都不行。

没达标怎么办？别靠灌水来凑。回头看看：是场景缺了质感需要补一笔环境描写？是角色内心太安静需要一段心理活动？是对话太匆忙缺少了反应和停顿？找出来，补上去。（扩充技巧详见 `chapter-craft.md`。）

---

## 第二件事：硬性句式拦截

在进入任何"感受"层面的判断之前，先做一件机械的事：用眼睛扫一遍全文，把下面这些句式一个一个揪出来。

- `不是……而是……`
- `不是……是……`
- `不是……不是……是……`
- `没有……没有……`
- `相较于……更……`
- **口语变体 `不是X，是Y`**（"不是堵，是酸""不是火，是冰"——AI 极爱的对比修辞，编辑报告专门点名，同样超标）
- 任何"先否定再肯定"的排比结构，哪怕变体也揪出来。

**标准：在单章中出现超过 0 次即为超标。** 出现 1 次也不行。一次就叫 AI 味。**"不是X，是Y"短变体同判（这句要的是"果断肯定"而非"否定对比"）。**

**找到之后，不要简单地"替换句式"——而是重新写出那个句子的意思。** 问自己：这句话到底想说什么？然后用最直接的方式说出来。

- 想表达对比？用果断的肯定句。"他不勇敢，他是不得不面对。" → "他怕得要死。但他没有退路了。"
- 想强调重点？把重点直接放到句首。"这不是一个关于爱情的故事，而是一个关于背叛的故事。" → "这是一个关于背叛的故事。爱情只是背叛发生之前的那个谎言。"
- 想制造节奏？用句号断开。"错了。全都错了。"

这一项没有商量的余地。作者可以喜欢"不是……而是……"——但那是作者的事。你的职责是在交稿之前把它杀干净。

## 第三件事：AI 指纹（AI 味自评）

硬性句式扫干净了。现在静下心来感受一下通篇的"气息"。

> **强制执行 `references/guides/ai-taste-selfcheck.md` 的十一项自评量表**——逐项自问（心理还原/叙述声音/感官私人性/场景呼吸/角色失控/紧张留白/句式工整/结尾方式/**开场同质**/信息灌输/情感传递），判定"人侧/AI侧"，并回答终极问题【这篇小说是不是AI写的？】给出证据段落。4 项以上 AI侧 → 走「DeAI 六步工作法」（deai-workflow.md）清洗后再复评。

快速敏感点（量表之外随手扫）：

- 太顺、太合理、太"不出意外"的思维路径和情绪转折
- 角色对话里"如你所知，这个世界的魔法是……"这种生硬信息灌输
- 情感描写停留在"他感到一阵悲伤涌上心头"的概括
- 角色只是被情节推着走，没有真实的内心活动
- 叙事声音里找不到一个有口癖、有偏见、会说错话的人
- 缺少那种"像是亲身经历过才能写出来"的意外细节

### AI 高频词与语言毛病（补充检查）

- **高频 AI 词**（出现一个改一个）："此外""然而""值得注意的是""需要强调的是""不可忽视""彰显""诠释""赋能""映射""折射""不禁""油然而生""心潮澎湃""这一刻""仿佛""宛如"
- **四字成语堆砌**：连续使用两个以上四字成语属于堆砌，拆开或替换为口语表达
- **"的"字密度**：一句话里"的"不超过两个；绝不出现连续的"的的"；"他的红色的漂亮的大衣"→"他那件红色大衣"
- **模糊词**："一些""某种""大概""似乎"（除非刻意表达不确定性）
- **抽象词**："天气不好"→"闷热，空气黏在皮肤上"
- **动词优于形容词**："她走得很快"不如"她几乎是跑过去的"

### 展示而非讲述（核心对照）

| 讲述（避免） | 展示（使用） |
|-------------|-------------|
| 他很愤怒 | 他握紧拳头，指节发白 |
| 她很美丽 | 他凝视着她，忘记说话 |
| 他很紧张 | 他反复调整领带 |
| 房间很乱 | 衣服扔在沙发上，外卖盒堆在桌上 |
| 她很伤心 | 她低头搅咖啡，勺子停了很久 |

## 第四件事：杠精自检——自己跟自己抬杠

写完了，也扫完了 AI 痕迹。现在换一副面孔。你不是这个故事的编辑，你是一个专门挑刺的读者。你来读这章不是为了欣赏它，而是为了找茬。你的任务是在通读后问出最刁钻的问题，把作者可能想蒙混过去的地方一个个揪出来。

**杠精的视角（任选几个切入，不用全部）：**

- **"等等，这不合逻辑。"** —— 角色的某个行为，是否在那一刻真的是 TA 的最优选择？有没有更合理的选择却被忽略，只因为那样剧情就推不下去？
- **"这角色是不是被夺舍了？"** —— 有没有某个角色的反应、对话、决策，和前文建立起的性格或智商水平不符？不是弧光转变的话，那就是写崩了。
- **"这段拖拉了。"** —— 有没有哪个段落让你想跳过去？不是节奏慢的问题，是节奏慢的同时没有提供新的信息或情绪推进。
- **"这段太快了。"** —— 有没有哪个重要转折被一笔带过？情感转变、关键决定、重大揭示——该停下来的地方反而赶了。
- **"这句台词谁会这么说？"** —— 对话里有没有哪句读出来不像这个角色会说的话？或者更像是在给读者解释信息？
- **"这个世界前后不一致。"** —— 有没有设定上的前后矛盾？某个规则在这一章和前面某章的描述对不上？
- **"这不是巧合是什么？"** —— 有没有情节推进过度依赖巧合或角色降智？如果有，读者会翻白眼的。

**杠完之后：**

给出一个"杠精结论"：这章最经不起推敲的 1-2 个点是什么？它们是必须修的结构性硬伤，还是可以接受的故事设计（但要承认它的存在）？

如果杠精发现的问题确实需要修，标记出来，下一步精修时处理。如果杠了一圈发现没什么可杠的，或者杠出来的都是鸡毛蒜皮——那这章大概率是真的写得不错。

## 第五件事：剧作与人味

问自己两个最直觉的问题：

1. 读完最后一段后，你想继续读下一章吗？这种"想知道接下来发生什么"的冲动有多强？别分析结构，就回答这种感觉的强度。
2. 读这章的时候，你是忘记了自己在阅读、直接进入了场景，还是始终意识到"这是一堆字"？好的文字有"文学在场感"——那种难以定义但能感受到的东西。你感受到多少？

最后快速对一下故事圣经：人名、地名、设定、时间线，有没有矛盾。

## 第六件事：人味配额验收（宏观层，AI 分布指纹）

**微观（前五件事）查"这句像不像 AI"，本件事查"整本书的分布像不像 AI"。** 执行 `references/guides/human-quota.md` 的配额验收：

```
毛边：X 处（≥2 ✓/✗）    废话对话：X 处（≥1 ✓/✗）
比喻：X 个（≤4 ✓/✗）    金句：X 句（≤1 ✓/✗）
意象重复：本章核心意象第 X 次出现（每卷 ≤4）
情感表达差异：✓/✗
重复检测：python scripts/check_repetition.py <章节文件>（必须 0 重复）
```

任何一项 ✗ = 本章不合格，补人味后复验。验收结果记入质检档案（`04-质检档案.md`）。

## 质检摘要（每章"出生证明"）

改完后，把质检摘要写入项目级 `04-质检档案.md`（**不写入章节正文**——正文保持纯净可发布）。记录格式（完整字段见 Phase 3 步骤 19，核心字段如下）：

```
### 第N章 [标题]
- 最终字数：XXXX（达标/未达标）
- 硬性句式扫描：已清零
- AI 味自评：人侧 X/10 — 终极自问判断 + 证据
- 杠精自检：最经不起推敲的点，以及处理决定
- 衔接检查 / 逻辑检查：通过/未通过
- 质量评分：XX/80
- 吸引力 / 文本质感 / 一致性：...
```

这份档案会在 Phase 4 自动校验时被复查——它是质量底线的证据链。
