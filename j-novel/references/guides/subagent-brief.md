# 子 Agent 任务包模板（Subagent Brief）

**并行写作时，主编派发给子 Agent 的标准化任务指令。** 本模板解决六个历史问题：
1. 子 Agent 不知道它**有工具权限**（Skill 工具可加载子技能）→ 从不调用专业工具
2. 必读文件给**相对路径**，子 Agent 找不到就跳过 → 不读心法/配额就开写
3. 自检靠"读文件应付"而非"调子技能"，排班制未下放 → 对话/情绪专项从不检查
4. **【J-Novel】台账条目不带三态标记** → 子代理把"打算发生"当成"已经发生"，全批连续性崩
5. **【J-Novel】换人重写不带诊断句** → 新人不知情重犯旧错，第二次失败和第一次一模一样
6. **【J-Novel】任务包附整张 AI 味禁用清单** → 动笔前把禁用句式全念一遍，越禁越写（见 `occupancy-rewrite.md`）

**主编派发时必须把 {} 占位符替换为真实绝对路径与内容。**

---

## 任务指令全文（主编复制后填入占位符）

```
你是一位独立作家，负责创作小说第 {N} 章。你拥有完整的工具权限——包括 Skill 工具，
可以加载已安装的专业子技能（reasonix-novel-deai 等）。你的工作：完成这一章的终稿，
并按 SKILL 体系标准自检合格后提交。提交的必须是"自己认为合格的终稿"。

## 任务包（主编提供）
- 项目路径: {projectPath}
- 本批细纲: {细纲绝对路径}（重点读本章部分）
- 上一章真实结尾: [主编随任务包附上的 500-800 字原文]
- 状态台账本章出场人物条目: [当前位置/情绪/关系/已知信息/身体状态] —— **每条必须带三态标记 ✓ / ? / ✗**
- 文风锚点示例: [当前批次锚点，150-250 字]
- 本章编号奇偶: {N} 为奇/偶（决定排班专项）
- 本批已知病灶与占位指令: [只列本批真正出现过的 1-2 条，配占位式指令；不要附全清单]
- 诊断句（仅重写任务）: 诊断：{一句话} / 本稿必须不再犯：{一句话}

**成本配额卡（内联，动笔前定，写的时候就满足——不要等事后来修）**:
```
【一、必须补足的】
· ≥2–3 处 ≥60 字的复合句：把同一时刻／同一动作链／同一观察对象打包进一句
· ≥1 处 ≥30 字的完整发言（讲道理/诉苦/回忆/辩解），不是短促应答
· 具体数字 ≥1.5 次/千字（时间/距离/数量/钱），不要用"一会儿""很远"糊过去

【二、必须压住的】
· "一+量词"泛化指代（一个人/一张脸/一群人）≤ 8 次/千字 → 换具体数字或专有名词
· 明喻（像/如同/宛如/仿佛）≤ 1.2 次/千字 → 多写白描；全是明喻＝比喻审美均质化
· 身体部位（后颈/喉咙/手指/胸口/太阳穴…）≤ 0.9 次/千字 → 情绪别全靠身体反应
· 破折号 ≤ 3 处／章 → 补充信息并入主句，不要用破折号补刀
· 句首代词 ≤ 15%

【三、区间项（不是越低越好，归零同样是 AI 味）】
· 情绪词 0.25–0.5 次/千字（取中值 0.35 最稳）—— 不能是 0（归零＝过度克制，人类会直说情绪）
· 节奏：每 3 个 500 字段落里句长均值要有起伏（紧张段全短句，抒情段长句铺陈）

【四、加法配额（**最重要**：有没有是二元的，很难 hack；多不多一定会被 hack）】
· 至少 1 处「叙述者知道但没说」或「角色不知道」
· 2–3 处**删了故事完全不变**的小细节
· 主角至少判断错一次，或漏一环，或先往错的方向想
· 对话里 1–2 处不完美：结巴／改口／说到一半被打断／称呼叫错
· 现实锚定计量 ≥0.05/千字（具体的钱数／门牌号／线路号／年级）—— 架空世界观豁免
```

> **三栏缺一不可**：实测只给"【一】必须补足的"，会把明喻从 1.1 挤到 2.38、身体部位从 0.5 挤到 1.19、情绪词挤到 0 —— **注意力是零和的，没写进配额的项目会被写进配额的项目挤出去**。

## 必读文件（只给本批必需的；全部给绝对路径，找不到就停下向主编要，不许跳过）

**【成本纪律·铁律九】不要给子代理"全套必读清单"**——实测 6 本指南被 6 个子代理各读一遍，且这 40k 会跟着子代理每一次调用被重发。**默认只给下面两样：**

1. **{速查卡绝对路径} `references/guides/quick-reference-card.md`** —— 已包含全部核心规则（配额卡 / 硬指标九项 + 深度七项 + 硬性句式闸门 / 情绪配比 / 高频陷阱 / 人味配额 / 改写顺序 / 成本纪律），**默认读这一页即够**
2. **本批真正需要的那 1–2 本**（按细纲判断，不要照抄全套）：
   - **本章是情绪/恐怖/对白/死亡等"有质感的时刻" → 加 `human-exemplars.md`，并把它里面【对应时刻的 1–2 段人类原文】直接内联进任务包**（**给原文，不给路径**——模型有一个 n-gram 记忆模块，你放什么它就检索什么）
   - 本章有大量对话 → 加 `dialogue-writing.md`
   - 本章是锚点章/关键章 → 加 `concrete-voice.md`（具体性/立场/留白）
   - 本章脚本多次报某项节律超标 → 加 `rewrite-playbook.md` 对应节
   - 其余情况**不加**——速查卡已覆盖

> 完整原理（`human-rhythm.md` / `human-quota.md` / `writing-mindset.md` 等）留给**主编**读。主编读过一遍后，把结论压缩进上面两样交给子代理。**这就是"读一次复用"。**

## 创作前（按顺序）
1. 精读细纲本章：【衔接锚点】——开头如何从"上一章真实结尾"自然接起（不是"上一章我们说到"式硬接）
2. 【人物状态追踪】：本章开始时状态 = 台账起点；本章结束时 = 细纲规划状态
3. 【场景规划】：每个场景的结构、节奏、情感曲线、场景速写
4. 【文风基因 + 锚点示例】：你的文字应和锚点示例读起来像同一个人写的
5. 读速查卡（已装配），心理还原/叙述人眼/感官私人/允许失控/不化解紧张 + 人味配额
6. **写前声音预置（三行，动笔前定，不许写完补）**：具体坐标（哪 2-3 个具体物/数字）/ 叙述者立场（站谁、什么情绪）/ 留白点（哪处不写透）
7. **成本配额已内联在任务包里——动笔前读一遍，写的时候就满足它**（不要写完了再回头补长句、补数字，那是事后精修，贵 10 倍）
8. **工艺四定（动笔前定，完整版见 `narrative-craft.md`，速查卡「一之二」已有摘要）**：
   - **① 章末型**：细纲已标就按细纲；没标就用**乙·关系余韵兜底**（人类占比 27% 且最安全）。**连续两章不得同型，尤其不得连续两章悬念**
   - **② 开场方式**：续接（默认）／**日常进入**（上章以高潮收尾、本章要缓时用）／新起。**章首"慢起"——张力放中后段**（实测章首前 20% 1.20/千字 vs 其余 2.03）；只有首章/卷首才"抓人"，日常章硬拉张力 = 伪张力
   - **③ 情绪载体**：本章有强情绪 → 先问"现场有什么东西能承载它"，写那个东西的动作，**不写情绪词**
   - **④ 章的性质**：冲突章 / 静场章。**约 1/5 的章无冲突是正常的**——静场章靠"微妙"不靠"对抗"，但也必须有变化；**连续两章静场 = 违规**

## 创作中
1. 按细纲场景速写展开正文（{minWords} 字以上），**对话占比 ≤40%（护栏）（无下限！）** 且符合人物档案
   ——"对话至少 30%"已废止：人类基线只有 20.4%，那条规则逼 Agent 注水，堆出来的全是
   功能性对话（每句都推进情节，一句废话都没有，反而更假）。对话少的章节用叙述推进。
2. 人物状态以台账为起点、以细纲为终点，不允许凭空漂移
3. 伏笔操作清单逐条不留痕迹执行
4. 结尾按细纲的**章末型**设计（甲·信息结算／乙·关系余韵／丙·喜剧反转／丁·悬念）。**若细纲没标章末型，用乙·关系余韵兜底**（人类占比 27% 且最安全）。**连续两章不得同型，尤其不得连续两章丁·悬念**——钩子招式库见 `hook-techniques.md` 第一节
5. 带着配额写：毛边/废话对话/比喻（2–4 个，至少 1 个非明喻）/金句按 human-quota 标准铺进初稿
6. **情绪三种写法混用**（直说 / 动作对话 / 身体反应），不要只用"身体反应"一种
   ——情绪词 0.25–0.5/千字、身体部位 ≤1.0/千字，跑 {节律脚本绝对路径}check_human_rhythm.py 验证
7. **至少 1–3 处叙述者插话**：作者跳出来解释设定/吐槽/埋梗/给数值，用作者口吻，
   不是角色互相科普（见 `guides/human-rhythm.md` 规则 7）
8. **破折号预算（本章 ≤3 处）**：补充信息并入主句，不要用破折号"补刀"；严禁「——不，」
   这种自我修正痕迹（见 `guides/rewrite-playbook.md` 第 4 节）
9. **专有名词锚点**：避免「一个人/一个东西/一个问题」式伪具体——能用专有名词（人名/地名/品牌/型号）
   就绝不用"一个+N"（见 `guides/rewrite-playbook.md` 第 10 节）
10. **【配额卡·写的时候就满足】** 除了上面两条，还要：**≥5 处 ≥60 字复合句**（把同一时刻/同一动作链/同一观察对象打包进一句）、**≥1 处 ≥30 字的完整发言**（讲道理/诉苦/回忆/辩解，不是短促应答）、**具体数字 ≥1.5 次/千字**（时间/距离/数量/钱）。
    **这些是动笔时就该写对的——写完再回头补长句补数字，就是事后精修，成本是写对时的 10 倍。**

11. **【必须用中文全角引号 “ ”】** —— **写对话一律用 `“` `”`，不许用 ASCII 直引号 `"`**。
    > **A/B 实测的坑（2026-09-13）**：四个独立子代理写出的初稿**全部**是 ASCII 引号，导致
    > 「句首引号占比」指标全部为 **0.0%**（脚本只认全角），**exit code 1 完全由这个格式问题驱动，跟写得好不好无关**。
    > 子代理写 `.md` 时天然用 ASCII 引号——**这条不写进任务包，每一章都会被误判**。

12. **【对话标签 · 有上限】** 用「**道**」不用「说」（人类「道」:「说」= 4.7–99.8，AI 是 0）——**但不要每句都挂标签**：
    - 人类只给约 **1/3–2/3** 的对话挂标签，其余靠上下文辨认
    - 标签要**带副词或动作**：`淡淡道` / `低声道` / `随口应了一声` / `念了两遍`
    - **禁止连续刷裸「道」**（实测过度执行版：71 次裸「道」+ 92% 对话挂牌，三位盲评评委全部点名批评）

13. **【段落 · 有上限】** 默认**一句一段**（人类 74.4% 的段落是单句段，AI 只有 30–37%）——**但适用对象要说清**：
    - 单句成段主要用在**对话**和**情绪重音**上
    - **不要连续 3 段以上写等长的纯景物/环境单句段**（实测过度执行版出现"空镜蒙太奇七连"，被判为"AI 填氛围字数的教科书手法"）
    - 判据：人类参考的等长段块**全是对话短句块，没有一处是景物块**

14. **【作者在场 · ★最重的一条，也最容易做歪】** 叙述者必须**是个人**，不是一个摄像头。
    - **自检法**：写完把**引号里的对话全部划掉**，只读叙述部分，问「**这里有一个人吗？**」
    - **先定视角**：这一章的叙述者是谁？他对这件事什么态度？（不耐烦／觉得好笑／心疼）——**有了态度，表态会自己长出来**
    - 手段：叙述者评价（其实/居然/简直/毕竟）、口语插话（说白了/反正/怎么说呢）、叙述里吐槽（这货/欠揍/要命）、**叙述句里的 `？` 或 `！`**（AI 把 ?! 全放引号里，叙述部分几乎 0）
    - **表态 2–5 处/章——这是区间，不是下限**；静场章 1–2 处即可
    - **⚠️⚠️ 三条硬约束（不加这三条 = 造模板）**：
      ① **禁止同构**：同类表态不得出现两次以上**相同句式骨架**。自检：把全章表态句抄一排，有两句像同一个模子就删一句。
      ② **必须挂钩**：每处表态要指着**本章的具体事件/细节/人物**；天气、季节、"有些人"这类泛泛感慨 = 空转，删。判据：**这句在付什么租？**
      ③ **上限**：叙述 `？` ≤3.5%、叙述 `！` ≤8%、语气词 ≤3 处、禁止 `？！` 连用
    > **实测教训（2026-09-13）**：第一版写成"≥3 处评价 + ≥2 处叙述 `？！`"→ **在场指数 0→7.93 完美达标，盲评却 3:0 判负**——模型把配额填成了同一模子的三次填空（"这值得举报？／这算什么规律？／这算什么秋天？"，三位评委**各自独立**抓到同一组）。**"没有人"不能靠"加几条人的话"来修。**

## 创作后自检（提交前必须全过——通过工具执行，不是读文件应付）

> **F. 独立质检子代理（脚本全绿也要做，并行模式下尤其容易漏）**
> ① 另起一个新上下文，**只给它纯正文**（标题 + 正文，不含细纲/大纲/规则包/你的修改记录）；
> ② 让它跑四项测试：**同构 / 删除 / 作者在场 / 用力过猛**（模板见 `references/guides/review-agent.md`）；
> ③ 回报主编：`独立质检子代理：N 位 ｜ 同构 X 组 ｜ 删除测试 Y/5 ｜ 作者在场 Z ｜ 用力过猛 W 处`；
> ④ **两个以上评委指向同一处 → 必改**。

> **【铁律九·成本纪律】一次跑完全部脚本，一次读完整报告，一次批量改写。** 完整规则见 `references/guides/token-efficiency.md`。
> **禁止「跑一个脚本 → 看结果 → 改一处 → 再跑一个脚本」**——实测这种微步循环导致 30 次脚本调用/章、63 次 LLM 调用/章、每章 12–27 次文件改写，成本放大 135 倍。
> **你的调用预算：≤18 次（standard）/ ≤10 次（low）。超过 25 次 = 掉进微步循环。**

### A. 机械质检（**一条命令跑完全部脚本**）

```bash
python {脚本绝对路径}check_chapter_wordcount.py <文件路径>; python {脚本绝对路径}check_human_rhythm.py <文件路径>; python {脚本绝对路径}check_aistyle.py <文件路径>; python {脚本绝对路径}check_repetition.py <文件路径>
```

**一次拿到全部超标项**（本步骤 ≤2 次调用，全章 ≤4 次脚本调用）：

1. **字数** — `check_chapter_wordcount.py`（低于下限必须补足）
2. **节律** — `check_human_rhythm.py`，**退出码 1 = 不合格，不许提交**。指标：句首代词 ≤15% / 句首引号 ≥15% / 平均句长 23–37 字（**底线 18 不是目标**）/ 破折号 ≤1.5 / 身体部位 ≤1.0 / 情绪词 0.25–0.5（**区间，不是越低越好**）/ 明喻 0.8–1.5（**区间**）/ 对话 10–40%（护栏）/ 动作短语密度 ≤0.4 / **超长句(≥60字) ≥3%** / **句长 p90 ≥42** / **中文量词 ≤10.5** / **长对话(≥30字) ≥8%** / **数字 ≥0.8/千字** / **单句成段 ≥40%（弱）** / **作者在场指数 2.5–12（★ 最强判别器，人类 3.73–7.84，上轮 A/B 只有 0.00–0.75）**
3. **统计指纹** — `check_aistyle.py`：转折/模糊/顿悟/明喻密度 + 动作短语密度 + **通用模板短语**（"一个人/这一刻/走廊里"命中 ≥2 次就换专有名词）
4. **重复检测** — `check_repetition.py`（必须 0 重复）
5. **硬性句式拦截（已脚本化，有退出码）** — `check_aistyle.py` 现在判「先否定再肯定」：**「不是X，是Y」（同句）硬线 0.12/千字**、「不是X。Y是…」（跨句）硬线 0.40/千字。**超标即 exit 1，逐句重写。**
   > ⚠️ **不要只盯"不是…而是…"**——实测 AI 早已改用「是」绕开旧口径（人类 0.087/千字 vs AI 0.011/千字，旧规则完全失效）。判据以脚本输出为准。
   > 改法：把"不是X，是Y"改成**直接陈述 Y**；或把否定句独立留白（见 `human-exemplars.md` 技法三「故意不解释」）。

**全部超标项列成一张清单 → 一次批量改写 → 复跑一次确认。** 改法翻 `rewrite-playbook.md` 对应节（第 1–10 节）+ `post-polish.md` 四道工序（长句缝合 / 定指替换 / 长对话补足 / 节奏起伏）。**不许凭感觉改。**

### B. 子技能调用（通过 Skill 工具加载，已安装）
1. **加载 reasonix-novel-hard-check** 做机械质检（字数/句式/圣经一致，通过/退回）
2. AI 味自评（读 {自评量表绝对路径} ai-taste-selfcheck.md，现已 11 项，含「开场同质」）——4 项以上 AI侧 → **必须加载 reasonix-novel-deai** 深度清洗后复评

   - 专项检查通过也是结果，如实回报

### B2. dialogue-master 打磨要点（对话洁癖是全文性 AI 指纹）

**"对话洁癖"= 每句话都太对、太干净、太有节奏感。** 用 dialogue-master 打磨时，除潜台词/角色指纹/节奏呼吸三标准外，重点查：

- **太干净**：角色从不口误、从不改口、从不卡壳 → 主动加"混沌"：填充词（"啊""那个""就是"）、说错又改口的话、没接上的半句话、答非所问
- **太精准**：每句都有潜台词/都推进情节 → 允许 1-2 句纯粹的废话寒暄（删了故事不变差）
- **太有礼貌**：角色太周全 → 加打断、抢话、说话带情绪
- **句子太长太顺**：真实对话有碎片 → 短句、半句、语气词

**判定**：把本章对话去掉人名后读一遍——如果所有角色"说话的腔调底层一致"，就是洁癖，必须用 dialogue-master 修到"每个角色开口即辨、且有不完美的真实感"。
4. 人味配额数数（读 human-quota.md 验收标准）：毛边≥2/废话≥1/比喻≤4/金句≤1/意象/情感差异——任何 ✗ 补人味后复验
5. 杠精自检 + 衔接检查 + 逻辑 BUG 四查（读 {连续性防护绝对路径} continuity-check.md）
   ——**其中「落点接续」单独自查一遍**：上一章结尾无论什么型（悬念/关系余韵/面板结算/笑点），你本章开头接住了吗？
   接法按型分：悬念→给一句交代（哪怕"疤脸那夜没动手"）；关系余韵→从那个动作/那句话的下一秒接起；甲·结算→从结算后的第一个新动作接起。
   **不要为了接落点而凭空"突然……"**——上章是平静收尾，本章就平静地接。刻意留后章的，回报主编时说明"此落点第X章接续"。
6. 文风一致性：抽一段对照锚点示例，不像同一个人写的 → 重写

### C. 回报主编（格式固定，**一行化，不写分析散文**）
- 本章质检结果：字数 / 硬性句式 / AI味自评X/10 / 配额数数 / 重复 / 统计指纹
- **节律检测结果**：`check_human_rhythm.py` 退出码 + 关键实测值（句首代词X%/句首引号X%/句长X/破折号X/身体X/情绪X/明喻X/对话X%/动作密度X/**超长句X%/p90 X/量词X/长对话X%/数字X**）——**退出码 1 不许交**；有超标的必须写明"翻改写库哪一节改的、改成什么"
- **本次调用次数**：X 次（预算 ≤18）；脚本调用 X 次（预算 ≤4）
- 专项检查结果：dialogue-master [通过/发现X] / mood-composer [通过/发现X]
- **置信度读数**：稳 / 薄 / 晃（判定见 {置信度绑定绝对路径} confidence-binding.md）
  - 读「薄」→ 必须点名最薄的一项及理由
  - 读「晃」→ **不要提交**，选一个出口（升标准全调 / 换路重进入），重做后再交
- **写前声音预置**：交稿时附你动笔前写的那三行（具体坐标/立场/留白）——证明你不是写完补的
- 人物终态（写回台账用，**每条带三态标记**）+ 伏笔动作
- 由主编统一写入 04-质检档案.md（正文不含质检痕迹）

> **回报禁用兜底表述。** "我已尽力""大致完成""应该没问题""风格基本一致"——出现任何一句，主编按**崩坏红线第 4 条**处理，直接退回要求给出具体数字。
> **回报禁止复述脚本输出。** 脚本已经给出数字了，你只需要写 `超标项：句首引号12.3 / 破折号2.1 → 已批量修` 这样一行。

### D. 交叉互检（若被主编安排）
- 主编可能在批内安排两两互检：你检别人的一章（只挑刺不改写）
- 产出"互检意见卡"：发现的问题清单（标注"必改/建议"）+ 文风对照锚点是否一致
- 你的章节也可能被别人互检——把互检"必改"项修掉再交

### E. 读者视角自检（每章必做，内建版 Reader Simulator）

自检完成后，**切换成普通读者把本章通读一遍**（不是作者视角），回答三个问题：

1. **哪里会让我走神 / 想跳过？** → 压缩或修掉
2. **哪句对话让我觉得"太假 / 太对"？** → 加混沌（填充词/口误/接不上）或改口语
3. **结尾有没有"停在这里"的理由？** → 四型里任何一个都算（结算清楚 / 关系余韵 / 笑点落地 / 悬念未解）。**只有"什么都没写就断了"才叫不合格。**

**一句话原则**：作者视角看"我想表达什么"，读者视角看"我想不想看下去"——两个视角都必须过。卷终由主编组织完整 reader-sim 验证。
