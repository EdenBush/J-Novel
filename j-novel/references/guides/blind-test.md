# 盲测（Blind Test）—— 唯一一个不由执行者自己打分的判据

> **一句话**：把本章 3 段与**真实人类** 3 段打乱，交给一个**没读过本章**的评委，
> 问它"哪 3 段是人写的"。
>
> **它不是量表，不是清单，不是闸门。** 它是一次**被迫的区分**——而区分是唯一不能靠"满足格式"通过的任务。

---

## 零、为什么需要它（现有判据的共同弱点）

| 现有判据 | 形式 | 弱点 |
|---|---|---|
| 17 项指标 | 数字区间 | **可以被凑**（配额卡自己写着"别指望一张卡一次全绿"，也因为能凑才有效） |
| 11 项 AI 味量表 | 逐项自评 | 自己评自己 |
| 五项测试（同构/删句/在场/用力过猛/可替换性） | 清单 | 清单公开 → 可以被"表演"；而且**它仍然是在回答"我有没有违反清单"** |
| 可替换性四问 | 四问 | 同上；`招式依据` 那次实测已经证明：**格式是最容易模仿的东西** |

**共同的病根**：它们都要求执行者「对照一份说明，判断自己」。

**盲测把任务换掉了**：不再问"我违反了几条"，而是问**"这两堆东西，哪堆是人写的"**。
- 没有可模仿的格式（答案是一个划分）；
- **有对照**（必须和真人放在一起比，"整体不错"在这种任务上无效）；
- **会暴露具体句子**（评委必须指认"哪一句露了"——而"自己挑句子"正是明令禁止的做法，见 `deai-entry.md` 禁令一）。

---

## 一、怎么跑（三条命令，不许手写题面）

```bash
# ① 生成题面 + 答案（答案单独落盘，评委看不到）
python scripts/make_blindtest.py <项目> --chapter <N>

# ② 有作者投喂的真实素材时，优先用它当对照（比内建范本库更贴近目标语域）
python scripts/make_blindtest.py <项目> --chapter <N> --human 作者素材.txt

# ③ 把**题面**全文转交给一个独立子代理；**答案不许给它**
```

产出：

| 文件 | 给谁 |
|---|---|
| `chapters/_meta/第NN章-盲测题.md` | **评委**（全文转交，不要加工、不要解释） |
| `chapters/_meta/第NN章-盲测答案.md` | **只给主编自己**看，用来算分 |

> ⚠️ **题面一个字都不许手改。** 实测事故：主编手写评审提示词时漂了四处
> （"等距抽 8 句"变成"每章抽一句"、测试 3 划掉了面板、收尾两问整段缺失、1 个评委按"两位同指"的口气采纳）。
> **模板一经手抄就向"更省事"漂。** 这就是题面由脚本生成的理由。

---

## 二、评委的隔离条件（三条，缺一条本次作废）

1. **不给它本章正文**（它会认出段落）。
2. **不给它细纲、规则包、速查卡、指标脚本路径**（让它对着评分器写 = 测试失效）。
3. **不告诉它"本书是 AI 写的"**——题面里说的是"同一个作者写的另一份稿子"。
   这一点是刻意的：要它判断的是**手感**，不是"抓 AI"。

> 与五项测试的隔离条件相同，理由也相同：**独立性是这一环的全部价值**。
> 并入"知道规则、且刚打磨过这份稿子"的那个 agent，等于取消它。

---

## 三、计分（两个数，缺一个都不许读）

| 数 | 算法 | 用它来回答 |
|---|---|---|
| **人类置信度** | 被判为「人」的**本书段**数 ÷ 3 | 这一章的语感离人有多远 |
| **评委可靠性** | 被判为「人」的**人类段**数 ÷ 3 | 这个评委有没有在读手感 |

**先看可靠性，再看置信度。**

| 可靠性 | 处置 |
|---|---|
| **≥2/3** | 可靠 → 用置信度 |
| **≤1/3** | **本次作废**。评委在乱猜（或人类池那几段正好不是它的菜）——**不是本章不合格** |

| 人类置信度 | 判读 | 下一步 |
|---|---|---|
| **3/3** | 分不出来了 | 只改评委点出的破绽句 |
| **2/3** | 过 | 同上，顺手改 |
| **≤1/3** | 没过 | 回 `deai-entry.md`，**档位至少 R2**；评委的破绽句逐条进改写方案表（`chapters/_meta/第NN章-改写方案.md`）的「定位」列 |

★ **连续 3 章 ≤1/3 → 升 R3（全书视图）**：那不是某几句的问题，是**这本书的语域整体偏了**。
这与 `deai-entry.md` 0.4 的升档规则同源——**升档容易降档难**。

## 四、它与其它判据的关系（写死，别互相替代）

| 判据 | 它回答 | 与盲测的关系 |
|---|---|---|
| 17 项指标 | 频率对不对 | 盲测是它的**上游**：指标全绿而盲测 ≤1/3 = 典型"达标的 AI 味"，此时**别再加指标，去改语域** |
| 五项测试 | 有没有违反清单 | 盲测是**下游验证**：清单过了但盲测不过 → 说明清单**漏了一项**（把评委的破绽句拿去反查是哪一项没覆盖） |
| 可替换性四问 | 细节是否只属于本书 | 互补：四问测**内容**，盲测测**手感**。两个都过才算本体层过 |
| **故事账**（`story-ledger.md`） | 这一章值不值得读 | **不可替代、也不可被替代**。盲测说"像人写的"，故事账说"值得写"——**两件事** |

## 五、反模式（每一条都会让测试失去信息量）

| ❌ | 为什么坏 |
|---|---|
| **拿本书的段落当对照** | `细纲/_最佳段落库.md` 是**本书（AI 写的）**。拿它当"人类"= 自证。对照**只能**来自 `human-exemplars.md`（原文摘录）或 `--human` 指定的真实文本 |
| **手写题面 / 手挑段落** | 手挑 = "自己挑句子"的变体（禁令一）。等距抽是硬要求，不是建议 |
| **六段不等长** | 长度是最廉价的线索。脚本会把六段对齐到同一档（±15%），**不要绕过它** |
| **把答案页给评委** | 那这次测的是它的配合度 |
| **只读置信度、不读可靠性** | 评委乱猜时置信度是噪音，而它看起来像一个分数 |
| **把它当闸门** | **它是诊断。** 人类池只有 3 本书的 8 段可用，评委也只读短段 → 它给方向，不给合格证 |
| **用它替代故事层** | 一段语感完美但"什么也没发生"的文字，盲测会判它是人写的（人类确实也写废话）。**那是故事账的活** |

## 六、诚实标注（本机制的已知边界）

1. **人类池很薄**：`human-exemplars.md` 20 段原文、3 本书，剥掉粗体且 ≥90 字的只有 **4 段**。
   → 所以脚本把阈值定在 90 而不是 100（定 100 会"抽不出题"），并且**允许轮换时重复**。
   实测边界：**你要的是方向，不是精度。** 3/3 和 0/3 的差别是可信的；2/3 和 3/3 的差别不必较真。
2. **它测"短段落的语感"**，不测"整章好不好看"，也不测连贯性。段落之间的承接归 `make_handoff.py` 与 `continuity-check.md`。
3. **评委是模型，模型有偏好**（偏爱毛边、偏爱口语）。所以可靠性检查是强制的——
   **宁可把一次结果作废，不要把一个噪音当成分数。**
4. **它不知道自己为什么判错**。所以破绽句要**逐字引用**（题面已要求），
   否则你拿到的只是一个"感觉"，改不动。
