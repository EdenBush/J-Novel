# 故事账（Story Ledger）—— 文字层之外的那一层

> **定位**：本文件只做一件事——把"**这一章作为一个故事单元，立不立得住**"变成
> **可写、可查、可对账的五个字段**。
>
> **它不管文字怎么写。** 句子怎么写归 `human-rhythm.md` / `rewrite-*` / `humanize-toolkit`；
> 它管的是**在那些句子底下，到底发生了一件值不值得写下来的事**。

---

## 零、为什么会有这一本（缺口是结构性的，不是遗漏）

**把现有质检链按"它在测什么"铺开，会看到同一条水平线：**

| 机制 | 测的是 |
|---|---|
| `check_human_rhythm.py` 17 项 | 句长、密度、比例、次数 |
| `check_aistyle.py` | 转折词、模糊词、模板句式 |
| 独立质检子代理五项测试 | 同构／闲笔／叙述者在场／用力过猛／**可替换性** |
| 可替换性四问 | 这个细节**只属于这本书吗** |
| 口吻宪法 + 声音样本 | 这句话**像那个人说的吗** |

**全部落在"句子层"。一条都没有问过："这一章，为什么必须存在？"**

后果不是抽象的。它的具体形态是这样的：

> 一本句子全部达标、伏笔登记工整、章末型轮换正确、盲评能通过"像人写的"的书，
> 读者读到第 12 章弃了——因为**每章都在原地转**：主角一直在做事，但没有一次真的**失去**什么，
> 也没有一次真的**改变了什么**。每一章都可以删掉，而故事不会少任何东西。

**再往下追一层，为什么这条线一直没被补上**：
子代理的**唯一读物**是 `quick-reference-card.md`（一页速查卡）。
那一页 17k 字符里，**讲的全是句法指标**——0 字符讲"这一章该发生什么才好看"。
→ 于是写手结构上**不可能**知道故事层的要求。它不是在偷懒，是**没人告诉过它**。

> **一句话**：本体系此前能把"一段不必要的事"写得越来越像人。
> 这一本补的是——**先让那件事有必要**。

---

## 一、五个字段（唯一权威载体）

**落盘位置（接口契约，逐字）**：`chapters/_meta/<章名>.meta.md` 的 `## 故事账` 段。
**绝不写进正文文件**（工程字段留在正文里是最强的 AI 指纹，见 `chapter-template.md`）。

```markdown
## 故事账

- 选择：<谁 / 在什么处境下 / 必须在 A 与 B 之间选一个，两个都想要>
- 代价：<他失去了什么——已经发生的事，不是"他累了">
- 位移：<信息 / 关系 / 位置 / 资源 / 自我认知 —— 选一项，写清"从什么变成什么">
- 可删性：<删掉这一章，后文要改 N 处；一句话理由>
- 欲望：<本章结束时，读者能说出"他现在最想要什么"——一句话，不许用抽象词>
```

**解析规则是跨 agent 的接口契约，不许改**：
定位 `## 故事账` 标题行 → 向下取 `- 键：值` 形式的条目 → 遇到下一个 `## ` 或文件结束为止。
键名逐字：`选择` / `代价` / `位移` / `可删性` / `欲望`。**改一个字，`check_story.py` 就判不了。**

## 二、每一格写到什么精度（**这一节是本文件的核心，别跳**）

> **为什么单列这一节**：v7.5.0 的教训——只规定"表格形状 + 字段名 + 闸门怎么判"，
> 结果**真实项目 10 章的方案表四列逐字相同**（"落笔/句式缺陷｜章末或指定句｜见三行对照"）。
> **填满字段 ≠ 算过内容。** 所以每一格都给正例/反例。

### 选择（这一章的主干动作）

| | 写法 |
|---|---|
| ❌ | 「林砚决定去矿洞」——**没有两难**，这是行程，不是选择 |
| ❌ | 「林砚决定救苏晚」——只有一个选项的东西不叫选择 |
| ✅ | 「救苏晚要暴露密道，不救她会死；他选了暴露」——**两个都想要，只能拿一个** |

**判据（能当场回答是/否）**：把 A 和 B 并列写出来，读者能不能替主角找出"都行"或者"当然选 B"？
能 → **不是选择**，是必然。重写这一章的处境，直到**两个选项都疼**。

### 代价（选择的账单）

| | 写法 |
|---|---|
| ❌ | 「他付出了很大代价」「他很痛苦」——**形容词不是代价** |
| ❌ | 「他受了伤」——伤在下一章就好了，那是**成本**不是代价 |
| ✅ | 「密道暴露 → 下一批货出不去 → 他欠老周的那笔钱还不上了（第 14 章追债）」 |

**判据**：这格写完之后，**能不能指出"第几章会因此出问题"**？
指不出 → 代价还没有兑现安排 → 它是**情绪**，不是账单。

### 位移（章末与章初的差）

**只能从这五个里选一个（不许自造）**：`信息`／`关系`／`位置`／`资源`／`自我认知`。

| | 写法 |
|---|---|
| ❌ | 「他变强了」——那是数值，不是位移（数值每章都会涨，读者不认它） |
| ❌ | 「气氛更紧张了」——**气氛不是状态** |
| ✅ | 「关系：他和苏晚从'互相试探'变成'她替他撒了一次谎'」 |
| ✅ | 「信息：他知道矿洞塌方不是意外，但不知道是谁做的」 |

**判据**：这句能不能写进 `03-状态台账.md` 的「落地」列并标 `✓`？能 → 它是位移。

> ⚠️ **静场章也要有位移。** `narrative-craft.md` 已定：静场章靠"微妙"不靠"对抗"，
> 但仍要有变化（**关系 / 认知 / 位置至少变一样**）。所以「位移」这一格**永远不许写"无"**。
> 真正无事发生的章，问题不在这一格——**在"这一章该不该存在"**。

### 可删性（**本文件最强的单一判据**）

问一句：**删掉这一章，后面要改几处？**

| 答案 | 含义 | 怎么办 |
|---|---|---|
| **≥3 处** | 这章**承重**（后面三章的因果都踩在它上面） | 通过 |
| **1–2 处** | 可压缩 | 能并进相邻章就并；不能，就给它第二件事 |
| **0 处** | **水章** | 要么删，要么**给它一件事**（见第三节「三种病」） |

**写法**：`- 可删性：3 处（第 14 章追债、第 16 章他被逐出匠籍、第 19 章苏晚替他作证，都依赖密道已暴露）`

❌ `- 可删性：有` ／ `- 可删性：不能删` —— **没给数字 = 没算过**。脚本会直接判不合格。

### 欲望（读者手里的那根线）

**一句话，不许用抽象词**（野心／复仇／成长／变强 —— 全部不合格）。

| | 写法 |
|---|---|
| ❌ | 「他想变强」／「他想复仇」／「他想活下去」 |
| ✅ | 「他想在下个月之前凑够三十七两，把妹妹从那张契上赎回来」 |

**判据**：这句话里有没有**具体对象 + 具体期限或数量**？没有 → 读者没有线可抓。

## 三、三种病（故事层的三种失败形态，各有各的处方）

> **共同点：三种病都改不出好章——加描写、加比喻、加闲笔，全都无效。**
> 它们不是文字问题，是**事件问题**。处方一律是"改事件"，不是"改句子"。

| 病 | 症状 | 根因 | 处方 |
|---|---|---|---|
| **流水账** | 每章都在"做事"：赶路、打怪、谈判、吃饭；读完记不住他做了什么决定 | `选择` 一格写成了行程 | 把其中一件事改造成**两难**：给他一个"不做会更好"的选项 |
| **白给** | 爽点很足，但读者不为他高兴——赢了之后什么都没少 | `代价` 一格是形容词 | 让这次胜利**花掉**一样东西（关系 / 信誉 / 一个他喜欢的地方） |
| **原地转** | 单章都不难看，连读十章像在原地 | `位移` 一格五章同值 | 换轨：把"变强"换成"关系"或"自我认知"位移 |

**诊断顺序**：先看 `可删性`（0 = 流水账的典型结果），再看 `代价`，最后看 `位移`。
**别从 `选择` 开始看**——`选择` 是最容易写得漂亮的一格（"他选择了牺牲"），它最容易骗人。

## 四、三条判据（**人判，脚本不判**）

脚本只验"五格齐不齐、精度够不够"，**不验好坏**（那需要理解，正则做不到——本体系已诚实承认过一次，
v6.9.0 的"闲笔密度"判据就是因此弃用的）。好坏由**独立评委**判，三问：

1. **选择是否两难**：把 A、B 并列念一遍，**能不能替主角找到"其实可以都不选"**？能找到 → 不是两难。
2. **代价是否已发生**：它是**这件事**造成的，还是**本来就会发生**的？（"他受伤了"通常是后者）
3. **位移是否不可逆**：他能不能**下一章就当无事发生**？能 → 那不是位移，是波动。

> **谁来判**：`review-agent.md` 的独立质检子代理。
> ⚠️ 判这三问时**可以给它故事账**（与五项测试不同——那五项必须只给纯正文）。
> 理由：这三问问的是"事件的重要性能不能撑住一章"，不是"文字像不像人"，给背景不污染判断。

## 五、与已有产物的接口（写死，别另存一份）

| 已有产物 | 关系 | 规矩 |
|---|---|---|
| `细纲/剧情卡-第NN-NN章.md` | **本章钩子 = 选择之后的结果**；「回不去的事件」= 位移 | 剧情卡在前（批级共创），故事账在细纲展开时落。**顺序不能反**：先有"哪件事"，才谈"这件事有没有代价" |
| `01-大纲.md` 伏笔对照表 | 位移是伏笔的**触发器** | 位移换了，回来对一遍伏笔：哪个原来是"埋"的，现在该"收" |
| `03-状态台账.md` | 位移**必须**写进「落地」列并标 `✓` | 不写 = 下一章的人不知道局面变了 = 状态分叉 |
| 细纲的「接口契约（冻结）」 | `选择` 与 `代价` 要能推出「退出·情绪」与「退出·已知」 | 契约对不上 → `check_contract.py` 会报 |
| `04-质检档案.md` | 三问答完写进「故事层」段（与「五项测试」并列，不合并） | 合并 = 取消独立性 |

## 六、反模式

| ❌ 反模式 | 为什么坏 |
|---|---|
| **五格全填"无"** | 「位移」不许写无；其余写无必须带**指向**（`无——代价在第 14 章兑现`）。**全无 = 这章不该存在**，脚本会报 |
| **把 `代价` 写成情绪** | "他很痛苦"不是账单。判据：指不出"第几章会因此出问题" |
| **用 `选择` 骗过 `代价`** | 「他选择了牺牲」写得漂亮，但没写**牺牲掉了什么具体的东西**。前者是姿态，后者才是账 |
| **把它当合规表格** | 五格是**写给即将动笔的那个人看的执行指令**（很可能就是你自己）。填满但没有一处是真的 = 比不填更坏（看起来像想过了） |
| **善后式补写** | 写完正文再补故事账 → 只会补出"我写的东西的意义"。**必须在动笔前定**（与实物清单同一时点） |
| **拿它替代剧情卡** | 剧情卡是"哪件事"（内容层），故事账是"这件事够不够格"（质量层）。**两件东西，两个时点** |
| **让脚本判好坏** | 不许。脚本只判"字段齐不齐 + 精度够不够"。**判好坏必须理解，理解无法用正则表达** |

## 七、诚实标注（本文件的已知边界）

1. **五格能挡住"水章"，挡不住"俗章"。** 一个两难选择、真代价、不可逆位移的章，也可能是俗套。
   俗套由 `plot-co-creation.md`（钩子候选）与 `thrill-panel.md` 管，本文件不管。
2. **`可删性` 是估算，不是计算。** 它靠"后面几章依赖它"来数，而后面几章可能还没写。
   → 所以它**允许后续修订**（写到第 16 章发现第 12 章的代价没兑现 → 回来改第 12 章那一格并记一行）。
3. **本文件不产生任何文字技法。** 它只规定"这一章底下必须有什么"。
   句子怎么写，回 `quick-reference-card.md` 零节。
