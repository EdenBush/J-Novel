# 章节质量评分卡（Quality Scorecard）

**把质量从"感觉"变成"数据"。** 每章交付前打一次分，全书完成后画出质量曲线——哪里塌了、哪里超常，一目了然。

继承自 Chinese Novelist 的 8 维评分体系（融合版此前遗漏，本轮捡回并升级），与十一项 AI 味自评互补：自评管"像不像人写的"，评分卡管"这章整体成色"。

---

## 八维评分（每维 /10 分，总分 /80）

| 维度 | 判分标准 | 低分信号 |
|------|---------|---------|
| **开头吸引力** | 前 3 段抓住读者了吗？ | 前 20% 平淡、无冲突、无信息 |
| **情节推进** | 本章推进主线了吗？ | 原地踏步、信息重复、纯过渡 |
| **人物塑造** | 行为一致且有深度吗？ | 崩人设、工具人、无弧光推进 |
| **对话质量** | 自然且推动情节吗？ | 信息倾倒、所有人一个腔调、无潜台词 |
| **悬念设置** | 结尾钩子让人想看下一章吗？ | 无钩子、虚假悬念、同质钩子 |
| **节奏控制** | 张弛有度、有波浪感吗？ | 一条直线、全程紧绷或全程松散 |
| **展示而非讲述** | 用行动/对话而非陈述吗？ | 情绪被直接说出、形容词堆砌 |
| **语言质量** | 无 AI 痕迹、用词精确吗？ | AI 味自评超过 3 项 AI侧、硬性句式残留 |

**判分规则**：
- 对照 `ai-taste-selfcheck.md`、`continuity-check.md`、`hook-techniques.md` 的检查项判分，不凭感觉
- 任何一项 ≤ 6 分 → 该维度必须修改后重新评分
- 总分 < 60 → 整章大改（结合 DeAI/Write Master 修复）
- 60-70 → 基本可交付，打磨细节
- ≥ 70 → 质量过关，可交付

---

## 评分时机与写入

- **每章质检**（Phase 3 步骤 3）：初稿质检后评一次；修改完成后终评。**终评分写入 `04-质检档案.md` 的本章记录**（质检摘要不写入章节正文）

- **Phase 4 校验**：汇总全书各章评分，生成「质量曲线」——章节号为横轴、总分为纵轴：
  - 连续 3 章 < 65 分 → 标记"低潮区"，提示卷末复盘或回炉
  - 锚点章 < 70 分 → 必须回炉（锚点章是文风基准，不能掉链子）
  - 高分章 → 可作为文风锚点候选（写入资产库）

---

## 全书质量报告（完稿时，Phase 5 输出）

```
📈 《[小说名]》质量报告
平均分：[X]/80 | 最高：[第X章 YY分] | 最低：[第X章 YY分]

质量曲线：[每章分数走势简述，标注低潮区/高峰区]

最强维度：[如"悬念设置平均 8.2"]
最弱维度：[如"节奏控制平均 6.1"——下一部作品重点加强]

资产沉淀建议：
- 高分章节（≥75）：抽取文风锚点入资产库
- 反复低分维度：记入教训库，下个作品预判规避
```

这份报告会沉淀到资产库（`asset-vault.md`），成为下一部作品的"起跑线数据"。
