# AI 模板黑名单（词 · 句式 · 道具）

> **这份指南解决什么**：`ai-taste-selfcheck.md` 是**自问**（"我的心理描写是还原还是总结？"），
> `humanize-toolkit.md` 是**配方**（"该往里加什么"）。
> 这一份是**清单**——具体到词和句，**扫一遍就能改**。
>
> **来源**：融合 `novel-humanize` 的禁用词表 / AI 模板句式清洗表 / 模板道具清单，
> 并按本 SKILL 的人类基线（3 部真实长篇实测）**逐条做了密度裁决**。
> **凡经实测不成立的，已标 ❌ 并给数据**——不要照抄那一部分。

---

## 〇、使用纪律（三条，先读）

1. **看密度，不看单次。** 下面绝大多数词**人类也用**。真正的判据不是"出现了"，是"出现了多少次"。
   反复出现的才是指纹。**（这一条已被实测反复验证，见第四节）**
2. **换法不能雷同。** 同一个词多处出现时，**每处替换写法不能一样**——
   否则替代词本身变成新指纹。（实测踩坑：把"忽然"全卷换成"冷不丁"13 处，替代词被检出）
3. **改完必须复查替代词密度。** 热门替代词（冷不丁/莫名/到底/没来由/一下）改完后再全卷 grep 一次。

## 一、分级禁用词

### A 级 · 零容忍（出现即改，无法辩护）

| 词/类 | 为什么 | 换成 |
|---|---|---|
| **半角双引号 `"`** | **人类样本 0%**（AI 0–6.45%）。子代理写 .md 天然用 ASCII 引号 → 「句首引号占比」指标直接判 0 | 中文引号 `“ ”`（或项目统一用 `「」`） |
| **破折号 `——`** | 人类 **0.03–0.29/千字**，AI 4.72–5.94。是"句子写完了再补一刀"的痕迹 | 逗号 / 句号；补充信息并入主句 |
| **解释式提示冒号** | "核心是：""值得注意的是：""一句话总结："——**定义式工整**，自媒体腔 | 删掉冒号，改成口语直述 |
| **「不是 X，而是 Y」连用** | 人类 0.04–0.12/千字，AI 用"是"绕开。**800 字内 ≥3 次**是铁证 | 拆成两句独立短句，或删掉"不是 X"直接说"是 Y" |
| **结构性套话** | 「让我们来看看」「在当今……的时代」「众所周知」「毋庸置疑」 | 整句删除 |
| **大纲式罗列** | 连续 bullet / 大段加粗罗列（**小说正文禁用**） | 改成叙述 |

### B 级 · 看密度（人类也用，超密度才改）

以下是来源标为"命中即换"的词。**实测人类并不少用——不能"命中即换"。**

| 词 | 人类/千字 | AI/千字 | 裁决 |
|---|---|---|---|
| 仿佛 / 犹如 / 一丝 / 微微 / 轻轻 / 淡淡 / 似乎 / 宛如 / 俨然 / 显然 / 或许 / 忽然 / 猛地 / 骤然 / 分明 | **0.62–2.49（合计）** | **1.80–2.34** | ❌ **区间重叠，密度无法分离**。只改**明显复用**的（同一个词在一章里 ≥3 次） |

**替换方向（只在这一词确实被滥用时用）**：

| 滥用时 | 换成 |
|---|---|
| 忽然 | 冷不丁 / 突然 / 一下（**换法要分散**） |
| 微微 | 低了低头 / 挪了半寸 |
| 轻轻 | 踢了踢 / 蹭了一下 |
| 分明 | 摆明 |
| 俨然 | 活像个 |
| 似乎 | 八成 / 看着像 |
| 然而 | 可 / 但 |
| 因此 | 就 / 所以 |
| 仿佛 / 犹如 | 删掉，直接写本体 |

### C 级 · 出戏检测（出现在小说正文里本身就异常，但**不是 AI 判据**）

这些是**自媒体/公文/学术腔**，出现在小说里说明"作者腔"盖过了"叙述者腔"。
**但实测人类 0.01–0.04、AI 0.00–0.02 —— 两边都趋零，无法分离**，所以只能当"出戏提示"，不能当 AI 证据。

```
说白了 | 意味着什么 | 本质上 | 某种程度上 | 值得一提 | 不得不说 | 总而言之 | 综上所述 |
由此可见 | 值得注意的是 | 不可忽视的是 | 毋庸置疑 | 显而易见 | 归根结底 |
作为 | 关于 | 基于 | 进行 | 进一步 | 持续 | 不断 | 日益 |
赋能 | 重构 | 重塑 | 破局 | 深耕 | 布局 | 闭环 | 护城河 | 赛道 |
显著 | 深入 | 全面 | 系统 | 核心 | 关键 | 标志着 | 意味着 | 彰显了 | 体现了 |
至关重要 | 不可或缺 | 举足轻重
```

## 二、AI 模板句式清洗表（整句模式，发现即拆）

| AI 模板句式 | 为什么是 AI | 怎么拆 |
|---|---|---|
| **不是 X，而是 Y** | 对比句式反复复用 = 铁证 | 拆两句独立短句，或删前半直接说"是 Y" |
| **那一刻，他/她意识到……** | 配置式心理揭示句 | 删掉"意识到"，让人物做点什么 |
| **眼中闪过一丝……** | 小说圈最恶名昭彰的 AI 句式 | 整句删除，换具体身体动作或对话 |
| **心中涌起…… / 内心深处……** | 情绪万能句式 | 删除，用身体反应代替 |
| **不由得 / 不禁 / 忍不住……** | 人物不需要"不由得" | 删除三个词，直接写后面的动作 |
| **XX，仿佛 / 似乎 / 好像……** | 一篇超过 3 个是在凑比喻 | 砍掉一半，保留最独特的 |
| **在……的背景下 / 随着……的发展** | 开篇万能模板 | 删整句，从第二句开始 |
| **首先…其次…再次…最后…** | 结构化列举铁证 | 用"还有""对了""另外"串联 |
| **不仅……更…… / 既……又……** | "全面覆盖"强迫症 | 拆两句，或只说一半，留一半给读者 |
| **XX 是 YY 的 ZZ / XX 意味着 YY** | 定义癖——总想下定义 | 直接陈述事实，不下定义 |
| **空气中弥漫着…… / 空气仿佛凝固了** | 悬疑/情感类高度复用 | 换具体环境描写或人物感受 |
| **他/她深吸一口气……** | "准备做某事"的标准动作 | 删除，直接写后续动作 |
| **说不上来 / 难以形容 / 难以名状** | 写不出情绪就写"说不出" | 删。写人物**做了什么**来回避这种感受 |
| **心里涌起…… / 一股莫名的…… / 没来由地……** | 用"莫名"糊弄 | 删除。让读者从上下文自己感受 |
| **她/他突然意识到…… / 终于明白……** | 配置式心理揭示句 | 删除「意识到/明白」，直接写做什么、说什么 |
| **顿了几秒 / 沉默片刻 / 半晌 / 良久** | 对话停顿的统一模板 | **用动作填充停顿**：他把烟掐了。又点了一根。她拿起杯子，喝了一口已经凉掉的水 |
| **他/她知道……（某种心理或关系判断）** | 把内心状态**直接总结给读者** | 用动作/反应展示，不替读者下结论（见 `ai-taste-selfcheck.md` 第 1 项） |
| **他/她不知道的是……** | 铺设伏笔最偷懒的方式 | 用具体暗示代替，让读者自己发现"有什么不对" |
| **XX 的目光 / 眼神……**（目光平静/眼神复杂/目光闪烁） | 赋予"神情"最偷懒的方式 | 删。**写人物的手在干什么——手比眼神诚实** |
| **开头三件套**（钩子+痛点+承诺） | 自媒体开头模板 | 从**你真正想让读者知道的那件事**开始 |
| **段段金句收束**（"这才是……""这就是……"） | 连续 3 段都有 → 铁证 | 只让最重要的 1–2 段有金句 |
| **命名仪式**（"我把它叫做……"） | 同篇 ≥2 次 | 只留 1 次 |
| **对"深刻"的过拟合**（"本质上""归根结底"+ 升维命题） | AI 的假深刻 | 删掉升维句 |

## 三、★ 小说专属：万能情绪/恐惧模板（**已进脚本硬检测**）

> **这一节是本次融合最有实战价值的部分。**
> 实测：**人类 0.00–0.02/千字，AI 0.00–0.12** —— 人类几乎从不使用这些"标准件"。
> 已在 `check_aistyle.py` 新增 `cliche_emotion` 检测（非阻塞提示，因为单次出现可能是修辞）。

### 3.1 三档分类（**按实测分离度分，不是按"看起来像不像 AI"分**）

> 来源给了 44 个"万能情绪模板"。**逐词实测（人类 3 部 × 60 万字 vs AI 3 样本全书）后：只有 7 个真能分离。**
> 这是个重要提醒：**"读起来很 AI"和"统计上能分离"是两件事。**

| 档 | 词 | 实测（人类 → AI，/千字） | 怎么用 |
|---|---|---|---|
| **① 可分离（7 个）** | 空气凝固 · 心跳漏了一拍 · 后背发凉 · 指节泛白 · 心跳如鼓 · 指节攥得发白 · 脊背发凉 | 0.00–0.007 → 0.01–0.06 | **已进脚本**（非阻塞提示）。可作改写信号 |
| **② 人类也用，❌ 不可当判据（11 个）** | 忍不住 · 不禁 · 头皮发麻 · 眼中闪过一丝 · 忽然意识到 · 突然意识到 · 终于明白 · 脑海中闪过 · 良久 · 顿了几秒 · 身体一晃 | 忍不住 **0.25** vs AI 0.02（人类是 AI 的 12 倍！） | **不要当 AI 证据**。只是"用多了会腻" |
| **③ 两边都是 0（无信号，23 个）** | 指尖泛白 · 手心发凉 · 后背发热 · 呼吸停滞 · 呼吸一窒 · 手足发抖 · 双腿发软 · 后颈汗毛竖起 · 一片死寂 · 安静得可怕 · 心提到了嗓子眼 · 心中涌起 · 内心深处 · 目光复杂 · 目光闪烁 · 眼神复杂 · 沉默片刻 · 指甲嵌进掌心 · 指尖攥紧 · 忘了呼吸 · 脑海里浮现 · 不由得¹ · 目光平静² | 人类 0，AI 也 ≈0 | **写作时避免**（是标准件），**但不当判据** |

> ¹ 「不由得/不禁」严格说属第 ② 档（人类全书命中 68/375 次）——列在这里是因为按"章"看它们密度极低，
> 容易误判为"没用过"。
>
> ² 「目光平静」人类（重生啊）用了 4 次、AI 用了 0–3 次——**不分离**，与「半晌」「空气中弥漫」同类，已从脚本词表剔除。
>
> **⚠️ 弱信号声明**：即便是第 ① 档，AI 也只有 0.081–0.201/千字 = **3000 字章 0–1 次命中**。
> 所以它**不能做逐章硬闸门**（会变成假闸门）。它的价值在**写作时**（别写成标准件），不在**判稿时**。

### 3.2 万能情绪描写（③ 档为主，写作时避免）
| 模板 | 为什么像 AI | 重写方向 |
|---|---|---|
| 指尖泛白 / 指节泛白 | 悬疑 AI 标配生理反应 | 换成**只有这个人物会做的**特定动作——有人紧张时反复清嗓子，有人不停摸耳垂 |
| 手心发凉 / 后背发凉 / 后背发热 | 万能"恐惧"标签 | 用环境反衬：她没觉得冷，但她发现自己的手指在抖 |
| 心跳轰鸣 / 心跳如鼓 / 心跳漏了一拍 | 紧张反应三件套 | 换成非标准动作：她把手机翻过来扣在桌上。又翻回来 |
| 手脚发抖 / 双腿发软 / 身体一晃 | 恐惧标准动作包 | 换。有人恐惧时站得更直、有人不停眨眼 |
| 指尖攥紧 / 指节攥得发白 / 指甲嵌进掌心 | **「攥」是 AI 写恐惧最爱的动词** | 换。有人反复揉衣角、有人不停转手上的戒指 |
| 呼吸停滞 / 呼吸一窒 / 忘了呼吸 / 喘不上气 | 恐惧 = 呼吸异常 | 删。恐惧时呼吸的变化读者身体会自己同步 |
| 后颈汗毛竖起 | "第六感"标准写法 | 删。让人物注意到**一个具体的异常细节** |
| 空气凝固 / 一片死寂 / 安静得可怕 | 悬疑氛围三件套 | 写具体的声音：空调停了。冰箱也没响。连楼下的狗都不叫了 |
| 心提到了嗓子眼 | 标配紧张反应 | 删。换成具体动作——她把包抱在胸前，一直没放开 |
| 脑海中闪过 / 脑海里浮现 | 回忆引入标准句式 | **直接切入回忆画面**，不需要桥梁 |
| 头皮发麻 / 脊背发凉 | 恐惧万能收尾句 | 删。前面描写够到位，读者自己会头皮发麻 |
| 心头一紧 / 心头一颤 / 微微一怔 / 微微一愣 | 情绪转场填充 | 换动作 |
| 目光平静 / 眼神复杂 / 目光闪烁 | 神情偷懒 | 写手在干什么 |

### 3.3 动作描写底层结构签名
**「动词+宾语，动词+宾语，动词+宾语」连续三个以上的逗号罗列** —— AI 动作描写的结构签名。

按人物情绪处理（见 `humanize-toolkit.md` 第 20 招）：
| 情境 | 处理 |
|---|---|
| 冷静观察 / 日常行动 | **可保留**逗号罗列 |
| 恐惧 / 紧张 / 疲惫 | **必须拆成句号断句**——「钥匙插进去。拧两圈。开门。进去。关门。反锁。」 |

### 3.4 叙事结构层
| 模板 | 为什么是 AI | 重写方向 |
|---|---|---|
| 所有伏笔在结尾精准回收、每条线索导向同一真相 | **「零废料」叙事** | 保留 1–2 条不回收的支线；加主角猜错的方向；让某些细节纯粹因为"生活里存在"而存在 |
| 关键信息靠口述/文档/截图/搜索一次性交代 | 信息直塞 | 碎玻璃法（5–7 片散落日常场景） |
| 主角推理全程零失误 | AI 全知视角 | 至少 1 个推理错误 |
| 人物善恶二元切割 | AI 安全性训练痕迹 | ≥2 个角色有"与阵营矛盾"的行为 |

## 四、模板道具清单（**出现即警惕，两个以上确认模板化**）

> **核心原则**：**道具必须长在这个故事里。**
> 如果同样的道具可以无缝换到另一个故事——它就是模板道具。

| 模板道具 | AI 的用法 | 替换思路 |
|---|---|---|
| 监控摄像头 | "监控里拍到了不该出现的东西" | 换成只有这个场景才有的观察方式——邻居老太太的买菜路线、保安的交班时间 |
| U 盘 | "里面存着秘密文件" | 换成只有这个职业/年代才会用的存储方式——速写本、病历、旧手机备忘录、账本夹页 |
| 旧相册 / 老照片 | "翻到一张褪色的照片，揭开往事" | 换成有感官细节的记忆载体——一件起球的毛衣、一盒过期的药、一张超市小票 |
| 手机 | "一条没有发送的短信" | 手机可用，但内容不能是模板——不是"未发送的短信"，是**某个人反复打又反复删的草稿** |
| 钥匙 | "一把不知道开哪扇门的钥匙" | 太老套。换 |
| 拖鞋 / 鞋子 | "门口多了一双/少了一双鞋" | 换成只有这个人物会注意到的——冰箱里少了一罐啤酒、洗衣机里的衣服不是他的 |
| 餐桌 / 晚餐 | "餐桌上的沉默" | 餐桌可用，但重点从"沉默的氛围"移到**具体的、奇怪的动作** |
| 秒表 / 计时器 / 闹钟 | 主角用它"量化异常" | 换成体感。不写「电梯用了 47 秒」，写「她感觉过了很久」 |
| 旧报纸 / 微缩胶片 | "在档案馆翻到一条旧新闻" | 信息不能靠"翻到"获取——打碎成多人的只言片语 |
| 电梯面板 / 楼层按钮 | "按钮磨损程度不一样" | 换。换成只有这栋楼/这个职业才会注意的空间异常 |
| 监控截图 / 录像回放 | "回放监控发现……" | AI 最爱的信息直塞方式。换成主角自己注意到的、**无法截图**的生活细节 |
| 手写纸条 / 匿名信 | "收到一张纸条" | 太偷懒。关键线索不能从天而降 |
| 百度街景 / 地图年份 | "翻街景历史年份" | 换成不经意的日常发现——不是主动去搜，是偶然注意到 |

## 五、误伤警告表（**不能机械判 AI**）

> 处理原则：**先看密度，再看语境。** 人类偶用是修辞，AI 是高频复用。
> 单次出现不判，**密度超标才处理**。

| 特征 | 触发阈值 | 说明 |
|---|---|---|
| "不是 X 是 Y" | 800 字内 ≥3 次 | 鲁迅、李敖、罗翔都用。**实测人类 0.04–0.12 > AI 0.00–0.03** |
| 收束金句（"这才是…"） | **连续 3 段**都有 | 偶尔用是修辞，段段都用才是 AI |
| 堵住反驳（穷尽反面） | 仅适用于自媒体/社媒 | 学术写作和法律论证穷尽反驳**是规范**，不判 AI |
| 命名仪式（"我把它叫做…"） | 同篇 ≥2 次同一句式 | 偶尔一次正常 |
| 短句独立成段 | **每段都这样** | 情绪高点用是力量（见裁决） |
| 自然嵌入的小比喻 | — | "像两颗泡在水里的黑豆"这类**增人味，允许保留** |
| 书面连接词 | **无法用密度分离** | 人类 0.62–2.49 vs AI 1.80–2.34 —— **区间重叠** |

## 六、❌ 来源中被实测驳回的条目（**不要照抄**）
