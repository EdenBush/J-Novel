# 具体性与叙述者立场：AI 味最深的两层

**为什么还需要这份指南**：`human-rhythm.md` 管句法（句子怎么组织），`ai-taste-selfcheck.md` 管词汇（用不用"仿佛"）。
但还有两层，比句法更深、比词汇更难抓——它们是"这一句写什么"的决策层，不是"这一句怎么写"的修辞层。

- **具体性**：人类写"半包受潮的火柴"，AI 写"一些东西"。
- **叙述者立场**：人类叙述者会同情、会嘲讽、会觉得好笑，AI 叙述者永远客观中立。
- **信息取舍**：人类留白、信任读者，AI 把一切都解释清楚。

数据（三人类作者全书 vs 三部 SKILL 小说，最干净的一个信号）：

| 指标 | 人类 | AI | 倍差 |
|---|---|---|---|
| **具体数字/千字** | 1.46–3.13 | 0.05–0.11 | **13–28×** |

人类用"十二年""120分""90000点技巧值""一公里外"锚定世界；AI 用"很多年""很久以前""很多人"。
这不是数字崇拜，是**具体性**的外在表现——数字是"可触摸坐标"的最硬形式。

---

## 一、具体性：把每一个泛化词换成一个具体物

### 数字锚定

| ❌ 泛化（AI 默认） | ✅ 具体（人类写法） |
|---|---|
| 很多年前 | 十二年前 / 三年前的冬天 |
| 过了一会儿 | 四十七秒后 / 抽完那根烟 |
| 很多人 | 十七个人 / 一屋子人 |
| 很远 | 一公里外 / 三个街口外 |
| 很大一笔钱 | 二十万 / 他三个月工资 |

**规则**：写完一章，扫一遍"很多/一些/一点/一会儿/很久/很大/很远/很快"，
每处问一句：**能不能换成一个具体数字或具体物？** 能换就换。

### 具体物 vs 泛化物

| ❌ 泛化 | ✅ 具体 |
|---|---|
| 一些东西 | 半包受潮的火柴、一把生锈的钥匙 |
| 一个礼物 | 一支用了一半的口红 |
| 一些食物 | 两片隔夜的面包、半碗凉掉的粥 |
| 那个人 | 穿蓝雨衣的那个男人 |

**为什么有效**：泛化词让读者"看见概念"，具体物让读者"看见东西"。
概念不产生画面，东西才产生画面。AI 最大的问题就是整篇都是概念，没有一个可以摸的东西。

### 具体动词 vs 泛化动词

| ❌ 泛化 | ✅ 具体 |
|---|---|
| 走过去 | 蹭过去 / 挪过去 / 踮着脚摸过去 |
| 看 | 扫了一眼 / 盯着 / 乜斜了一眼 |
| 说 | 嘟囔 / 吼 / 从牙缝里挤出一句 |
| 拿起来 | 捏起来 / 抄起来 / 用两个指头拈起来 |
| 离开 | 摔门走了 / 贴着墙根溜了 |

**AI 的动词库极其贫乏**：走、看、说、拿、想、感到。人类的动词是有质感的——
"蹭""挪""摸""拈""乜斜"这类词自带身体和情绪。每个"走过去"都该问一句：他是怎么走的？

## 二、叙述者立场：叙述者不是摄像头

**这是 AI 味最隐蔽、也最深的一层。** AI 的叙述者永远是中立的、客观的、不偏不倚的摄像头。
人类的叙述者是有立场的人——他会同情某个角色、嘲讽另一个、觉得某个情节好笑或可悲。

### 有立场的叙述 vs 无立场的叙述

| ❌ AI（摄像头） | ✅ 人类（有立场） |
|---|---|
| 他叹了口气，觉得生活很艰难。 | 他叹了口气。就这日子，狗都嫌。 |
| 她是个很要强的人。 | 她这种人，就是摔了跟头也要先说"没事"。 |
| 两人争执起来。 | 吵到最后，谁也没说一句人话。 |
| 他失败了，心情很差。 | 他又搞砸了——毫不意外。 |

看真实的人类例子（三天两觉《惊悚乐园》）：

> 狙击手近战弱是常识，曾经的潘匡也是这么想的，然后他死了。
> 对付杀手的专业人士，还是杀手。
> 傻了吧，我有甲！

**叙述者在嘲讽、在玩梗、在给角色下判词。** 他不是在"客观陈述"，他是在**用一句话表达一个判断**。

### 怎么建立立场（写前决定，不是写后补）

每场戏开写前，问自己三个问题：

1. **这场戏里，叙述者站谁那边？** 同情谁？不耐烦谁？喜欢谁？
2. **叙述者对正在发生的事，是什么情绪？** 觉得爽？觉得荒诞？觉得悲哀？觉得好笑？
3. **叙述者想对读者说哪句话？** 就一句，藏在戏里，不直说。

**判据**：把叙述段落里所有"客观描述"挑出来，问——**这句话里，叙述者有态度吗？**
没有态度的句子，就是摄像头在说话。一整章都这样，就是"没人味"的来源。

> **注意边界**：立场 ≠ 说教。立场是"叙述者怎么看待世界"，不是"作者跳出来教育读者"。
> 立场藏在判断里（"然后他死了"），说教挂在脸上（"所以人要学会珍惜"）。前者是味道，后者是 AI 的另一副面孔。

## 三、信息取舍：留白，信任读者

**AI 会解释一切；人类会留一半不说。** 这是信任问题——人类相信读者能自己填上空白，AI 不相信。

### 该留白的三类

1. **动机留白**：人物为什么这么做，不写透。
   - ❌ 他之所以拒绝，是因为童年时父亲也曾这样背叛过他。
   - ✅ 他拒绝了。没人知道为什么——也许他自己也不知道。
2. **情绪留白**：情绪不点破，只给动作。
   - ❌ 她感到一阵复杂的悲伤。
   - ✅ 她把那杯茶放回桌上，杯底在桌布上压出一个圆印。
3. **解释留白**：不解释"这意味着什么"。
   - ❌ 这句话说明她已经知道了真相。
   - ✅ "哦。"她说。（她自己想）

**判据**：删掉这句话，读者会不会就完全看不懂了？不会 → 删。
人类小说的魅力有一半来自"读者自己拼出来的那部分"。AI 把拼图都拼好了，还附了说明书。

## 四、写前声音预置（这三层不是写后补，是写前定）

**最重要的原则**：具体性、立场、取舍，都是**动笔前决定**的，不是质检时补的。
质检时补"具体物"，就像给已经画完的画加高光——能看，但不对。

所以 Phase 3 的「写前分析」（步骤 1）里，除了衔接/人物/伏笔，必须加这一步：

```
## 本场声音预置（动笔前写三行，30 秒）
- 具体坐标：这场戏要放哪 2–3 个具体物/具体数字？（可触摸的锚）
- 叙述者立场：这场戏叙述者站谁、是什么情绪？（同情/嘲讽/觉得荒诞）
- 留白点：这场戏哪一处不写透，留给读者自己拼？
```

这三行写进细纲或任务卡，子代理照单写。**没写这三行，不算"写前分析完成"。**

## 五、怎么测

具体性有一个可测量的硬信号（数字密度），其余靠自检：

```bash
python scripts/check_human_rhythm.py 第X章-xxx.md   # 含「数字/千字」弱参考项
```

- **数字/千字**：人类 1.46–3.13，AI 0.05–0.11。低于 0.5 = 具体性不足（但题材敏感，作弱参考，不阻塞）
- **具体物/具体动词**：没有自动检测，靠自检——扫一遍"很多/一些/一点/东西/事情"，能换具体就换

## 六、自检（每章收尾问一遍）

1. 这章有几个具体数字？（一个都没有 = 太泛）
2. 把"很多/一些/一点/一会儿/东西/事情"圈出来——每个都能换成具体物吗？
3. 动词是不是全是"走/看/说/拿/想/感到"？有没有一个"蹭/挪/拈/乜斜"？
4. 叙述者有立场吗？还是全程摄像头？
5. 有没有一处该留白却写满了？

**这五条，是 AI 味最深、也最贵的五条。** 句法对了、词汇对了、配额对了，但这一层空了，读起来还是"没人味"。
