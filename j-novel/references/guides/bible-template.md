## 〇、口吻宪法

> 硬上限 2000 字。定稿后只读不改（除非换书）。它不是设定，是声音。

### 叙述者人格

- **谁在讲**：〔给一个身份，不是"第三人称"。写明"他是这本书的什么人"——一个在灰炉村收了二十年废料的独眼账房／一个刚入行的记名官／一个已经死过一次的人。身份一变，句子就变。〕
- **他对这个世界的态度**：〔他站谁那边、看不起什么、心疼什么。**一个词就够**：护短／冷眼／又怕又想看／嘴上刻薄心里记账。这一格决定判断句的倾向。〕
- **他惯用的句式**：〔长短比例 + 一两个标志性小动作。例：判断句三五个字一句，长句全用在吐槽上；骂人不带脏字；爱在句尾补一个具体数字。〕
- **他不做什么**：〔★ **负面边界，比上面三格更重要。** 他在任何情况下都不做的事，逐条写。例：不解释动机／不上价值／不预告危险／不煽情／不替读者下结论／不用"仿佛""宛如"开头。**这一格是防"通用先验把声音补回平均水平"的唯一闸门。**〕

### 声音样本（300–500 字）

> 〔**这不是设定说明，是"本书正文会有的语感"。** 判据：把这段随便插进本书任何一章的正文里，读者不会觉得换人了。〕
>
> 〔三条写法：① 说一件这个世界的**普通小事**（不推动主线）② 全程**不解释任何设定名词** ③ **允许一句旁白**——对读者说话、或括号自嘲，至少有一处。〕
>
> 〔样本必须 ≥300 字。**只有人格定义、没有样本 = 等于没写。**〕

（在此写 300–500 字正文片段。不是大纲、不是设定、不是"本书将会……"的说明。）

### 语域禁令

〔本书**不出现**的声音。挑 3–5 条抄下来——**抄下来才会被当约束用**，只读一遍不会。〕

- [ ] 书面语讲解腔（"综上所述""值得注意的是""由此可见"）
- [ ] 全知预告（"他不知道，这一别就是三年""命运的齿轮开始转动"）
- [ ] 形容词堆叠抒情（"无边的孤寂如潮水般涌来"）
- [ ] 网络热词吐槽（"这波啊，这波是……""属实是绷不住了"）
- [ ] 说明书式设定播报（"该体系共分七阶，分别为……"）

## 一、世界观手册

> **这一章决定"落笔时是不是一个庞大的世界"。**
>
> 实测事故（2026-09-20）：这一节长期只有 6 行占位符，其中「关键地理/场景」还明确写着
> **"每个一两句话"** → 于是真实项目产出 **1236 字世界观**（时空 72 + 规则 381 + 格局 272 +
> 地理 210 + 留白 132 + 视角 169），而同一项目的细纲 9028 字、大纲 7433 字。
>
> 后果不是"少写了几段景"，而是**落笔时手里没有"世界"这个维度**：
> 大纲管"这一章发生什么"，人物档案管"谁在场上"，细纲管"这场怎么演"——
> **没有一样回答"这个世界长什么样"**。Agent 只能用通用先验补：
> 补出来的是"一个村子"，不是"灰炉村"；而且每个子代理补得都不一样。
>
> **判据：这一章每一条都要能在写作时被"调用"。** 写不动、用不上的条目删掉——
> 但如果删完只剩几百字，那不是条目该删，是**这个世界还没想清楚**。

### 写法铁律：写实体，不写形容词

| ❌ 抽象概括（必然被吃掉） | ✓ 可调用的实体（正文能直接用） |
|---|---|
| 低阶矿产与药草丰富 | 灰铁矿（地表，含硫高、熔点八百上下）· 灰叶草（三株一组，刷新 12 分钟）· 岩纹铁（第一层以下，纹理对不上就报废） |
| 风景秀丽，民风淳朴 | 村口就一口井，井绳磨断过三根；铁匠只修白装，绿的看都不看 |
| 数值即地位 | 战力榜三千万行，副本准入按名次切；主城内城门槛 5000，进不去的连门口传送阵都不给点 |

**一句话自检**：把这条**抄进正文**，读者能不能直接看见东西、地点、数字、动作？看不见就重写。

### 机制卡（★ 世界观里"能算出冲突"的东西）

> **这里是容器，不是方法。** 怎么造卡、四类实体的完整实例、提问式生成器、命名学 —— 见 `guides/world-engine.md`
> （那是"怎么造"的权威载体，本节不重抄它的方法）。
>
> ★ **硬判据：每张卡必须能推出至少一个具体冲突。** 推不出来 → 它不是机制，是**描写** →
> 移到零件表（第 4 节的场景卡「可调用的 3 个具体细节」）。

**六格模板（字段名逐字，不许改）**：

```
**名称**：[绰号 + 本体]
**能做什么**：[一句可运算的话，不是形容]
**代价**：[用它会付出什么、由谁结算]
**边界**：[明确写出做不到什么]
**触发条件**：[什么情况下它会启动]
**会引发什么冲突**：[至少一个具体冲突]
```

**合格样张**（取材 `_rulebook_raw.txt` 的示例怪物「宝石，跨次元蛋白石」，改写成小说用）：

```
**名称**：「宝石」，跨次元蛋白石——持有即寄生
**能做什么**：持有者可以施展任何曾经触碰过它的人所知的法术（即使那个法术已经被用掉过一次）；
它还能变成持有者从任意一本书里挑出的任意一个名词（形状，不是能力）。
**代价**：它只要一件事——被一直拿着。一旦离手，它就不再以你为目标；
所以它替你解决掉"想让你放下它"的人。持有者越舍不得，它越肯出力。
**边界**：① 只能施别人已知的法术，自己不能发明；② 变的只是形状，不是本事；
③ 不能自己走——它必须有人拿着。
**触发条件**：一个知道法术的人第一次触碰它时认主；此后每一次持有者被劝、被逼、或手里的东西被打掉，它就介入。
**会引发什么冲突**：主角得到它之后，每一次"你先帮我拿着"都变成一次谋杀预警；
而最想让他放下它的那个人，恰好最可能是他唯一信任的人。
```

**不合格样张（逐格点破）**：

```
**名称**：幽冥玄铁令
**能做什么**：蕴含着极其强大的神秘力量，能够影响周围的一切事物
**代价**：使用它会付出代价
**边界**：无
**触发条件**：在关键时刻
**会引发什么冲突**：主角可能会面临一些困难
```

| 格 | 为什么不合格 |
|---|---|
| **名称** | 只有本体没有绰号，且"幽冥玄铁"是通用玄幻词——**不自带任何画面** |
| **能做什么** | **不可运算**。"极其强大""影响一切"算不出任何结果 → 改成"它能让已经死掉的一次再发生一次" |
| **代价** | **"会付出代价"是同义反复**，等于没写 → 写清付出什么（记忆/寿数/名字）、**由谁结算** |
| **边界** | **空着**——没有边界的规则不算规则（见第 2 节的"边界是可信度的唯一来源"） |
| **触发条件** | "关键时刻"是**叙述判断，不是世界条件** → 改成"当在场有人说出死者的名字时" |
| **会引发什么冲突** | **空话**，推不出任何一场戏 → 换成"主角只能用别人的死来救自己人" |

> 六格里三格是空话 → **它先不是"不合格的卡"，是描写** → 按上面那条硬判据移进零件表；
> 要留在本章，必须六格全填并且推得出冲突。

### 反模式（命中即重写）

- ❌ **只写形容词**："风景秀丽""民风淳朴""实力强大"
- ❌ **只有概念没有实体**："低阶矿产与药草丰富"——丰富的是什么？叫什么名？在哪一层？
- ❌ **只写能做什么，不写不能做什么**（没有边界的世界 = 不会产生冲突的世界）
- ❌ **专有名词表空着**（这一项空着，子代理必然各造一套词 → 世界分裂）
- ❌ **场景卡没有"可调用的具体细节"**（写正文时你回到这里会发现无事可写）
- ❌ **口吻宪法只有定义、没有样本**（"叙述者立场：护短"是抽象参数。抽象描述不激活语域，
  **必须有 ≥300 字的样本**——见 `guides/voice-charter.md`）
- ❌ **机制卡六格缺「边界」或推不出冲突**（缺边界 = 没有可信度；推不出冲突 = 它是描写，
  不是机制，移到零件表去）

> "同一个伏笔在两个地方状态不同"，**那正是伏笔机制想防的事**。
> 冲突时以 `01-大纲.md` 为准。

| 伏笔 | 埋下章节 | 回收章节 | 当前状态 | 落地 | 预期效果 |
|------|---------|---------|---------|------|---------|
|      |         |         | 待埋设 | ?    |          |

**状态机**（卷终用 Bible Updater 更新）：`待埋设` → `已埋设（第X章）` → `已回收（第X章）`；回收章节已过但未回收 → 标记 `进度异常`；写作中临时新增的伏笔 → 标记 `写作中新增`。

**「落地」列 = 三态标记（铁律五，J-Novel 新增）：**

| 标记 | 含义 | 写法 |
|---|---|---|
| `✓` | 已在正文明确写出 | `✓（第3章）` |
| `?` | 仅规划/推断，未落正文 | `?` |
| `✗` | 已被后续剧情否定 | `✗（第14章推翻）` |

**默认无标记 = `?`。任何标 `?` 的条目，下游章节不得当作已发生的事实来写。**

它与「当前状态」列回答两个不同的问题：状态机管"这条伏笔在生命周期的哪一环"，落地管"**这条是不是真的已经写进正文了**"。两条都要填——状态写"已埋设"但落地还是 `?`，说明它在计划里埋了，正文里还没埋，这正是最容易出事的组合。

## 四·五、意象使用记录（防机械重复）

登记核心意象（反复出现的具象物/词，如鸡蛋/月光/剑穗）。**红线：同一意象每卷 ≤4 次，且至少有一次"该出现时缺席"。**

| 意象 | 出现章节 | 已出现次数 | 情感功能 | 下次计划出现 |
|------|---------|-----------|---------|-------------|
| [例：鸡蛋] | 第1、5、14、24章 | 4（已达上限） | 朴素之爱 | 本卷不再出现，下卷第 30 章 |
