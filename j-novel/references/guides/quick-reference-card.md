# 写作速查卡（Quick Reference Card）

> 这份卡片把 6 本必读 guide 的核心规则压缩成一页。**低费用模式（costMode: low）和子代理写作时，只读这一页，不读全套 guide 全文。** 完整原理与改法见卡片末尾指出的原文。

---

## 零、成本配额卡（动笔前定，写的时候就满足）

> 大模型的 AI 味不是"无能"而是"默认倾向"：默认拆短句、默认用"一+量词"泛化指代、默认把对话写成短促信息交换。它**有能力**写长句、**有能力**写完整发言，只是不会主动写。给出配额，它就会写。
>
> **⚠️ 这张卡必须"三栏齐全"，缺一栏就会挤出问题**（实测：只列"要补什么"的版本，会让明喻从 1.1 冲到 2.38、身体部位从 0.5 冲到 1.19、情绪词归零——**注意力是零和的，没被写进配额的项目会被写进配额的项目挤出去**）。

```
本章写作配额（写的时候就满足，不要等事后来修）

【一、必须补足的】
· ≥5 处 ≥60 字的复合句：把同一时刻／同一动作链／同一观察对象打包进一句
  （人类 4.7–19% 的句子是超长句 → 3000 字章约 5–17 句。**"2–3 处"是底线不是目标**）
· **≥1 句 ≥100 字的超长句**（长度上沿）：人类章 73% 都有，AI 章只有 22%
  （实测窗口级：人类最长句中位 112 字、p90 166 字；AI 中位只有 79 字）
  ⚠️ 是"把一个复杂处境整个塞进一句"，不是堆形容词——配方见 human-rhythm.md 规则 3
· ≥1 处 ≥30 字的完整发言（讲道理/诉苦/回忆/辩解），不是短促应答
· 具体数字 ≥1.5 次/千字（时间/距离/数量/钱），不要用"一会儿""很远"糊过去

【二、必须压住的】
· "一+量词"泛化指代（一个人/一张脸/一群人）≤ 8 次/千字 → 换具体数字或专有名词
· 明喻（像/如同/宛如/仿佛）≤ 1.3 次/千字 → 多写白描；全是明喻＝比喻审美均质化
· 身体部位（后颈/喉咙/手指/胸口/太阳穴…）≤ 0.9 次/千字 → 情绪别全靠身体反应
· 破折号 ≤ 3 处／章 → 补充信息并入主句，不要用破折号补刀
· 句首代词 ≤ 15%
· 平均句长压住 **23–37 字**（人类实测均值 30.8）——**低于 23 字就是碎句风格，18 字只是及格底线**

【三、区间项（不是越低越好，归零同样是 AI 味）】
· 情绪词 0.25–0.5 次/千字（取中值 0.35 最稳）—— 不能是 0（归零＝过度克制，人类会直说情绪）
· 节奏：每 3 个 500 字段落里句长均值要有起伏（紧张段全短句，抒情段长句铺陈）
  —— 只补长句会让节奏变均匀，这条是防它的

【四、加法配额（抗 hack：有没有是二元的，多不多一定会被 hack）】
· 至少 1 处「叙述者知道但没说」或「角色不知道」—— 人类会不解释，AI 会把一切补全
· 2–3 处**删了故事完全不变**的小细节（一个用过就扔的东西／一段无人的环境／一次没有后果的小动作）
· 主角至少判断错一次，或漏一环，或先往错的方向想
· 对话里 1–2 处不完美：结巴／改口／说到一半被打断／称呼叫错
· 现实锚定计量 ≥0.05/千字（具体的钱数/门牌号/线路号/年级）—— 架空世界观豁免

【五、作者在场（★ 最重的一条，AI 结构性缺失）】
  AI 的叙述是**透明的**：只报告事件，不表态。人类的叙述里**站着一个人**。
  · **先定视角，再写句子**：这一章的叙述者是谁？他对这件事什么态度？
    （不耐烦／觉得好笑／心疼／看不下去——**有了态度，表态会自己长出来**）
  · **自检法**：写完把**引号里的对话全部划掉**，只读叙述部分，问「**这里有一个人吗？**」
  · 手段：叙述者评价（其实／居然／简直／毕竟）· 口语插话（说白了／反正／怎么说呢）
    · 叙述里吐槽（这货／欠揍／要命）· **叙述句里的 ？或 ！**
    （人类叙述部分 2.4% 是问句、3.2% 是感叹句；**AI 把 ?! 全放引号里，几乎 0**）
  · **表态 2–5 处/章**（不是下限！静场章 1–2 处即可）

  ⚠️⚠️ **三条硬约束（不加这三条，你就只是造了个模板）**：
  ① **禁止同构**——同类表态不得出现两次以上相同句式骨架。
     自检：把全章表态句抄一排，**有两句像同一个模子就删一句**。
     （实测反例：一个人形模板，三句连用——"这值得举报？"／"这算什么规律？"／"这算什么秋天？"，
       三位盲评评委各自独立地抓到了同一组）
  ② **必须挂钩**——每处表态要指着**本章的某个具体事件/细节/人物**。
     天气、季节、"有些人""这股味道"这类泛泛感慨 = 空转，删。
     判据：**这句表态在付什么租？**
  ③ **上限**：叙述 ? ≤3.5%、叙述 ! ≤8%、语气词 ≤3 处/章、禁止 `？！` 连用
```

> **实测边界（《第0号存档》第 11 章 A/B，三轮）**：本卡让**超长句 1.40→4.41（2.6×）、数字 0.31→1.55（5.4×）、量词 19.17→11.3、节奏CV 0.28→0.36、身体部位 0.55→0.89** 显著改善；但**14 项指标是耦合的，改一项会牵动别项**（补长句那轮把明喻从 1.1 挤到 2.38；补数字那轮情绪词归零），三轮都没能一次全达标。
> **结论：配额卡治"缺什么"很灵，治"耦合失衡"要配合一次批量精修。** 生产上按两段走——**生成时用配额卡把大头压住（干净的一半）→ 复跑脚本 → 只对残留的 2–3 项做一次批量精修**。别指望一张卡一次全绿。

**为什么必须前置**：事后精修 = 在已经膨胀到几百 k 的上下文里纠偏，贵 10 倍；生成时配额 = 一行字，让它一开始就写对。

> **两级口径（别搞混）**：配额卡里的数字是**生成时的目标，故意比脚本硬线更严**——量词 ≤8（硬线 10.5）、明喻 ≤1.3（硬线 1.5）、身体部位 ≤0.9（硬线 1.0）、破折号 ≤3 处/章（硬线 1.5/千字）、数字 ≥1.5（硬线 0.8）、平均句长 23–37（硬线 18）。
> **按配额写 → 天然不会碰硬线；按硬线写 → 只到及格线，读起来还是"达标但不像人"。**
> 唯一的例外是**区间项**（情绪词、明喻下限、节奏起伏）：它们不是"越低越好"，归零同样是 AI 味。
>
> **⚠️「底线当目标」是本 SKILL 最容易犯的错**：脚本里写 `hard=18`（低于 18 就不合格）是**底线**，真值区间 `22.7–36.6` 也在同一行；但一旦文档只把 18 抄出来给模型看，模型就会把它当目标，写到 18–22 就"觉得自己达标了"。**给模型看的数字必须是目标区间，不是硬线。**

## 一、写前声音预置（动笔前写三行，不许写完补）

1. **具体坐标**：本章哪 2-3 个具体物/数字锚定世界（不是"一个人/一些东西"，是"那件褪色的校服""半包受潮的火柴"）
2. **叙述者立场**：叙述者站谁、什么态度（有立场，不是摄像头）
3. **留白点**：哪一处不写透，让读者自己补

## 一之二、工艺四定（同样动笔前定，完整版见 `narrative-craft.md`）

**① 章末型（四型选一，写细纲时就定）**

| 型 | 占比 | 用在什么处境 | 落点 |
|---|---:|---|---|
| **甲 · 信息/结算** | 30% | 一个阶段刚结束 | 面板/任务提示/客观陈述，**具体到数字和名字** |
| **乙 · 关系余韵** | 27% | 本章实质是两人关系变化 | **一个小动作 + 一句对话，不上价值、不解释** |
| **丙 · 喜剧/反转** | 23% | 前面有紧张；或主角刚自以为是 | 紧张后**紧挨着**一句吐槽 |
| **丁 · 悬念** | 13% | 弧末/卷末；且能保证下章就回答 | 少用。**连续两章悬念型 = 违规** |

> **实测数据**：30 个真实章末的分类。**章末的主流不是悬念**——"每章都悬"是 AI 味。

**② 开场方式（★ 章首是"慢起"，不是"越抓人越好"）**
- **大多数章用「日常进入」**：起床、走路、坐车、吃饭、上班、检查装备（真人主力）
- **只有首章/卷首/新场景断开**才用「异常切入」或章首引子
- **实测 210 章：章首前 20% 的张力密度 1.20/千字，其余 80% 是 2.03/千字——人类低开高走。** 张力放在中后段，别堆在开头
- ✗ 每章都想着"抓人" → 伪张力（"她一推门，就知道今天要出事"）。**"抓人"= 让读者愿意往下读，不是"制造危险"**

**③ 情绪载体**
- 本章要有一次强情绪 → **先问"现场有什么东西能承载它"**，写那个东西的动作，**不写情绪词**
- 厌倦=把东西碾过 / 怀念=一段旧歌 / 心虚=反复检查门锁 / 舍不得=收起来不放回原位

**④ 章的性质（冲突章 / 静场章）**
- **实测 210 章：19% 的章节不含任何冲突**——**不是每章都要有人跟主角对着干**
- 静场章 = 关系推进 / 世界观展开 / 幽默落地 / 生活质感，靠**微妙**而不是**对抗**
- 静场章仍要有变化（关系/认知/位置至少变一样）；**连续两章静场 = 违规**；冲突章占比保持 70%+

**另外三件随时可做的小事**：
- **称呼**：关系推进时**改称呼，不改解释**（"陈总"→"汉升"），见 `dialogue-writing.md` 三之二
- **排版（默认档，不是配额）**：**一句一段**——人类 74.4% 的段落是单句段（重生啊 99%、超神 83%、惊悚乐园 41%），AI 只有 30–37%。**多句段是例外，要有理由（连续动作/连续细节/一口气推进）**；"说不下去"用省略号或 `·····`，**不要用破折号**
- **标点**：别只用逗号句号。省略号是作者签名（人类 2.7–17.3/千字，选一档并全书保持一致）；问号 ≥3/千字（对话里要有"提问"这个动作）
- **对话标签**：用「**道**」不用「说」——人类「道/说」= 4.7–99.8，AI 是 **0**。`韩萧道："……"` / `"……"他低声道`
- **异质材料**：可以把歌词/面板/文件/日记**整段贴进正文**（独立成行），那一段就是换气口

## 二、硬指标（写完跑脚本，退出码 1 = 不合格）

> **⚠️ 脚本全绿 ≠ 像人写的。** 脚本能测频率，**测不出同构、空转、有没有人**——那些要靠**独立质检子代理**（`review-agent.md`：同构测试／删除测试／作者在场测试／用力过猛测试，**只给纯正文**、不给它看规则）。

> **⚠️ 动笔前第一条：对话一律用中文全角引号 `“` `”`，不许用 ASCII `"`。**
> A/B 实测（2026-09-13）：四个独立子代理写出的初稿**全部**是 ASCII 引号，导致「句首引号占比」全部 **0.0%**——
> **exit code 1 完全由这个格式问题驱动，跟写得好不好无关**。写完先扫一遍引号，再跑脚本。

**基础九项（check_human_rhythm）+ 硬性句式闸门（check_aistyle，会 exit 1）：**

| 指标 | 目标 | 超了怎么改 |
|---|---|---|
| 句首代词占比 | ≤15% | 主语换名词 / 时间地点开头 / 省主语 / 对话先行 |
| 句首引号占比 | ≥15% | 对话先行，提示语后置或省略 |
| 平均句长 | **目标 23–37 字**（人类 22.7–36.6，均值 30.8）；**18 字是及格底线，不是目标** | 合并碎句：[谁+状态]→[动作]→[手段]→[结果]→[机制]→[推论]；读完觉得"这句只装了一个信息"就并进上一句 |
| 35 字以上复合句 | **每千字 12–14 句**（210 章实测）——3000 字章约 38 句 | 同上 |
| 破折号 | ≤1.5/千字 | 补充信息并入主句，不要破折号补刀；严禁"——不，"自我修正 |

| 对话占比 | 10%–40%（区间） | 太少补对话，太多转叙述 |
| **硬性句式（先否定再肯定）** | **「不是X，是Y」≤0.12/千字**、「不是X。Y是…」≤0.40/千字 | **这是 `check_aistyle.py` 唯一会让退出码变 1 的项**：把"不是X，是Y"改成直接陈述 Y，或把否定句独立留白（见 `human-exemplars.md` 技法三「故意不解释」） |

| 指标 | 人类基线 | 脚本硬线 | AI 典型 | 说明 |
|---|---|---|---|---|

## 三、情绪三种写法配比（不要只用身体反应）

- ① 直说（"他很愤怒"）→ 节奏紧的地方
- ② 动作/对话（"把杯子顿在桌上"）→ 要读者自己感受的地方
- ③ 身体（"太阳穴一跳一跳"）→ 情绪最强的一两处，限量

## 四、两个高频陷阱

1. **"一个+N"伪具体**：能用专有名词（人名/地名/品牌/型号）就别用"一个人/一个东西"。判断：这个 N 能不能换成别的？能 = 伪具体。
2. **高频短语固化**：同一个表达（如"声音闷闷的"）全书 ≤3 次，第 3 次起换说法。人类高频词是专有名词，不是通用词。

## 五、人味配额（每章数一遍）

- 毛边 ≥2 处（无关细节/跑题/无效对话）
- 废话对话 ≥1 处（删了故事不变差的闲聊）
- 比喻 2–4 个（至少 1 个非明喻）
- 叙述者插话 1–3 处（作者跳出来吐槽/埋梗/给数值，不是角色互相科普）

## 六、改写顺序（脚本报多项超标时）

1. 先改句首代词 → 句首引号、句长会连带变好
2. 再合并碎句 → 破折号补刀自然变少，超长句占比上来
3. 再调情绪配比 → 身体部位降、情绪词升
4. 最后精修比喻/动作/数字/伪具体 + 长对话补足

## 七、成本纪律（铁律九，每次都适用）

| 纪律 | 一句话 |
|---|---|
| **一次跑完全部脚本** | 一条命令跑完 4 个 check_*.py，**一次**读完整报告（≤4 次脚本调用/章，禁止逐个跑） |
| **一次批量改写** | 把报告里**全部**超标项一次改完，复跑一次确认（≤5 次文件改写/章，禁止修一项验一项） |
| **读一次复用** | 同一本指南读一次就记住，不重读；本卡已含核心规则，不必再去翻原文 |
| **不逐章重读** | 已读过的文件不重复读；需要时引用记忆中的结论 |

**调用预算**：10–18 次/章（standard）/ 6–10 次（low）。**>25 次 = 掉进微步循环，停手自查**（`python scripts/audit_tokens.py <项目目录> --chapters N`）。

> 实测：掉进微步循环的项目是 **63 次调用/章**，成本 45.4M tokens / 6 章，其中 **97.8% 是上下文重发**。**减的是次数，不是质检项——质检项一个都不能少。**
