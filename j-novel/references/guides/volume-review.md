# 卷末复盘闭环（Volume Review Loop）

**这是写作体系最缺的"反馈环"：写完一卷 → 知道哪里不行 → 修订 → 下一卷带着教训写。**

没有这个环，长篇就是"一路闷头写到完"，写完才发现第三章就该修。有了这个环，每一卷结束都是一次"体检"，下一卷自动变好。

---

## 触发时机

- **每卷结束**（或每 10-15 章，长篇）
- 作者主动要求复盘时
- Phase 4 校验发现"低潮区"（连续 3 章 < 65 分）时

---

## 复盘流程（五步）

### 第一步：数据收集（先看数字，不看感觉）

1. 本卷各章质量评分（`quality-scorecard.md` 汇总）——质量曲线哪里塌了
2. 节奏自检结果（Phase 3 内置的三种类型/三种风险）
3. 伏笔台账——本卷埋的伏笔，回收状态是否正常
4. 状态台账——人物状态是否有异常漂移

### 第二步：读者三层反馈（模拟真实读者）

以三种身份各读本卷（或关键章节）：

- **普通读者**：好不好看？想不想继续翻？在哪里想弃书？
- **挑剔读者**：找"疙瘩"——逻辑漏洞、反应不合理、转折没铺垫（`continuity-check.md` 的逻辑四查配合）
- **作者同行**：欣赏什么？如果是 TA 来写，会往哪个方向加码？

**产出**：每层读者的"反应清单"——特别标注"想弃书的瞬间"和"拍案的瞬间"，这比任何评分都重要。

### 第三步：诊断（把反馈翻译成病根）

对照以下维度定位问题：

| 反馈信号 | 病根 | 下一步工具 |
|---------|------|-----------|
| 连续平淡、无波澜 | 情绪曲线平（缺落差/蓄能） | mood-composer 方法论 |
| 越写越散、风格不统一 | 文风漂移 | 重抽锚点示例 |
| 逻辑被挑出刺 | 衔接/因果链问题 | continuity-check 四查 |
| 对话被说"像AI" | 对话无指纹 | dialogue-writing 自查 |
| 节奏一条直线 | 紧张/缓冲安排失当 | rhythm-check 方法论 |
| 没读下去的欲望 | 钩子失效 | hook-techniques 招式库 |

### 第四步：修订计划（输出可执行的清单）

每条问题按"当前问题 → 调整方向 → 预期效果"三句式输出，标注优先级：

```
P0（必改）：第 8 章悬念线断更 → 第 13 章前补一段推进 → 读者重拾追踪欲
P1（应改）：第 5-7 章连续低张力 → 第 9 章安排小高潮（十色爽点）→ 打破低潮区
P2（下卷改）：人物配角弧光不足 → 下卷给配角加支线 → 人物网更立体
```

**P0/P1 立即执行**（修订相关章节），P2 写入圣经"下卷规划"。

### 第五步：更新档案（让教训进入体系）

1. **更新圣经**：伏笔状态机、角色弧光实际进度（Bible Updater 的活）
2. **更新状态台账**：人物终态、时间线推进
3. **写入资产库**（`asset-vault.md`）：
   - 本卷最大失误 → 教训库（下个作品预判规避）
   - 本卷最强章节片段 → 文风资产库（可作后续锚点）
   - 读者"拍案瞬间" → 灵感库（知道读者吃哪套）

---

## 复盘报告格式（向作者交付）

```
📋 《[小说名]》第 X 卷复盘报告

质量曲线：平均 [X]/80（第X章最高 [Y]，第X章最低 [Z]）
读者反馈：普通读者 [1-2 句] / 挑剔读者 [1-2 句] / 同行 [1-2 句]

病根诊断：[1-2 条核心问题，不列琐碎]
修订计划：
- P0 [必改]：[问题 → 调整 → 预期]
- P1 [应改]：[...]
- P2 [下卷]：[...]

档案更新：圣经 ✓ 台账 ✓ 资产库 ✓（教训 2 条 / 文风 1 段 / 灵感 1 条）
```

---

> **一句话**：卷末复盘 = 给作品做一次全身检查 + 把检查结果存进病历。下一卷动笔时，先翻病历，别再犯同样的病。
