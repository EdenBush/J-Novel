# 置信度绑定：读完必须选中一个出口

**这份指南存在的理由：读到"这章不太行"却继续往下走，是长篇创作里最贵的动作。**

一次没有选中出口的估计不是监控，是评论。

---

## 一、三档读数

质检七件事做完后，给这一章定一档。取**最差**的那一项，不取平均。

| 读数 | 触发（任一条命中即定档） | 义务 |
|---|---|---|
| **稳** | 人侧 ≥7 项 且 质量评分 ≥70 且 无未决杠精点 | 放行，正常收尾 |
| **薄** | 人侧 4-6 项 / 评分 65-69 / 有 1 个未决杠精点 | **在质检档案点名最薄的一项 + 理由**，然后放行 |
| **晃** | 人侧 ≤3 项 / 评分 <65 / retryCount ≥2 | **禁止原路重走。** 三选一，见下 |

**"薄"那一栏的"点名"不是形式。** 写"衔接有点弱"不算；写"第 4 节苏晚进门的情绪接不上第 3 节结尾的沉默，因为她刚得知消息就恢复常态"才算。点名一次，后面想偷懒就偷不掉了。

**别表演置信度。** 一次排练出来的"我不太确定"和排练出来的笃定一样假，而且更有腐蚀性——它看起来像谦逊。如果这一整轮你的读数都是同一档，那你不是在读数，你是在盖章。

---

## 二、三个出口（必须选中且仅选一个）

### 出口 A — 信任它

读数"稳"，或"薄"且已点名。放行。把读数写进 `04-质检档案.md`。

**通过也是结果。** 记下来，别让"这章没问题"变成没有痕迹的一句话。

### 出口 B — 带诊断重试

读数"薄"但有明确病灶，或"晃"但病灶清楚。

重试指令（或子代理任务包）的**第一行**必须写：

```
诊断：<一句话，上次到底错在哪>
本稿必须不再犯：<一句话，可判定的>
```

- ❌ 坏诊断：`诊断：AI 味重` —— 没法判定，下一稿照样犯
- ✅ 好诊断：`诊断：第 4-6 段全是总结式心理（"他意识到""他感到"），没有身体反应` / `本稿必须不再犯：这三段情绪全部通过动作和身体传递，不出现任何情绪词`

**不带诊断句的重试 = 同一个尝试，成本一样，收益为零。** 换子代理时，诊断句随任务包一起给新人——不然新人是在不知情的情况下重犯旧错。

### 出口 C — 换路，然后对账

**`retryCount == 2` 时强制。**

禁止沿用上一稿的场景顺序与开场类型。做法：

1. **用不同原语重述。** 用 200 字把"这一章要完成的三件事"重新说一遍，换一套词汇：
   - 从"场景清单" → "人物在这一章失去了什么 / 得到了什么"
   - 从"情节推进" → "这一段要让读者误会什么"
   - 从"情感基调" → "读完这一段，读者身体上是什么感觉"
2. 按新说法重新动笔，不参考上一稿的段落结构。
3. **对账**：新旧两稿并排放，只比一件事——**哪一稿读起来像同一个作者写的。** 情节完成度是第二位的；风格断裂比情节偏差更致命，因为它整本书都在流血。

---

## 三、第三次撞墙：问题被错误框架化了

**`retryCount == 3` → 停止自动修复，向用户上报。**

同一堵墙撞第三次，说明不是解法错了，是**问题被错误地定义了**。这时候再撞第四次不会突然通。

上报必须附：

```
⚠️ 第X章已重试 3 次仍未通过
三次诊断：①… ②… ③…
两个版本的核心差异：…
我的建议：[改大纲 / 降标准 / 换 POV / 这一章本来就不该存在]
→ 需要你决定：接受现状 / 降标准 / 改大纲 / 换人工
```

**不要"保留记录但不阻塞流程"。** 那等于把全书最难的一章悄悄埋掉，读者会在那里绊倒。

---

## 四、什么情况下停下来问用户

| 情况 | 动作 |
|---|---|
| 读数"晃"且两个出口都不适用（病灶不明） | 停下，把病灶不明这件事本身告诉用户 |
| retryCount == 3 | 停下，按上面格式上报 |
| 崩坏红线命中（见 execution-contract 第六节） | 先跑五拍恢复，恢复后仍不行 → 上报 |
| 故事方向的重大分歧 | 停下。这是作者的书，不是你的 |

**停下来的门槛是：继续下去会不会浪费作者的时间。** 会，就停。

---

## 五、自检

写完一章，问自己三个问题：

1. 我的读数是**在**质检之后、**在**决定之前给出的吗？（事后补的那叫注解，不叫读数）
2. 我选了出口吗？选了哪个？说得出来吗？
3. 如果是出口 B，诊断句在哪一行？能判定吗？

三个都答得出，这一章的监控是真的。
