# 占位式改写：把"不要写 X"换成"这里放 Y"

**一句话原理：提到即激活。**

对语言模型的实测有一条很反直觉的结论——**告诉模型"不要想 X"，X 的激活度远高于完全不提它**；而**仅仅"提到"一个概念，激活度几乎等于"要求聚焦"它**。

也就是说：**"不要写'不是X而是Y'"这九个字，本身就是一次写入。**

这不是玄学，它有可观察的后果：deai 反复清洗仍在同一处复发，往往不是能力问题，是**每次清洗都先把那个句式念了一遍**。

## 二、改写对照表

执行清洗与修改时，用右列的说法，不要用左列：

| 现状（禁止式） | 改为（占位式） |
|---|---|
| 不要写"不是 X，而是 Y" | 这一句只放**一个断言**，重点放句首 |
| 不要"没有…没有…" | 这一句放**一个具体动作**，剩下的删掉 |
| ~~不允许出现情绪词汇~~（**该规则已废止**） | 三种写法**混用**：直说（`他很愤怒`）/ 动作（`"我没生气。"`）/ 身体（`太阳穴一跳一跳`）。**情绪词 0.25–0.5/千字，低于下限同样不合格** |
| ~~不允许"他意识到/他感到"~~（**该规则已废止**） | 保留直说也行；要演出就写他**注意力飘到了哪儿**（无关联想、环境细节、一句跑题的念头）。**判据是一章里不能只有"身体反应"一种** |
| 不要"仿佛 / 似乎" | 这个比喻要挂在一个**私人记忆**上（她七岁那年、小学门口那家店） |
| 不要三段排比 | 这一段只留**一个**比喻，其余用动作补 |
| 不要每句话都有潜台词 | 这一段要有 **1-2 句**删掉故事不变差的废话 |
| 不要每章都从高潮炸开 | 这一章从上一章最后一幕的**同一个时空、同一个情绪**接进去 |
| 不要"如你所知"式科普 | 这条信息通过**一次冲突**露出来，让角色吵着说出来 |
| 不要结尾都画句号 | 这一章停在**一个动作做到一半**的地方 |
| 对话不要太干净 | 这一句加一个**填充词**，或让他说半句就改口 |
| 对话不要都推进情节 | 加一句**纯粹的寒暄**（"外面下雨了。""嗯。"） |

## 三、时机：念清单的时机会毁掉清洗

**最坏的时机，是刚读完禁用清单就动笔改。** 那时候那些句式正亮着。

所以 Phase 3 的流程里有一条硬约束（现在写进这里，强制执行）：

```
写初稿 → 关掉质检脑（不读清单）
   ↓
质检（这时才读清单，读是为了定位，不是为了记住它）
   ↓
修改 ← 危险区：清单刚念完，禁用结构正在激活
```

**修改前的三秒动作：** 合上清单，只带着**占位句**进入修改。

```
❌ 不要带着这个进修改："别写'不是X而是Y'，别写情绪词，别用三段排比"
✅ 要带着这个进修改："第 4-6 段，每一句换成身体动作；比喻只留一个"
```

**一句诊断 + 一句占位指令，胜过一整张禁用清单。**

## 四、给子代理的写法

派发子代理时，任务包里**不要**附一整张 AI 味禁用清单让它"注意避免"。改成：

```
本批已知病灶（上一批出现过）：
1. 第 3、7 章出现总结式心理（"他意识到…"）
   占位指令：情绪一律通过身体反应和动作传递，不出现情绪词
2. 第 5 章对话过干净
   占位指令：每段对话至少有一处填充词、口误或没接上的半句
```

**只给这一批真正出现过的病灶，配占位指令。** 给全清单等于把全书所有 AI 味句式在子代理动笔前念了一遍。

## 五、自检

1. 我刚才对自己（或对子代理）说的这句话，是**排除**还是**占据**？
2. 如果说的是"不要 X"，能不能换成"这里放 Y"？换成什么？
3. 我是在**动笔之前**念的清单，还是**定位之后**才念的？

**排除是把注意力放在不要的东西上。占据是把注意力放在要的东西上。** 后者才写得出东西。
