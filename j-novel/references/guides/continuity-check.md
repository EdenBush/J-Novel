# 连贯性防护：让每一章都接得上

**这份手册直接回应"上文不接下文、剧情出 BUG、逻辑不顺"——长篇小说的头号死因。**

根源几乎都是同一个：**大纲太简略**（每章只有一句"核心事件"），写作时角色状态、时间线、悬念线全凭记忆，写high了就跟前文脱节。融合版的解法是三层防护：**写前有锚点、写中有对照、写后有检查**。

---

## 一、写前必读（每章动笔前，Phase 3 步骤 1 强制执行）

1. **读上一章结尾**（不是大纲摘要，是正文最后一段）——确认：
   - 上章停在什么画面/情绪/悬念上？
   - 本章开头要从哪里自然接起？（不是"上一章我们说到"式硬接，是情绪和场景的顺滑延续）
   - **判定本章「开场类型」**：若无刻意场景断开（同场景 / 同时间线 / 同 POV），**默认「续接型」**——直接从上一章最后一幕的同一时空、同一情绪接着写，不另起炉灶、不重设钩子、不写章首引子；仅当换地点 / 时间跳 / 切 POV / 刻意断场景才标「新起型」并启用钩子开场（见 chapter-craft.md「续接优先」）。**这条是根治"章章跳脱"的关键：绝大多数续接章不该被剪断重接。**
2. **对人物状态**：本章所有出场角色的——位置（人在哪、怎么到的）、情绪（上章结尾什么心情）、关系（有没有变化）、已知信息（TA 知道什么、不知道什么）
3. **对时间线**：上章结束是什么时候？本章开始是什么时候？有没有跳跃？跳了的话读者能跟上吗？
4. **对悬念线**：上章立的钩子，本章要不要回应？还有哪些悬而未决的线在本章应该推进？

> **大纲字段不全时禁止动笔**：如果 `01-大纲.md` 本章只有一句"核心事件"，先停下来，把本章规划补全（衔接锚点、人物状态、悬念钩子、伏笔操作）再写——**带病开工是 BUG 的源头**。

## 二、逻辑 BUG 四查（质检时强制执行）

### 1. 因果链
- 事件 A 导致 B，是真的"必然导致"，还是作者为了让剧情走下去硬推的？
- **嫌疑信号**：巧合推进（刚好路过、刚好听见、刚好捡到）、角色突然降智（本来聪明的人犯低级错误只因为剧情需要）
- **判定**：删掉这个巧合，剧情还成立吗？不成立 → 补铺垫或改逻辑

### 2. 人物动机
- 角色为什么这么做？动机符合 TA 的档案设定（性格/目标/恐惧）吗？
- **嫌疑信号**：角色做出反常行为但没有任何弧光铺垫、配角为了服务主角强行犯错
- **判定**：如果是弧光转变，前文有铺垫吗？没有 → 要么加铺垫，要么改回符合人设的行为

### 3. 信息一致性
- 角色会"忘记"自己知道的事吗？读者记得的，角色不能忘。
- **嫌疑信号**：角色上章刚知道的关键信息，本章讨论时像不知道；角色上章受伤，本章健步如飞（除非有交代）
- **判定**：以正文实际呈现的信息为准，逐人核对

### 4. 世界规则
- 有没有打破圣经里已建立的规则？（魔法代价、力量体系、社会制度、时空设定）
- **嫌疑信号**：为了救场临时加设定、规则前后矛盾
- **判定**：设定冲突时，要么遵守圣经，要么回圣经改规则（并在卷终由 Bible Updater 记录）

## 三、衔接三查（质检时与 BUG 四查并列执行）

1. **开头承接**（按开场类型检查）：
   - **续接型**：本章第一段/第一场景必须从上一章最后一幕的同一时空、同一情绪延续切入——可接半句对话、接一个动作中段、接沉默余波。**禁止另起炉灶、禁止重设钩子、禁止为了"即时冲突"硬让续接章开头突然爆炸。** 这才是连贯的正解。
   - **新起型**：允许独立钩子开场，但仍需在开头或引子里与上章的悬念/情绪线"接一根线"（哪怕是反差式承接），避免读者觉得"上一章被一刀剪断"。
   - 共同红线：有没有突兀的硬切（且不是有意设计的蒙太奇）？
   - **⛔ 场景重述红线（新增，硬性）**：**禁止把上一章已经写过的场景重新叙述一遍。**
     "续接"是从上一章结尾**之后**的第一个新动作开始，不是把上一章结尾**再写一次**。
     必须回溯时用一句话带过（"那天下午的事我后来想了很多遍"），不要重演。
   - **🔗 钩子桥接（新增，硬性）**：上一章结尾如果留了悬念钩子（某人盯上主角 / 某人被抓 / 一个未完成的动作），本章开头**必须给这个钩子一句交代**——哪怕只有一句"疤脸那夜没动手"或"他盘算了一夜"。
     **判据**：把上一章结尾的最后 200 字读一遍，找出"悬在那里的那个人/那件事"；再读本章开头 500 字——那个人/那件事出现了吗？没出现，就是**钩子被晾了一章**。
     **例外**：钩子被刻意推迟到后章时，必须在大纲/细纲里显式标注"此钩子第X章回收"，否则读者会以为你忘了。
     > 这是并行写作最容易漏的一条：第 4 章的子代理照着细纲写"塞拉芬娜的日常章"，却忘了第 3 章结尾还悬着一个"疤脸霍恩盯上诺瓦"。**钩子桥接不是细纲能代劳的——它是每章开头必须自查的一步。** 跑 `check_continuity.py` 可以自动扫出"上章结尾的人物在本章开头缺席"的边界。
2. **人物状态连续**：出场角色的位置/情绪/关系/能力，与上一章结束时一致吗？
3. **伏笔登记**：本章埋的伏笔/回收的伏笔，是否同步登记到 `01-大纲.md` 伏笔对照表？遗漏 = 后期必然断线

### 场景重述红线：判据与后果

**为什么单列**：这是实测出来的真实事故，而且**逐字重合率很低，查重查不出来**。

AI-A《反派少爷》第 12 章结尾与第 13 章开头：

```
第12章：暑假第一天，阳光把九条宅的泳池晒成一块会反光的玻璃。我穿着泳裤站在池边……
        管家走出来："少爷，小夜小姐来了。"……"九条君，暑假快乐。"
第13章：暑假第一天，阳光把泳池晒成一块会反光的玻璃。我穿着泳裤站在池边，脚趾踩着发烫的瓷砖……
        管家站在回廊的阴影里："小夜小姐来了。"……"九条君，暑假快乐。"
```

- **逐字 6-gram 重合率只有 0.8%** —— 不是复制粘贴，是**换了一批词重新写了一遍**
- 但叙事上是**同一个节拍讲了两遍**
- 而且细节产生了矛盾：第 12 章小夜提"竹编盒子"、出现在**泳池边**；第 13 章是"浅蓝色布包"、到**客厅**

**判据（写完本章开头后自测）**：本章前 300 字与上一章最后 800 字，是否描述了同一个事件序列？
是 → 删掉重述部分，从上章结尾之后的第一个新动作开始。

**后果**：读者感觉"这章开头我好像看过"，而且重述时极易产生细节不一致，直接制造连续性 BUG。

## 四、常见断档场景清单（写作/质检时对照）

| 断档类型 | 例子 | 防护 |
|---------|------|------|
| 角色凭空出现/消失 | 上章在城东，本章开场在城西，没有交代 | 写前核对位置；写中提一句移动 |
| 已知信息遗忘 | 上章知道凶手是谁，本章分析案情像不知道 | 信息一致性检查 |
| 时间跳跃错误 | 上章是春天，本章人物说"去年冬天"但其实是同一年 | 时间线核对 |
| 悬念线断更 | 上章立的钩子，五章没人再提 | 悬念线检查（短弧 2-3 章必收） |
| 规则被打破 | 设定里魔法有代价，本章主角随便用 | 世界规则检查 |
| 情绪断层 | 上章结尾悲痛欲绝，本章开头若无其事 | 人物状态检查（除非是刻意的麻木设计） |
| 关系倒退 | 上章已经和好，本章又像陌生人 | 人物状态检查 |
| 巧合推进 | 主角刚好在关键时刻遇到关键人物 | 因果链检查（改铺垫或加代价） |

---

## 五、质检摘要中的记录格式

在【本章质检摘要】中追加两行：

```
衔接检查：通过（承接上章：[一句话]）
逻辑检查：通过（BUG 四查：因果/动机/信息/规则）
```

有问题的章标记为：
```
衔接检查：⚠ 未通过 — [具体问题]，已修复 / 待修复
```

---

> **为什么这份手册存在**：Chinese Novelist 的大纲只有"核心事件"一句话，章与章之间靠 JSON 状态硬撑，写长了必然断档。Reasonix 的细纲其实有「衔接锚点/人物状态追踪/伏笔清单」——但只在细纲里，没变成强制检查。融合版把这两者的精华提炼成**三道强制关卡**：写前锚点（步骤 1）、写后四查（步骤 3）、登记闭环（伏笔表）。只要不跳关卡，长篇就不会"断"。
