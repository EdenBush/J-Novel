# 改写单元（Rewrite Units）—— 从"改对指标"到"改好文本"

> **一句话**：这本指南**不教你新的改法**，它管的是**改之前那一步**——
> **用哪种粒度改、动哪一段、什么不许动**。
>
> **改法的招式在 `rewrite-playbook.md`（11 节）；工序在 `post-polish.md`（4 道）。
> 本指南给的是**路由表**与**边界声明**。**

---

## 零、为什么需要这一本（把诊断摆出来）

### 0.1 现状：整个改写体系只有"句级"这一档

| 位置 | 它给了什么 | 粒度 |
|---|---|---|
| `rewrite-playbook.md` 的 **11 节** | 每一节都是**逐项句级改法**：句首代词／句首引号／平均句长／破折号／身体部位／情绪词／明喻／动作短语／数字密度／「一个+N」／抽象句 | **句级** |
| `post-polish.md` 的 **4 道工序** | 长句缝合／定指替换／长对话补足／节奏起伏 | **局部**（合并几个短句、替换几个指代、扩写一段对话、调一段节奏） |

**每一件工具的对象都是"句子"或"句子的邻域"——整个体系没有一档工具的对象是"段落"。**

### 0.2 纪律 3 原文，以及它为什么会变成全链纪律

`post-polish.md`「三、执行纪律」纪律 3 的原文是：

> ### 纪律 3：只改写，不重写；只加不减
>
> - 精修阶段**禁止"重写整章"**——重写会引入新一轮 AI 味，等于白做
> - **只做局部改写**（合并句子/替换指代/扩写对话/调段落节奏）
> - **不许为了达标删掉好内容**——指标是"补"的指引，不是"删"的许可

**这条纪律本身是对的**：它写在《4 道精修工序》那一章的「执行纪律」里，
防的就是"跑完脚本、看到一串超标，于是把整章重做一遍"。

**但它没有写作用域。** 而 `grep -rn "重写" references/guides/*.md` 的结果是：
**除这条纪律之外，没有任何一处提供"重写"这一档工序**
（唯一另一处提及是 `review-agent.md` 第五项 5B 失败的处置「整章重写」——
那说的是"回生成端重做"，**同样没有工序、没有边界**）。
于是这条**只该管四道工序**的局部禁令，读起来就是**全链禁重写**。

这不是第一次。`skill-mechanics.md` 的反模式表已把这一类错误单列成一条，
**并明确写了它在本 SKILL 已经发生两次**：

1. **v6.5.0**：把 `不是` 加进**全局排除表** → 排除词没限定对象 → 立刻漏掉一条真问题；
2. **2026-10-01**：`Do not ask clarifying questions` **无作用域限定** →
   第一层通用指令压住第二层流程 → **吞掉整个 Phase 1 采访阶段**。

> **修法是"限定作用域"，不是"删掉纪律"。**
> 本指南第二节给纪律 3 补作用域；`post-polish.md` 就地写明它管什么、不管什么。

### 0.3 唯一的重写出口是一个外部子技能

体系里**唯一**被当成"重写"用的东西，是外部子技能 `reasonix-novel-write-master`，
触发词是「**没毛病但差口气**」。三个问题：**模糊**（"差口气"是什么程度？）、
**无定位工序**（不知道该动哪一段、动多大）、**无边界声明**（不知道什么不许动）。
**它是个出口，但不是一档可执行的工序。**

### 0.4 而"文笔还是很 AI"的主要表现，恰恰是段级的

`SKILL.md` 里 v6.9.0 留下的原话，说的正是**段级**的症状：
整段"**每句都在干活、没有一句是为自己写的**"。
同一层级的典型表现还有：**章末落笔公式化**（`hook-techniques.md` 实测 5 章全部落在
「叙述一句 + 留点余味」上）、**角色一个腔调**、**通篇平**。

### 0.5 一句判据

> **段级的问题用句级工具改，就是改不动。**

你可以把一整段里每一个超标项都压进区间——句首代词降到 5%、破折号清零、「一个+N」全换掉——
**这一段读起来还是"每句都在干活"**。因为那不是"哪一句"的问题，
是**这一段怎么组织**的问题，而**句级工具改变不了一段话的组织方式**。

### 0.6 与 `rewrite-playbook.md` 的分工（写死）

```
playbook = 逐项"知道超标之后怎么改" → U1 / U2 / U3 的招式库（11 节）
本指南   = 先决定"用哪种粒度改、动哪一段、不许动什么" → U1–U6 的路由表
顺序     = 先在本指南选单元 → 再用 playbook 的招
```

**两个都要用。** 本指南**不重讲任何一招**——它只在"该用哪一档、边界在哪"这一层做事。

## 一、六种单元（总表）

> ★ **这是全文件最重要的一张表。**
> 六个单元对应**六层病灶**：频率层偏低 / 频率层偏高 / 本体层 / 声音层 / 结构层 / 语感层。
> **编号与名称是接口契约**（跨 agent 共享），**一个字都不许改**。

| 单元 | 治什么 | 允许动什么 | ★ 不许动什么 | 粒度 | 改后怎么验 |
|---|---|---|---|---|---|
| **U1** 句级·插入 | 频率层**偏低**：平均句长／超长句／数字密度／情绪词／长对话 | 在**现有句子之间**插入新句子（铺陈句、环境句、身体感受句、数字、一段完整发言） | **不许删原句**（原句逐字仍在）；**不许改写原句措辞**（与原文字符级一致）；**不许合并原句**（原句边界不被并入他句） | 句（插入点） | 复跑 `check_human_rhythm.py`，被治的那几项**从"偏低"进入区间**；且原句 diff 为空 |
| **U2** 句级·替换 | 频率层**偏高**：句首代词／破折号／中文量词／身体部位／动作短语／「一个+N」 | 在**句内**替换词组、换主语、并句、拆句、把标签动作换成具体动作 | **不许删句**（删了信息就丢）：段内句数不减，且**逐句信息点在改后仍能一一对应**；不许改对白的信息内容 | 句 | 复跑脚本，被治项**从"超标"降回区间**；句数不减、信息点逐条可对 |
| **U3** 句级·换物 | **本体层**（脚本测不了的那一层）：通用件、抽象句 | 把句内的通用名词换成**只属于这本书的实物**；把抽象句**落到一个可感载体上**（设定**不删**，改走实物出场） | 不许改**事件与情节走向**；不许改**人物状态**；**不许删设定**（改前句中的设定名词，改后必须仍在句内、或以它的可感载体出现） | 句 | 可替换性四问（换名／换书／删句／复述），由**独立质检子代理**跑（`specificity-gate.md` 第三节） |
| **U4** 对话段·重写 | **声音层**：角色一个腔调、功能性短句（对谁都能说、而且什么都说了） | 重写**台词本身**的措辞与节奏：可打断、可躲避、可延迟、可只答一半、可加填充词 | 不许改对白的**信息内容与结果**（改前列出信息点／谁说服了谁／谁答应了什么，改后逐条勾）；不许**新增**人物过往、关系温度、口头禅（改后出现的每个人名/地名/事件/称呼，必须能在**前文或人物档案**里找到出处）；不许改**说话人** | 对话段 | 声口压力测试七问（`character-voice.md` 第四节）+ 信息点表逐条核对 |
| **U5** 段落级·重写 | **结构层**：章末落笔公式化、开场同质／空镜、整段"每句都在干活" | 重写**这一段（或这一处）的"落笔"**：用词、句式、落点形态 | 不许改**章末型**（细纲「章末型」字段不动）；不许动**伏笔**（伏笔表登记项逐条仍在本文）；不许动**接口契约**（`_meta` 实物清单承诺项仍在、交接段首末段的事件不动）；不许增删**事件** | 段 | ① **功能对账**：重写后这一段的功能与重写前**逐字相同** ② 复跑脚本 ③ 章末型字段未变 |
| **U6** 段群·重写 | **语感层**：通篇平、白开水、节奏全程一个带 | 重写**连续 2–4 段**的整体语感：句长起伏、叙述距离、松紧配比 | 不许改**情节**（事件清单逐条仍在）；不许改**人物状态**（在场者、知情范围、伤势/情绪取值不变）；不许动**交接段首末段**（范围声明里的段号区间不得包含章首段与章末段）；不许改章末型；不许增删事件与信息 | 段群（2–4 段） | ① 复跑脚本（平均句长／句长 CV／节奏 CV）② 与相邻段对比"句长带"是否错开 ③ 事件清单逐条核对 |

### 1.1 一条总则：**「允许动什么」和「不许动什么」一样重要**

以前只写"不许动什么"，结果是两种失败：**保守**——Agent 不知道"动的额度"有多大，
于是**达标即停**，指标一进区间就收手，段级的问题原样留着（改它需要动一整段，
而没人为"动一整段"发过许可）；**越界**——Agent 想改好，顺手把伏笔、契约、
章末型一起动了，**改坏的是别的东西**。

> **边界声明有两个作用：给出许可的额度，同时划出禁区。**
> 只写禁区 = 只会让 Agent 更保守；只写许可 = 越界。
> 所以本指南的每一行都成对写，而且**「不许动什么」必须可判定**——
> 不能写成"要有感情""要自然"这类**没法查**的边界。

## 二、★ U5 / U6：重写档（本指南新增的那一档）

### 2.1 先说清与 `post-polish.md` 纪律 3 的关系

这是全文件最需要小心的一段，所以原文照引——`post-polish.md`「三、执行纪律」纪律 3 的完整原文：

> ### 纪律 3：只改写，不重写；只加不减
>
> - 精修阶段**禁止"重写整章"**——重写会引入新一轮 AI 味，等于白做
> - **只做局部改写**（合并句子/替换指代/扩写对话/调段落节奏）
> - **不许为了达标删掉好内容**——指标是"补"的指引，不是"删"的许可

**它的作用域**：只适用于 `post-polish.md` 的**四道精修工序（工序 1–4）**。
那四道——长句缝合／定指替换／长对话补足／节奏起伏——**全部是局部改写**，
对它们说"禁止整章重写"是对的，理由也是真的：
**跑完脚本一冲动把整章重做，等于回到粗胚，新一轮 AI 味原样长回来。**

**U5 / U6 不是这条纪律管的对象**，因为它们**不是裸重写**：

| | 裸重写（纪律 3 禁止的） | U5 / U6（有边界的重写） |
|---|---|---|
| 保留什么 | 什么都不保证 | **保留功能 / 事件 / 信息 / 接口** |
| 动什么 | 整章、全部 | **只动"文字本身"**（落笔、句长起伏、语感） |
| 范围 | 整章 | **单段 / 连续 2–4 段**（不许一次重写整章） |
| 怎么验 | 没有验法 | **功能对账 + 复跑指标 + 契约项逐条核** |

**更要紧的一层是机制**：

> **没有作用域的否定式指令，会被当成全链纪律。**

本 SKILL 已经发生过两次，两次都写进了 `skill-mechanics.md` 的反模式表：

1. **v6.5.0**：把 `不是` 加进全局排除表 → 立刻漏掉一条真问题；
2. **2026-10-01**：`Do not ask clarifying questions` 无作用域限定 →
   第一层通用指令压住第二层流程，**吞掉整个 Phase 1 采访阶段**。

**纪律 3 是同一类。** 它写在一份文件的「执行纪律」里，内容是"禁止整章重写"，
**全文再没有第二处提供"重写"这一档** —— 于是它事实上成了全链禁重写。
**修法是限定作用域，不是删除它**（`post-polish.md` 已就地补上限定）。

### 2.2 U5 怎么做（段落级）：四步，顺序不能换

**定位**：先确定**动哪一段**。三种典型对象：
章末落笔那一处、开场那几句、整段"每句都在干活"的那一段。

```
① 写出这一段的【功能】——一句话
   （例："这一段的功能是：让读者知道他不是不想走，是走不了。"）

② 找出这段里【必须保住的东西】，逐条落到纸面：
   · 伏笔（伏笔表登记项：物件名／事件名）
   · 接口契约（`_meta` 实物清单的承诺项、交接段的接缝事件）
   · 信息（读者读完必须知道的、不能少的事实）
   · 人物状态（在场者、知情范围、伤势/情绪取值）

③ 只重写【落笔】——用词、句式、落点形态。
   ⚠️ 这一步里①②列出的东西一个都不许碰。

④ 重写后与【功能】对账
   （把重写后的这一段再读一遍，问：它做到①那句话了吗？
     功能对不上 = 这一轮作废，回到③重写）
```

**为什么必须写①**：不写功能，重写就没有验收标准——Agent 只能拿"读起来更好了"当验收，
而那是**不可判定**的；写了功能，验收变成**可判定**的：重写后的段落**做没做到那件事**。

**为什么必须写②**：U5 是唯一会"动一整段"的操作，是**改动量最大**、
也**最可能改坏伏笔/契约**的单元。②就是它的护栏——**逐条写下来的东西才守得住**，
心里的"我会注意的"守不住。

### 2.3 U6 怎么做（段群级）：同四步，对象换成"这一章的语感"

U6 的①②③④与 U5 完全同形，只有对象不同：
**U5 对的是"这一段"，U6 对的是"连续 2–4 段的语感"。**

**U6 的"保留什么"清单（照抄这七项，逐项勾）**：

| # | 保留项 | 怎么算保住（可判定） |
|---|---|---|
| 1 | **事件清单** | 重写前列出这一段群有哪几件事，重写后逐条仍在 |
| 2 | **人物状态** | 在场者、知情范围、伤势/情绪取值不变 |
| 3 | **接缝** | 与上一段的接续方式、与下一段的衔接点不变 |
| 4 | **章末型** | 段群若含章末段，细纲「章末型」字段不动 |
| 5 | **实物清单承诺项** | `_meta` 里的物，改后仍在文中（跑 `check_contract.py` 看覆盖率不降） |
| 6 | **对白信息点** | 段群若含对白，信息点表逐条仍在 |
| 7 | **视角与叙述距离** | 人称不变、叙述者在场程度不变 |

**范围是硬的**：U6 **一次只做连续 2–4 段**，**章首段与章末段不在范围内**
（它们各有专门的处理：章首见 `chapter-craft.md`，章末见 `hook-techniques.md`）。
**不许把 U6 用成"整章重写"** —— 那就是纪律 3 当初防的东西。

**U5 与 U6 的分工**：U5 治"**这一段的组织方式**"（一段之内的落笔问题）；
U6 治"**这几段之间的差异**"（每段单看都还行，连起来读是一个调子）。先做 U5 再做 U6。

### 2.4 ★ 风险声明（诚实）

> **U5 / U6 是"解除体系自己立的禁令"，风险是真实的。**

纪律 3 当初防的那件事——**"重写会引入新一轮 AI 味"**——**不是空话**：
重写一次，就是让模型用它的默认习惯再组织一遍语言，
而模型的默认习惯正是"短句、泛化指代、均匀节奏"。
**换句话说：U5/U6 打开的这个口子，正是 AI 味最擅长钻回来的地方。**

所以 U5 / U6 **必须**同时满足三条，缺一条就不许做：

1. **带强边界**：2.2 的② / 2.3 的七项保留清单，**逐条写到纸面**，不许"心里有数"。
2. **改后复跑指标**：跑 `check_human_rhythm.py`。**不许"我觉得更好了"**——
   句长分布、节奏 CV、超长句占比正是段级重写最可能改坏的地方（重写会让句长重新拉平）。
3. **范围是单段 / 段群**：**一次不许重写整章**。改坏一段损失一段；改坏整章损失整章。

> **一句话：U5/U6 是"带电作业"。边界、复跑、范围，三样是绝缘手套。**

### 2.5 U5 改前 / 改后对照（两组）

**组一 · 章末落笔（治"落笔公式化"）**

`hook-techniques.md` 实测的那类落笔是「**叙述一句 + 余味**」，
下面这一处就是它的变体（叙述一句 + 「反正」+ 自嘲）：

- 改前：
  > 他把炉门扣上，反正明天还得再来一趟。他靠在墙上，慢慢闭上眼。
- 改后：
  > 他把炉门扣上，回头看见阿禾还站在灶台边没走。
  > "回去吧。"
  > "你先走。"
- 为什么更好：**U5**。这一处的章末型是**乙·关系余韵**，按 `hook-techniques.md` 的「落笔形态」表，乙型的落笔形态**必须是"小动作 + 一句对话"**，「不该是"叙述者的评价"」——而改前两句正是叙述（"反正明天还得再来一趟"是心境评价）。改后保留了小动作（扣炉门）、把落点换成一句对话，**落笔形态真的换了**（不是换了措辞）。事件清单未变（扣炉门仍在）、章末型未变（仍是乙型）、未增删任何信息。

**组二 · 整段平（治"每句都在干活"）**

- 改前：
  > 他把行李放下，看了一眼屋子。屋子不大，只有一张床和一张桌子。他走到桌边，拉开抽屉。抽屉里有一本账本。他翻开账本看了起来。
- 改后：
  > 他把行李放下。屋子不大，一张床，一张桌子，桌子腿底下垫着半块砖。
  > 他在床边坐了一会儿，才起身去拉抽屉。抽屉卡住了，他拽了两下，第三下才开。
  > 账本压在最底下，封皮上印着一个圆圆的茶渍。他翻到上个月那一页，没往下看，先盯着那个茶渍看了半天。
- 为什么更好：**U5**（段落级重写，不是句级替换——改前改后**句子的组织方式**变了，不是把某几个词换掉）。补进了 **3 处不推进情节的实物与动作**：`垫桌腿的半块砖`／`抽屉卡住、第三下才开`／`封皮上的茶渍`——它们就是 v6.9.0 说的"**为自己写的句子**"（改前这一段一句都没有）。句长变化可查：改前 6 句全在 8–13 字；改后第二段有一个 26 字句、第三段有一个 30 字句。事件逐条未变（放行李／看屋子／拉抽屉／翻账本——四件事都在），人物状态未变。

## 三、每个单元的指令模板（★ 直接可复制）

**形态与 `occupancy-rewrite.md` 同源**：说"**这里要放一个具体的东西**"，
不说"不要写泛泛的感慨"。**每个模板必须包含四样**：
`定位（改哪一段/哪一句） + 单元 + 保住什么 + 目标是什么样（给样例或特征，不给指标区间）`

> ⚠️ **"目标是什么样"要用样例或特征说，不许用指标区间当目标。**
> 「把平均句长改到 25 字」不是目标，那是**指标**——Agent 会为了凑 25 字往里塞废话。
> **目标是"长成这个样子的句子"。**

**U1 · 句级·插入**
> 第 3 段第 2 句之后，插入一句这一动作周围的环境或身体感受（不是把原句拉长）。
> 保住原句的措辞与信息，原句一个字不动。
> 目标长这样：「他把碗放下，灶台上的水还在滴，一滴，两滴，砸在盆底。」

**U2 · 句级·替换**
> 第 5 段。这一段 4 句连开都以"他"起头。把其中 2 句的主语换成他手边的东西或一个时间（只换主语，不删句、不改信息）。
> 目标长这样：「他掏出手机，点开搜索框」→「手机在口袋里震了一下，点开搜索框」。

**U3 · 句级·换物**
> 第 7 段第 3 句。这一句是通用件（换书测试能原样搬进别的都市小说）。把「一件东西」换成一个只有这一章才有的实物，并让这句话的成立依赖它。
> 保住事件与人物状态不变，设定不删（改走实物出场）。
> 目标长这样：「桌上放着那半包受潮的火柴，他看了很久，没去动它。」
> （判据：把"火柴"换成"信封"，这句立刻不通。）

**U4 · 对话段·重写**
> 第 12–14 段这段对白。两个人说话一个腔调，而且全是信息交换——对谁都能说、而且什么都说了。只重写这几句台词本身：让其中一个人不马上答（先去做个无关的动作），或者答一半就改口。
> 保住对白传达的信息与结果一个不变、说话人不变，不新增任何过往。
> 目标长这样：「你去不去？」→ 他没答，先把手里的烟按灭在碗沿上。「不去。」

**U5 · 段落级·重写**
> 本章末段。这一处的落笔是"叙述一句 + 反正 + 自嘲"，与本批前三章的落笔形态同构。只重写这一段的落笔，不重写整章。
> 保住：章末型不变（乙·关系余韵）、伏笔不动、与上章的交接事件不动、事件不增不减。
> 目标长这样：见 2.5 组一的乙型样例——一个小动作 + 一句对话，不上价值。

**U6 · 段群·重写**
> 第 8–11 段（连续 4 段）。这四段的句长全部落在 15–20 字，整章节奏是平的。只重写这四段的语感，一次不扩到整章，不动情节与人物状态。
> 保住：事件清单、人物状态、与第 7 段的接缝、本章章末型。
> 目标长这样：这四段里至少有一段是连续短句（5–10 字，一句一个动作、不解释），至少有一段有一个 40 字以上的长句铺陈（多个修饰、慢下来）。

## 四、改前改后对照（★ 机制 4）

### 4.1 格式：每条改写必须产出三行

```
- 改前：<原句>
- 改后：<新句>
- 为什么更好：<具体到判据 —— 哪个单元 + 补进了什么 + 句长/位置变化，
                不许写"更自然了/更有画面感">
```

**三行一组，一条不能少。** 三行对照**写在改稿记录里**，与改稿同时交付。

### 4.2 为什么必须做：现在的流程验收不了"效果"

现在改完只跑一遍脚本比指标数字，于是有一个盲区：**Agent 不知道自己改得有没有效果。**

脚本能告诉你"平均句长从 14.2 升到 21.8"，但它告诉不了你
**"你改的那三处，是不是真的把这一段的问题解决了"**——
指标是**整章的统计量**，它上升有可能是别处来的。
三行对照把"效果"从统计量变成**看得见的东西**：原句是谁、新句是什么、为什么这么改更好。
**这三行是可被第三人复核的。**

### 4.3 哪一半可以机器校验（说清楚，别夸大）

| 部分 | 谁查 | 判据 |
|---|---|---|
| **对照块存在** | **脚本** | 改稿记录里每条改写块必须含 `改前：`／`改后：`／`为什么更好：` 三行 |
| **改前 ≠ 改后**（防空改） | **脚本** | 两行字符串不相等。**相等的直接判无效**——"改完了"其实是"抄了一遍"，这是最容易发生的假工作 |
| **"为什么更好"是否具体** | **质检子代理 / 人** | 必须能指认出：**哪个单元 + 补进了什么 + 句长或位置的变化**。这三样任缺一样即判**无效** |

> **半机器、半人工是刻意的。** "改前 ≠ 改后"是**字符串级**的，能做成硬判据，所以给脚本；
> "为什么更好是否具体"是**理解级**的，做不成硬判据（`specificity-gate.md` 0.2 已论证过
> 同类问题"宁可承认测不了，也不要造一个看起来在工作的闸门"），所以交给质检子代理。

### 4.4 反例一组（这一条是无效的）

```
- 改前：他走了很久，心里很乱。
- 改后：他从日头偏西一直走到掌灯，脑子里没停过。
- 为什么更好：读起来更顺了。          ← ❌ 无效
```

**为什么无效**："更顺了"**三样都没有**——没有单元、没有说补进了什么、没有句长/位置变化。
这句话在事实上不可证伪，在行动上不可执行：**下一个 agent 看了它，不知道能照做什么。**

有效版（同一个例子的合格写法）：

```
- 为什么更好：U1 插入。原句"走了很久"是泛化量、没有坐标，
  替换成"从日头偏西走到掌灯"（时间锚定，数字密度这一项的代理信号）；
  句长 9 → 14 字；位置未变、信息未增。
```

**差别**：合格版里每一句都在**指认对象**（U1 / 数字密度 / 句长 9→14），所以下一轮 agent 能照它判断"我这次算不算做到了"。

## 五、顺序：单元之间怎么排（★ "先粗后细"）

### 5.1 钉死的顺序

> `U5 / U6（段群、段落） → U3（本体层） → U1 / U2 / U4（句、对话段）`

### 5.2 为什么必须是这个顺序：段级重写会重置句长分布

> **段级重写（U5）会把整段的句子重新组织一遍。** 如果你在它**之前**先做了 U1（插入铺陈句），
> **重写会把你刚插入的那几句一起重写掉** —— **那一轮白做。**

这不是理论。U5 的输出形态就是"这一段重新写一遍"，它**必然**覆盖掉这一段里
所有先前的句级改动。**先做细的、再做粗的 = 细的那一轮全部作废。**

U3 放在 U1/U2 之前同理，只是更隐蔽：U3 换进去的**实物**（`半包受潮的火柴`）
是**句子成立所依赖的东西**——段级重写一覆盖，那个物就没了，U3 那一路的判断要全部重做。
**粗粒度先动，细粒度后动，才不会被覆盖。**

### 5.3 与 `rewrite-playbook.md` 的「附：改写顺序建议」的关系

> **不矛盾。本指南的顺序是套在它外面的那一层。**

`playbook` 附节分的是 **A / B**，分的是**频率层内部**（「欠写」走 A 先补足再压住；
「配额拉满」走 B 的压住顺序）——**那是句级招式之间的顺序**。
本指南分的是**粒度**（段群 → 段落 → 句）。层级关系是：

```
本指南：先定这一章要用哪几档粒度（U5/U6 → U3 → U1/U2/U4）
   ↓
playbook：进到句级那一档内部，再按 A / B 定招式顺序
```

**唯一需要讲清的口径差**在 U3 与 playbook 第 11 节（改抽象句）：
它们**是同一件事**（本体层），但**卡在流程的不同位置**。口径是：

| 本章情形 | U3（= 第 11 节）落在哪 | 为什么 |
|---|---|---|
| **先做了 U5 / U6** | **U1 / U2 之前** | **容器已由段级重写给出**（重写后的段落里有长句、有铺陈）。第 11 节要的"先有长句，才装得住一个物"**已被 U5/U6 满足**，所以 U3 可以提前 |
| **不做 U5 / U6** | **按 A 顺序落在最后**（A 的第 6 步） | 这时容器只能由**第 3 节插入铺陈句**（U1）提供 → 必须**先频率层、后本体层**，照 playbook 附节走 |

> **两条口径是同一条原理的两种到达路径：先有容器，再放实物。**
> 区别只是**容器由谁提供**——U5/U6，还是 U1。**不要推翻 playbook 的 A/B**，照旧生效。

**U4 为什么排最后**：对白必须与前面定下的**实物**（U3）和**句长手感**（U1/U2）一致——
先改对白，它就会和后面定下来的东西脱节，变成"手感很好但和这一章不搭"的孤岛。

## 六、与既有机制的分工（逐条点名，别重复劳动）

| 既有机制 | 它负责 | 本指南**不做什么** |
|---|---|---|
| **`rewrite-playbook.md`** | **项 → 招字典**：11 节，脚本报哪项就翻哪节 | **不重讲任何一招。** 它是 **U1 / U2 / U3 的招式库**；本指南只说"该用哪个单元" |
| **`post-polish.md`** | **Phase 5 四道工序 + 三条纪律** | **不重讲工序内容。** 本指南只把纪律 3 的**作用域**说清（第二节 2.1） |
| **`specificity-gate.md` 第三节** | **U3 的四问**：换名／换书／删句／复述 | 不重贴四问的表。**U3 的"改法"由它给，"什么时候用 U3"由本指南给** |
| **`humanize-toolkit.md`** | **"往里加什么"的 30 招**（加法层） | 不重讲招式。**它是 U1 / U5 的手段来源**——不知道该加什么时去那里挑 3–5 招 |
| **`human-exemplars.md`** | **外部范本**（人类作者原文，按"时刻"组织） | 不重贴范本。U5/U6 重写时**只读 1–2 段**对应"时刻" |
| **`character-voice.md`** | **U4 的声口卡 + 声口压力测试七问** | 不重讲声口。U4 的"目标长什么样"去它那里取 |
| **`occupancy-rewrite.md`** | **指令形态**：占位式（说"这里放 Y"，不说"不要 X"） | 不重讲形态。本指南第三节的模板**与它同源** |
| **`review-agent.md`** | **独立质检五项测试**（第五项 = U3 的校验） | 不做质检。**U3 交完稿后必须过它第五项**，本指南只负责把 U3 排进流程 |

> **一句话：本指南只做"路由与边界"这一层。** 招式在 playbook、工序在 post-polish、
> 四问在 specificity-gate、加法在 humanize-toolkit、范本在 human-exemplars、
> 声口在 character-voice、指令形态在 occupancy-rewrite、质检在 review-agent。
> **它们都在，缺的是"什么时候用哪一个、不许动什么"——那是本指南。**

## 七、反模式（至少 8 条）

| ❌ 反模式 | 症状 | 为什么会坏 / 修法 |
|---|---|---|
| **拿 U1/U2 去治段级问题** | 整段"每句都在干活"，却去压句首代词、去补破折号 | 17 项全绿、这一段读起来照旧。**段级问题必须用 U5** |
| **U5/U6 裸重写**（不写功能、不写保住什么） | 直接说"把这段重写一下" | 没有验收标准（不知道算不算做到）、没有护栏（伏笔/契约可能被改掉）。**没写①②就不许进③** |
| **一次重写整章** | "这一章文笔还是 AI，整章重写一遍" | 回到粗胚，新一轮 AI 味原样长回来——**这正是纪律 3 当初防的东西**。U5 = 一段，U6 = 连续 2–4 段，章首段与章末段不在内 |
| **用指标区间当改写目标** | "把平均句长改到 25 字" | Agent 为凑数字往句里塞废话，句子变长、内容变空。目标是"长成这个样子的句子"（给样例），不是数字 |
| **三行对照只写"更自然了"** | `为什么更好：读起来更顺了。` | 不可证伪、不可执行，下一个 agent 照不出任何东西。必须指认：**哪个单元 + 补进了什么 + 句长/位置变化** |
| **在 U5 之前先做 U1（白做）** | 先插入铺陈句，再对这一段做段级重写 | 段级重写把刚插入的句子一起覆盖掉——**那一轮完全作废**。顺序是 U5/U6 → U3 → U1/U2/U4 |
| **越界动伏笔/契约/交接段** | 重写段末时顺手把"上一章留下的那个信封"改成"一封信" | 伏笔被改掉、实物覆盖率下降、交接段对不上。U5 的②与 U6 保留清单第一项就是拦这个的 |
| **把 U6 当成"再润色一遍"** | 改动只是换了几个形容词 | 句长带没有错开、节奏 CV 没动——"通篇平"一点没治。U6 的验收是**句长起伏**（至少一段连续短句、至少一段 40 字以上铺陈） |
| **对白改完信息变了** | U4 重写台词时让角色多说一句原文没有的往事 | 新增人物过往（`character-voice.md` 第五节明令禁止），且改了信息内容，后面几章对账会挂。**U4 的验收是信息点表逐条对得上** |
| **U3 顺手把设定删了** | "灵能场衰退"这句太抽象 → 整句删掉 | 世界塌一块。`specificity-gate.md` 1.2 的处置是"**不删，要落到一个可感知的载体上**" |

## 八、一页速记

1. **六种单元**：U1 插入（偏低）／U2 替换（偏高）／U3 换物（本体层）／
   U4 对话段重写（声音层）／U5 段落重写（结构层）／U6 段群重写（语感层）。
2. **份量相同**：「允许动什么」和「不许动什么」**一样重要**——只写禁区只会让 Agent 更保守。
3. **纪律 3 只管道四道精修工序**；U5/U6 是**有边界的重写**（保功能/事件/信息/接口），
   不归它管。**没有作用域的否定式指令会被当成全链纪律**（本 SKILL 已发生两次）。
4. **U5 四步**：写功能 → 列必须保住的 → 只重写落笔 → 与功能对账。
5. **U6 七项保留**：事件／人物状态／接缝／章末型／实物清单／对白信息点／视角。
6. **顺序**：`U5/U6 → U3 → U1/U2/U4`。**做了 U5/U6，就不要再在这个顺序之前做 U1。**
7. **三行对照**：改前／改后／为什么更好。脚本查"块在不在 + 改前≠改后"；
   "为什么更好是否具体"交质检子代理。
8. **U5/U6 是带电作业**：强边界 + 复跑指标 + 单段范围，三样是绝缘手套。
