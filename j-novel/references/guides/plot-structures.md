# 情节结构模板库

继承自 Chinese Novelist 的情节结构库。规划阶段（Phase 2 生成大纲时）按题材选一个结构骨架，把章节号填进去，故事就有了"形状"。

---

## 一、结构选择指南（题材 → 结构 → 章节落点）

| 题材 | 推荐结构 | 建议章数 |
|------|---------|---------|
| 悬疑/推理 | 悬疑结构 / 反转结构 | 20-30 |
| 言情/都市 | 言情结构 / 三幕式 | 20-40 |
| 奇幻/玄幻 | 英雄之旅 / 三幕式 | 30-60 |
| 科幻 | 三幕式 / 多线叙事 | 20-40 |
| 历史/古风 | 三幕式 / 多线叙事 | 30-50 |
| 惊悚/动作 | 惊悚动作结构 | 15-25 |
| 短篇 | 微型/标准短篇结构 | 3-10 |

---

## 二、常用结构模板

### 1. 三幕式（最通用）

```
第一幕（前 25%）：引入世界与主角 → 激励事件（打破日常）→ 主角接受挑战
第二幕（中 50%）：上升冲突 → 中点（发现真相或立场反转）→ 最低点（一无所有）
第三幕（后 25%）：绝地反击 → 高潮对峙 → 解决与新平衡
```

**章节落点**：激励事件在第 1-2 章；中点大约在全书 50% 处；最低点在 70-80%；高潮在 90-95%。

### 2. 英雄之旅（12 阶段 → 章节映射）

```
1 平凡世界 → 2 冒险召唤 → 3 拒绝召唤 → 4 遇见导师 → 5 跨过门槛
→ 6 考验/盟友/敌人 → 7 接近洞穴 → 8 磨难（最深的恐惧）→ 9 报酬
→ 10 回归之路 → 11 复活（最终考验）→ 12 带着灵药归来
```

### 3. 悬疑结构

```
谜题出现（第 1-2 章）→ 调查深入（每章发现一条线索 + 一条死路）→ 真相揭示（高潮前）
规则：每章预设悬念钩子；线索公平（读者理论上可以提前猜到）
```

### 4. 言情结构

```
相遇（第 1-3 章）→ 发展（暧昧升温，误会与心动交替）→ 和解（感情确立或崩塌）
规则：每章关系必须有进展；甜虐比例按剧情阶段调整
```

### 5. 惊悚/动作结构（6 章节奏模板）

```
第1章 危机爆发 → 第2章 逃亡/对抗 → 第3章 短暂喘息（陷阱）→ 第4章 局势逆转 → 第5章 绝境 → 第6章 生死决战
```

### 6. 反转结构（10 章三次反转）

```
前 3 章建立 A 真相（埋无辜线索）→ 第 4-6 章第一次反转（A 被推翻）→ 第 7-8 章第二次反转（B 也不对）→ 第 9-10 章最终真相
规则：每次反转都要有此前埋下的线索支撑，读者回头能发现
```

### 7. 多线叙事

```
交叉剪辑模式：A 线/B 线交替推进，在交汇点合并
时间线模式：不同时间线并行，逐步收敛到同一点
规则：线越多，每条线的出场密度要越高，不能让读者忘记某条线；最终必须收敛
```

### 8. 短篇结构

```
微型（3 章）：悬念 → 发展 → 反转收尾
标准（5 章）：引入 → 升级 → 转折 → 高潮 → 余韵
```

## 三、单章内部结构（写作骨架检查项）

```
开头 10%：钩子（用 hook-techniques 的引子招式）
发展 60%：核心事件推进（2-3 个张力波峰）
高潮 20%：本章情绪或冲突最高点
结尾 10%：悬念钩子（回收旧悬念 + 立新悬念）
```

**无效章节结构（避免）**：全程铺垫无波峰 / 高潮过早后面泄气 / 结尾无钩子像被截断 / 多事件无重点平均用力。

---

## 四、关于"中点"的强化（来自 Reasonix 情节引擎）

任何结构中，**中点反转**都是最值钱的章节：读者以为故事在往东走，突然发现真正的东西在西边。规划大纲时，务必在中点安排一个改变全书走向的事件（身份揭底/立场反转/目标更换）。

> 融合版提示：结构选择要与 Phase 1 采访第 3 轮（叙事架构）一致；细化到章节落点时写进 `01-大纲.md`。
