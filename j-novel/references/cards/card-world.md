# 卡 · 世界（这份设定是约束，不是参考读物）

> 任务包里有一份**世界设定包**：场景卡 + 规则与**边界** + **专有名词表** + 三条硬设定。
> 它不是背景资料——**它是你和隔壁子代理之间"是不是同一个世界"的唯一凭据**。

---

## 一、四条纪律

1. **只用表内的词。** 表里已经有名字的东西，**禁止另造同义新词**：
   不许把「灰铁」写成「灰色铁矿」，不许把「第七矿脉」写成「深井矿洞」。
   > 文风可以各自接近，**名词必须完全一致**——这是最硬的判据。

2. **要造新词，必须报。** 本章确实需要表里没有的东西 → 照写，但在回报里**单列一行**
   `新增专名：[词] ｜ 定义：…`。**不报 = 下一个人不知道 → 两章之后世界就分裂了。**

3. **"做不到什么"和"能做到什么"一样重要。** 规则切片里写了边界（匠职不能进队伍主位 /
   解构之眼只对经手过的物件生效），正文里就不能违反。
   **违反设定换来的爽是假爽**——读者一旦发现世界没了规矩，所有爽点都会贬值。

4. **三条硬设定是红线。** 它们通常是这本书的**蓄能装置**（例：主角永远进不了内城）。
   **不要"顺手帮主角解决"掉**——那等于拆掉后面几十章的引信。

## 二、机制卡怎么用（它和"场景卡"的区别）

| | 场景卡 | 机制卡 |
|---|---|---|
| 是什么 | **描写素材**（可调用的细节：支撑木斜在洞口 / 白霉 / 敲石壁报材质） | **运行法则**（能做什么 / **代价** / **边界** / 触发条件 / **会引发什么冲突**） |
| 用几次 | 一次就没了 | **每章都在用** |

**判据**：这张卡能不能推出一场戏？
- 推得出 → 它是机制，**本章要用它产生一次代价或冲突**。
- 推不出 → 它是描写，放到素材区去，别当设定用。

**最常见的浪费**：机制卡写着「这能力有代价」，但正文里主角用它从来没付过代价。
→ 那不是设定，那是**免死金牌**。

## 三、自检一句

读完这一章，读者能不能在**没有旁白解释**的情况下，知道
"**这是在灰炉村 / 第七矿脉，而不是一个随便的村子 / 矿洞**"？

答不出 → 世界没落地。补的是**具体的物和行为规矩**，不是形容词。
