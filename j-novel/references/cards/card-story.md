# 卡 · 故事（这一章值不值得读）

> **句法决定它像不像人；这张卡决定它值不值得读。**
> 一页卡如果全是句子指标，结果就是"像人写的、但读完不想读下一章"。

---

## 一、五格（动笔前 90 秒填，写进 `_meta`，**不是正文**）

```markdown
## 故事账
- 选择：他在 A 与 B 之间选了一个，两个都疼
- 代价：选完真的失去了什么 —— 指得出第几章会因此出问题
- 位移：信息 / 关系 / 位置 / 资源 / 自我认知 —— 从什么变成什么
- 可删性：删掉这章后文要改 N 处（写出 N 和是哪几章）
- 欲望：他现在最想要什么 —— 具体对象 + 期限或数量
```

| 格 | ❌ 不合格 | ✅ 合格 |
|---|---|---|
| 选择 | 「他决定去矿洞」——那是行程 | 「救她要暴露密道，不救她会死；他选了暴露」 |
| 代价 | 「他很痛苦」「他受了伤」 | 「密道暴露 → 货出不去 → 欠老周的钱还不上（第 14 章追债）」 |
| 位移 | 「他变强了」——每章都涨，读者不认 | 「关系：从互相试探 → 她替他撒了一次谎」 |
| 可删性 | 「不能删」 | 「3 处（第14/16/19章都依赖它）」 |
| 欲望 | 「他想变强」 | 「下个月前凑够三十七两，把妹妹从契上赎回来」 |

**三条硬规矩**：`位移` **不许写「无」**（静场章也要变一样东西）／`可删性 0 处` = 水章／**动笔前定，不许写完补**。

## 二、后果链（五栏，**动笔前**；与五格同一个文件、同一个 30 秒）

> **五格问"这一章值不值得存在"，后果链问"这一章会往哪儿长"。**
> 前者是点，后者是线。**AI 编的故事，几乎全是"点都成立、线是断的"。**

```markdown
## 后果链
- 动作：本章最关键的那一个动作或决定（带专名）
- 一阶：它立刻改了什么（谁做了什么／什么东西换了位置）
- 二阶：那个改变又逼出什么（**必须指到章号或具体场景**）
- 没看见的路：读者会想到、他没选的那条路；**为什么没选**
- 误判：谁基于当时的信息判断错了，错在哪（**不许写"无"**）
```

| ❌ 表演式填空 | ✅ 真推演 |
|---|---|
| 「引发了冲突」 | 「证据袋被放进"待归档"抽屉 —— 第 9 章老周听说后改口，不肯作保」 |
| 「为后续埋下伏笔」 | 「他把钥匙还回去，但没说他进过那间屋子 → 下一章苏晚发现锁孔有划痕」 |
| 「他别无选择」 | 「他可以先复印一份 —— 读者会想到；他没选，因为他以为公家不会赖」 |
| 「没有人判断错」 | 「他以为警察信他。错在他只看见警察在记笔记，没看见警察一直在看表」 |

**三条硬规矩**：

1. **`二阶` 必须指到具体章号或场景**。指不到 = 只推了一跳，写的是形容词。
2. **换一本书还成立 → 这是总结，不是后果。** 全部退回。
3. **`误判` 不许空**。这一栏是"全员清醒"的唯一解药：人物心里得有一个**错的判断**，
   这个错会漏到动作里 —— **人味不是句子花，是人物手里有一个错**。

> **这一节不占你的推演预算**：想多久都行，但必须写。写完才动笔。
> `二阶` 里"下一章必须处理"的那件事，**当场登记进 `08-承诺账`**——那是它到期不还会被拦的地方。

## 三、三种病（处方一律是**改事件**，加描写全线无效）

| 病 | 症状 | 处方 |
|---|---|---|
| **流水账** | 每章都在做事，读完记不住他做了什么**决定** | 把其中一件事改造成两难：给他一个"不做会更好"的选项 |
| **白给** | 爽点很足，读者却不替他高兴——赢了之后什么都没少 | 让这次胜利**花掉**一样东西 |
| **原地转** | 单章不难看，连读十章像在原地 | 换位移维度（变强 → 关系 / 自我认知） |

> 诊断顺序：**先看可删性**（0 = 流水账的典型结果），再看代价，最后看位移。
> **别从「选择」看起**——它最容易写得漂亮（"他选择了牺牲"），也最容易骗人。

---

## 四、两笔账（写前还、写后欠）

- **还债**：brief 里有「本章必须还的债」→ **到期就还；还不了就当场改期**（改期合法，无声拖过去不合法）。
- **欠债**：写完问一句——**读者读完这章，会记着哪件事？** 那件事当场登记进 `08-承诺账.md`。

**一章最多还 2 笔。** 还 5 笔 = 交作业，读起来像结算清单。

---

## 五、一句话自检

> **删掉这一章，后面要改几处？**
> 0 处 → 它不该存在（要么删，要么给它一件事）。
