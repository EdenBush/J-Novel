# 质量宪法（Quality Constitution）

> **定位**：全体系**唯一一份"目标"文件**。其余所有文件回答"怎么做"，它回答"**做到什么算好**"。
> 冲突时以本文件为准；**本文件不重抄任何技法**（技法各有其主，见文末权威表）。
>
> **硬上限 9000 字。超过 = 又在写百科。** 见第七节「自毁条款」。

---

## 零、一句话

读者不会因为"平均句长 30.8、作者在场 4.1、命中率 46%"读下去。
他读下去是因为**想知道接下来会怎样**，并且**喜欢听这个人讲**。

→ 两件事，缺一件另一件都白搭：

| | 问题 | 谁回答 |
|---|---|---|
| **故事值得读吗** | 这一章作为一个故事单元，立不立得住 | `guides/story-ledger.md` |
| **像人写的吗** | 句子、声音、具体性 | 文字层（17 项指标 + 本体层 + `guides/blind-test.md`） |

**本体系此前的全部工程化精力都在第二行。** 这是它最贵的一个结构性空白：
它可以稳定产出"读起来像人写的、但读完不想读下一章"的章节——因为**没有任何一处问过第一行**。

---

## 一、三层目标（不是一层）

| 层 | 问什么 | 载体 | 能否脚本化 |
|---|---|---|---|
| **L1 故事层** | 这一章值得读吗 | `故事账` 五格 ＋ 独立评委的**可删性测试** | **半**：字段能脚本，好坏不能 |
| **L2 频率层** | 像不像人（可测的那一半） | 17 项指标（`check_human_rhythm.py`） | 能（有退出码） |
| **L3 本体层** | 这些细节只属于这本书吗 | 实物清单 → 可替换性四问 → **盲测** | 不能（正则做不到，本体系已诚实承认） |

**三条铁的关系（每条都踩过）：**

1. **L2 全绿 ≠ 达标。** 实测：某项目 10 章退出码全 0，而平均句长 10/10 章低于人类下沿、动作短语 10/10 章为 0 —— **整本欠写**。（`execution-contract.md` 第六节）
2. **L2 全绿 ≠ L3 过。** 17 项测的是"多长／多密／多少次"，测不了"这个细节是不是只属于这本书"。
3. ★★ **L1 是前两层的前提。** 一章如果没有"选择—代价—位移"，那么它的句子再像人、细节再具体，
   也只是**把一段不必要的事写得很像人**。前两层能保证"不假"，只有 L1 能保证"值得"。

> **为什么这条要写进宪法**：本体系历史上每一次"加固"，都加固在 L2 上
> （更多指标、更严的闸门、更细的配额卡）。而作者的反馈是**"文笔还是很 AI"**和**"故事不太好"**——
> 是两句话。只治第二句，第一句永远治不好。

## 二、五条生成承诺（动笔前定，写时满足，交付前对账）

**这五条不是指标，因此不能被"凑数"满足。它们都是二元的：有 / 没有。**

| # | 承诺 | 判据（能当场回答是/否） | 落盘位置 |
|---|---|---|---|
| 1 | **声音** | 本章**第一句**能否被认成口吻宪法里那个人？读样本 → 读第一句 → 像同一个人在讲吗 | `00-故事圣经.md` `## 〇、口吻宪法` |
| 2 | **具体** | 是否定了 3–8 件**搬到本书别章就不成立**的实物？ | `chapters/_meta/*.meta.md` `## 实物清单` |
| 3 | **代价** | 主角是否做了一个**两难选择**，并**因此真的失去了一样东西**？ | `_meta` `## 故事账`（`代价：`） |
| 4 | **冗余** | 是否有 ≥2 处**对情节无用、对人有用**的东西？（删掉故事不变） | 正文自检 ＋ `human-quota.md` |
| 5 | **未完成** | 是否有 ≥1 处**该解释而没解释**？ | 写前声音预置的「留白点」 |

**为什么是这五条**（不是十条）：
它们是本体系所有实测里**唯一反复被证明有效的五项**——口吻宪法（文本样本激活语域）、实物清单（本体层生成端）、
代价账（故事层，本轮新增）、毛边（加法层）、留白（叙述者在场）。
其余全部是**手段**（句长、破折号、明喻、量词…），手段服务于这五条，不是反过来。

> **判据**：写完一章，如果这五条里有任意一条答"没有"，**先补它，再谈指标**。
> 指标是事后可以调的数字；这五条是事后很难补的结构。

## 三、表述规范：给模型看的永远是「形态」，不是「阈值」

本体系最反复的一类事故叫**「底线当目标」**：
`check_human_rhythm.py` 里写 `hard=18`（低于 18 才不合格），而人类真值区间是 `22.7–36.6`；
文档一旦把 18 抄给模型看，**模型就把它当目标**，写到 18–22 就"觉得自己达标了"。

**修法不是把数字改对，是把数字换成形态。**

| ❌ 写给模型看的（阈值） | ✅ 写给模型看的（形态） |
|---|---|
| 平均句长 ≥23 字 | 这一章要有 **3–4 个"一句话装完一整个处境"的长句**，最长那句超过 100 字；它们之间允许碎句，允许只有一个词的段落 |
| 超长句占比 ≥3% | 至少有一次**连续两个长句**（读者被按在水里两口气），紧接着一句极短的话 |
| 作者在场指数 2.5–12 | 叙述者在**三个地方**忍不住表了态，其中一次他其实**不该说话** |
| 数字密度 ≥0.8/千字 | 全章至少出现 **3 个"只有这个世界才有的数"**：一个价钱、一个门牌或编号、一个年份或时间 |
| 明喻 0.8–1.5/千字 | 允许一处**写得挺烂的比喻**（人类会写坏比喻），不要每处都精修 |
| 破折号 ≤1.5/千字 | 想补充的那半句话，**并进主句**；并进去会啰嗦的地方，就让它单独成句 |

**判据一句话**：**这句话能不能直接指导一次落笔？**
不能 → 它是给审计看的，不是给写手看的，**不许出现在任务包与速查卡里**（那两处只放形态）。

> ⚠️ 阈值仍然必须存在于**脚本**里（那是判据的唯一事实源）。
> 本规范管的是**传播**：脚本用数字，写手用形态。**同一个东西，两个读者，两种写法。**

## 四、「不整齐」清单（正向义务，不是禁令）

好文字有一个共性：**它不在同一水平上用力。**

| 可执行的四件事 | 为什么 |
|---|---|
| 让**某一段明显比别的段长**（允许啰嗦一次） | 人类的注意力是有起伏的；均匀 = 机器的签名 |
| 让**一处比喻很烂** | 人类写坏比喻的频率远高于 AI；每处都精修 = 精修痕迹 |
| 让**一次对话没说完** | 人类对话 15.8–27.7% 是"一段话说完"，也大量存在"说到一半被打断" |
| 让**一次叙述者失态**（说多了／说得不合时宜） | 这是"有一个人在场"最硬的证据 |

★ **这四条与速查卡【四】加法配额同源**——那一节给"做什么"，本节给"**为什么"和"容许到什么程度"**。
它们全是**加法**：删不出这四条，只能加出来。

## 五、交付宣告的三句话（取代「可以交付」）

任何"这章完成"的宣告，**必须**带这三句。缺一句 = 宣告无效。

```
1. 最强的一段：<原文引用，≥80 字> —— 强在：<一句话，指认它做了什么别的段落没做的事>
2. 最弱的一项：<指标名或结构问题> —— 处理：<已改 / 带理由豁免（indicator-waived）/ 下一轮 R2 返工>
3. 盲测：人类置信度 <x>/3（评委可靠性：<正常/已作废>）
```

**为什么**：事故原话是"**结论：可以交付**"，同时命中率中位 12%。
"可以交付"是**给自己的合格证**；这三句是**给下一个人的交接单**——
第 1 句逼你说出"好在哪"（说不出来 = 这章没有好的地方，那是比指标更严重的信息）；
第 2 句禁止"留待资金宽裕时逐章补"这类无期限拖延；
第 3 句是**唯一一个不由执行者自己打分的读数**。

## 六、权威关系（谁说了算，改数字去改主人）

| 问题 | 唯一权威 | 备注 |
|---|---|---|
| 什么算"好" | **本文件** | 只定义目标，不定义数字 |
| 这一章值不值得读 | `guides/story-ledger.md` | 五格 + 三条判据 + 可删性 |
| 频率阈值是多少 | `scripts/check_human_rhythm.py` | 脚本是唯一事实源；文档里的数字必须与它同口径 |
| **生成时怎么满足** | `guides/quick-reference-card.md` 零节 | **子代理唯一读物**；本文件不重抄 |
| 细节是否只属于本书 | `guides/specificity-gate.md` 第三节 | 可替换性四问 |
| **像不像人（不由自己判）** | `guides/blind-test.md` | 盲测协议 |
| 改写按什么顺序 | `guides/deai-entry.md` | 五步 + 三禁令 |
| 一章有哪几个动作 | `SKILL.md` 每章最小必做清单 | 全体系唯一权威清单 |

> **本文件与它们的分工是"目标 vs 手段"。**
> 若本文件与脚本的数字冲突 → **服从脚本**；若本文件与某本 guide 的"什么算好"冲突 → **服从本文件**。

## 七、自毁条款（认真执行）

**如果本文件超过 9000 字，或者它开始重抄别的文件的内容，删掉重写。**

理由：本体系最贵的事故不是"缺一条规则"，是**规则太多以至于没人读完**。
实测：单章读点去重 21 本 ≈ 15.2 万 token；而调用预算只有 5–8 次/章（v9.0；旧 10–18）。
**读点要求与成本纪律在数学上互相否定，于是执行者只能二选一——而成本有审计、读点没有审计。**

> **清单越全，越没人信。** 这份宪法的全部价值，是让一个执行者在**两分钟内**知道"做到什么算好"。
> 一旦它需要十分钟，它就变成了它想治的那个病。
