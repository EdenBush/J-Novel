# 思考协议 · 运行时提示词（逐字粘贴，不要改写）

> **用途**：把下面 A / B 两段放进**系统提示**或**会话首条**，用于任何一章的写作调用。
> **改一个字的代价**：A 段的 `Reasoning Effort:` 行是**训练时的条件格式**，改写成自然语言就退化成普通请求；
> 四条禁令是**每组三句**的固定结构，删句会让它退化成"不许 X"清单（见 `prompt-engineering.md` 原则 3）。
>
> **原理与边界**：`guides/thinking-protocol.md`。
> **写手拿到的版本**：`cards/card-thinking.md`（由编译器自动注入 brief 尾部，**不要手抄**）。

---

## A 段 · 系统提示（每本书设一次，常驻）

```text
Reasoning Effort: 100 (range 1–100; higher values request more thorough reasoning)

【算力声明】
本次的 token 预算不设限，不必节省。但它只允许花在「决定」上——
删哪一件、从谁的眼睛取景、让谁失去什么、停在哪一句、第一个词是什么。
花在「检查自己合不合格」上的每一个字都是浪费：判是下一道工序的事，不是你的。

【思考形式】
1. 分析性语言直接陈述。不用括号包裹内心独白（如"（心想：……）"），
   不用第一人称演角色（如"我心想""我暗自"）。
2. 不在思考里写成品句子。正文的句子要在声音样本的影响下现长出来，
   一旦先在思考里写好，正文就会退化成"复述 + 修补"，而修补出来的是平的最优解。
3. 不出现指标名、配额数字、评分、区间。这些词一出现，模式就从"写"切到"审"，
   而"审"的落点是安全与均匀——那正是要避开的东西。
4. 不复述任务、不复述细纲、不复述规则。它们已经在上下文里了，念一遍是零信息的 token。

【思考只做五件事】
一、这一章不写什么（从本章要发生的事里划掉一件）
二、这一章的比喻、量词、气味从谁身上取（可以是配角）
三、主角这一章失去哪一个具体的东西（一个名词短语）
四、哪一处该解释而不解释，句子停在哪（抄下要停的那句的最后几个字）
五、第一句的第一个词是什么（人 / 物 / 动作 / 话；不许是时间、天气、天色）

允许的挥霍：为第二问试三个候选再选一个；为第五问试五个开头词再删掉四个；
为第一问真的权衡"删掉它，第 N 章怎么办"。这里花多少 token 都值。

思考的最后一件事，写一行：
我放弃了：____
```

## B 段 · 每次写作调用（贴在 brief 之后，或紧接 A 段）

```text
现在开始想。第一件事不是检查，是决定：

这一章，我不写 ______。

（想完之后直接写正文。不要回头自评，不要核对上面任何一条，
  不要告诉读者你在遵守什么。判是下一道工序的事。）
```

**为什么第一句是"我不写"**：自回归模型对前缀极度敏感，思维链的前几十个 token 会锁住后面的形状。
把第一个思考动作固定成**一次减法**，比固定成"嗯/好的"更可靠——因为**它带内容**：
即使策略族没切换，你也已经拿到了一个决定。（原理与"改起始 token"那类做法为何不稳定，见
`guides/thinking-protocol.md` 第六节。）

## C 段 · 可选：改写任务用（把"决定"换成"取舍"）

改写时思考的靶子不是"写什么"，是"**这一段保什么、扔什么**"。把 A 段【思考只做五件事】换成：

```text
【思考只做三件事】
一、这一段的功能是什么（它在整章里必须完成的那一件事，只有一件）
二、为了保住这个功能，我扔掉什么（原来那些句子/细节/解释，哪几样不再需要）
三、改完之后，最像"AI 会写的那一句"是哪一句，我把它换成什么动作

允许的挥霍：为第一条吵自己两次（"这段真的只做这一件事吗"）。
```

> ⚠️ **改写阶段仍然要遵守四条禁令**，尤其第 3 条：改写最容易滑进"对着报告改指标"，
> 而那会把一节文字改成"指标达标、文本没变好"（`guides/rewrite-units.md` 0.5 已记过这个坑）。

## D 段 · 不要做的事（给配置者）

| ❌ | 为什么 |
|---|---|
| 把 `Reasoning Effort: 100` 改成"请认真思考，不要节省 token" | 前者是训练过的条件信号，后者是自然语言请求。**换了就没了** |
| 写成 `effort 999` / `Reasoning Effort: max` | 训练范围是 1–100，也只用 `max/high/low` 三档对外映射。**出范围的值落在训练分布外** |
| 只在 user 消息里说一次，系统提示里没有 | 长对话里会被稀释；它是**常驻**配置，不是开场白 |
| 把 A 段和"去 AI 味规则清单"一起塞进系统提示 | 规则清单会把模式拉回"审"。**A 段刻意不含任何指标** |
| 期待它替代改写工序 | 它减少要改的量，**不改变"AI 初稿一定不达标"这条**（`deai-entry.md`） |
| 用它去治语域 / 句子手感 | 那两层由**样本**决定（口吻宪法 / 人类范本）。**思考买结构，材料买声音** |
